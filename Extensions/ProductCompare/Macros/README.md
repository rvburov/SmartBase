# Обновление двух макросов

Это полные модули для уже установленной в вашей книге группировки и отдельного форматирования.
Для замены не нужно искать отдельные процедуры внутри кода.

Скачайте [macros-windows.zip](macros-windows.zip) и распакуйте его. В архиве находятся два
готовых файла для импорта в VBA под Windows:

- `modProductGrouping.bas` — группировка по последнему блоку;
- `modProductFormatting.bas` — отдельное форматирование.

В архиве оба модуля записаны в Windows-1251 с окончаниями строк CRLF, чтобы при импорте
сохранились русские названия столбцов. Файлы `.bas` рядом с этим документом — исходники
в UTF-8 для чтения и правки; импортируйте модули именно из архива.

## Установка в шаблон расширения

Для следующих отчетов нужно обновить именно шаблон из настройки
**Настройки → Расширения → Сравнение составов изделий → Файл-шаблон расшифровки**.
Расширение сохраняет VBA шаблона без изменений: установка макросов только в готовый отчет
не обновляет последующие выгрузки. Нужна также обновленная сборка SmartBase с сопоставлением
по КД; прежняя сборка продолжит сопоставлять строки по индексам.

1. Сохраните копию `.xlsm`-шаблона. Откройте эту копию и нажмите **Alt+F11**.
2. Слева в дереве проекта выберите именно эту книгу и раскройте папку **Modules**.
3. Выделите созданный нами модуль **modProductGrouping**. Нажмите правой кнопкой и выберите
   **Remove modProductGrouping**. На предложение сохранить модуль ответьте **Yes** и сохраните
   его как резервный файл. Так же удалите с сохранением резервной копии только наш модуль
   **modProductFormatting**.
4. **Другие модули, ThisWorkbook / «ЭтаКнига» и код листов оставьте.**
5. Выберите **File → Import File** и импортируйте
   **modProductGrouping.bas**. Затем так же импортируйте
   **modProductFormatting.bas**.
   В файлах уже заданы правильные имена модулей: `modProductGrouping` и `modProductFormatting`.
6. Откройте **ThisWorkbook / «ЭтаКнига»** этой книги. Проверьте обработчики из файла
   `ThisWorkbook-menu-events.txt`. Если обработчики уже есть, добавьте в них указанные вызовы,
   сохранив остальной код. Не создавайте вторую процедуру с тем же именем. Если обработчиков нет,
   скопируйте их из файла. Именно они восстанавливают меню при открытии нового отчета.
7. Нажмите **Debug → Compile VBAProject**, затем сохраните книгу через **Ctrl+S**.
8. Вернитесь в табличный редактор. Нажмите **Alt+F8**, выберите **InstallProductGroupingMenu** и нажмите
   **«Выполнить»**. Затем через **Alt+F8** запустите **InstallProductFormattingMenu**.

При правом клике по ячейке сверху будет **«Форматирование»**, следом —
**«Группировать по индексам»**. Прежние обработчики в «ЭтаКнига» продолжают работать:
названия вызываемых процедур сохранены.

В настройке **«Файл-шаблон расшифровки»** укажите эту обновленную копию шаблона и заново
сформируйте отчет обновленным расширением. Для существующего отчета достаточно заменить
модуль в самой книге: группировка будет построена по его последнему столбцу индекса.
Книги исходных расшифровок обновлять не нужно.

## Как работают обновленные команды

**Группировка.** В первых пяти строках ищется самый правый заголовок **«Индекс»**
или **«Уровень идентификатор»**. Группы строятся только по номерам индексов этого последнего
блока: `1` включает `1.1`, `1.2` и их потомков; `1.1` завершается перед `1.2` или `2`.
При этом `1.10` не считается потомком `1.1`: после номера родителя должна идти точка.
Допускаются запятые вместо точек, ведущие нули частей и одна завершающая точка.
Индексы храните текстом, как в выгрузке расширения: преобразованный в число `1.10` уже
не отличается от `1.1`, и макрос не может восстановить утраченный ноль.

Столбец «Уровень» и индексы предыдущих блоков не используются. Макрос не сверяет разные
даты, не заполняет первый блок и не меняет значения ячеек. Операции и пустые строки без
индекса остаются внутри текущего узла. Группа заканчивается только перед следующим индексом,
который не является ее потомком, или в конце всего отчета. Поэтому строки после последнего
номера, включая исторический хвост прежних дат, входят в последний открытый узел. Наличие
или отсутствие данных в соседних столбцах границы групп не меняет.

Вложенность учитывает только родителей, которые действительно встречались выше: если
первый номер — `1.2`, для отсутствующего `1` отдельная группа не создается. «Изделие» и
одиночный нулевой индекс сбрасывают текущую вложенность и остаются на базовом уровне;
пустые строки до первого узла тоже остаются на нем. Уровни глубже восьмого показываются
на восьмом, но полные номера продолжают определять границы ветвей. Некорректный индекс
останавливает команду до изменения группировки.

Макрос не поднимает операции и не удаляет строки. Сопоставление изделий и одинаковых
операций между датами сохраняется таким, каким его сформировало расширение.

Группировка действует на всю строку листа, поэтому одновременно сворачивает все даты.
Перед запуском снимите активный отбор и защиту листа. Команда перестраивает прежнюю
группировку и раскрывает строки отчета.

**Форматирование.** Эта команда остается отдельной. Она определяет все блоки по шапке,
поддерживает оба названия индекса и оформляет все даты: Arial 12 от первой строки до
общего конца отчета, все обычные границы с пятой строки до конца данных. Пустые столбцы
между блоками не затрагиваются. Значения индексов, иерархия и группировка не пересчитываются.

Нативное выполнение этих модулей в VBA табличного редактора здесь не проверялось.

## Обновление архива разработчиком

Единственные исходники модулей — UTF-8 файлы `.bas` в этой папке. После их правки
пересоберите готовый архив из корня репозитория:

```bash
python3 Extensions/ProductCompare/Macros/export.py
```

Скрипт не требует сторонних пакетов. Он упаковывает модули в Windows-1251/CRLF,
обработчики книги и эту инструкцию — в UTF-8. Архив не устанавливает макросы в шаблон
автоматически: установка выполняется по шагам выше.
