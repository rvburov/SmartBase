# Свойство: «Статус» (`status`)

Часть [реестра типов свойств](overview.md). Единый источник классификации — [`FieldTypeInfo`](../../../../Core/Models/FieldTypeInfo.cs).


Полный аналог `select` во всех местах (строка-значение, опции из `ConfigJson`, редактор `ComboBox`;
классификатор `FieldTypeInfo.IsOptionList`), отличия только два:
- **новое поле сразу получает три опции** по умолчанию — Запланировано / В работе / Выполнено
  (`ConstructorRepository.TaskStatusOptions`), которые дальше правятся как обычные пункты списка;
- это **тип авто-поля «Статус»** в разделе задач: при включении задач в коллекции недостающее поле
  «Статус» создаётся типом `status` (роль определяется флагом `IsTaskStatus`; старые поля-статусы типа
  `select` продолжают работать) — см. [tasks/overview.md](../../features/tasks.md).
