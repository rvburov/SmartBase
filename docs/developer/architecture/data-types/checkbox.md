# Свойство: «Чекбокс» (`checkbox`)

Часть [реестра типов свойств](overview.md). Единый источник классификации — [`FieldTypeInfo`](../../../../Core/Models/FieldTypeInfo.cs).


Канон хранения — `1`/`0`; на чтении распознаётся и легаси `true`/`True` (`WriterHelpers.IsChecked`).
Показ — `✓`/пусто. Редактор — `CheckBox`.
