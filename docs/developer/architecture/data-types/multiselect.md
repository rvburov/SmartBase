# Свойство: «Мультисписок» (`multiselect`)

Часть [реестра типов свойств](overview.md). Единый источник классификации — [`FieldTypeInfo`](../../../../Core/Models/FieldTypeInfo.cs).


Набор опций определяется как у `select` (тот же блок «Пункты списка», опции в `ConfigJson`), но
хранит **несколько** значений — JSON-массивом в `db_field_values` ([`MultiSelectValue`](../../../../Core/Models/MultiSelectValue.cs)):
пусто → пустой массив; непустая **не-JSON** строка трактуется как одно значение, поэтому смена типа
из `select`/`status` не теряет данные (при следующем сохранении перепишется массивом). Выбранное
показывается **текстом через разделитель** (и в таблице, и в панели записи); редактор
([`MultiSelectBox`](../../../../Controls/Components/MultiSelectBox.cs)) — выпадающий чеклист с полем поиска
(чекбокс на опцию) в стиле дропдауна фильтра таблицы, **виртуализированный** (тысячи опций без
задержки). **Формат склейки** значений выбирается в диалоге свойства («Формат записи значений»:
запятая/пробел/точка с запятой/новая строка) и хранится в `ConfigJson` рядом с опциями
(ключ `separator`; по умолчанию `comma`); применяется к показу и текстовому экспорту.
Экспорт: CSV/XLSX — значения через выбранный разделитель, JSON — массивом.
