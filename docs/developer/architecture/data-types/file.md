# Свойство: «Файл» (`file`)

Часть [реестра типов свойств](overview.md). Единый источник классификации — [`FieldTypeInfo`](../../../../Core/Models/FieldTypeInfo.cs).


**Ссылка на файл на диске, без копирования.** В `db_field_values` хранится **абсолютный путь
строкой, как есть** (без нормализации и относительных путей — чтобы не ломать пути между ОС).
Файл никуда не копируется, папок рядом с БД не создаётся. Один файл на ячейку. Миграции БД не
нужны — тип строковый.

## Показ (одинаково в таблице и на странице записи)

| Состояние | Что видно |
|---|---|
| Есть файл (путь ведёт к существующему файлу) | имя файла с расширением — **синяя подчёркнутая ссылка**; клик открывает файл штатным приложением ОС |
| Путь задан, но файла нет | `имя.ext — файл не найден` (серым) |
| Пусто | серое некликабельное `Выбрать файл…` |

Путь, созданный в одной ОС (`C:\…`), в другой (`/…`) не резолвится — это не ошибка данных,
просто показывается «файл не найден».

## Правка (по аналогии с типом «дата»)

Редактор — [`FileEditor`](../../../../Controls/Widgets/FileEditor.axaml.cs), общий для таблицы и
страницы записи (identical behavior):

- **Правая иконка-скрепка** (`IconFieldFile`, всегда кликабельна) — открывает системный выбор
  файла (`StorageProvider.OpenFilePickerAsync`), путь подставляется в значение.
- **Ручной ввод пути** — двойной клик по значению (или клик по «файл не найден») превращает
  показ в текстовое поле с полным путём; ввод/правка/очистка вручную. Коммит — Enter или уход
  фокуса; Escape отменяет.
- **Проверка при ручном вводе:** непустой путь без существующего файла → текст поля **красный** +
  плашка-уведомление [`ErrorBanner`](../../../../Controls/Widgets/ErrorBanner.axaml.cs)
  («Укажите путь и наименование файла»), которая держится, пока путь не станет верным или поле не
  покинут. После коммита неверный путь сохраняется и показывается как «файл не найден».
- **Имя файла** для показа (ссылка, «файл не найден», список значений фильтра, журнал изменений) —
  общий источник [`FileValue.DisplayName`](../../../../Core/Models/FileValue.cs): из пути берётся
  базовое имя, а значение, доставшееся от прежнего типа поля, показывается как есть. В журнале
  правок (`SetFieldValue` → `ChangeDetail`) «до → после» тоже сворачивается до имени файла, а не
  абсолютного пути.

Открытие файла — `Process.Start(UseShellExecute=true)` (делегирование ОС: `open`/ассоциация/
`xdg-open`). Иконка типа — скрепка `IconFieldFile` (реестр [`Icons.axaml`](../../../../Assets/Styles/Icons.axaml)),
используется в шапке колонки, диалоге свойства и на карточке записи.

## Авто-привязка файлов (по столбцу)

Поле «Файл» можно перевести в **авто-режим**: файл не выбирается вручную, а подбирается из папки
по совпадению имени. Правило хранится в ConfigJson —
[`FileAutoRule`](../../../../Core/Models/FileAutoRule.cs):
`{ "auto": { "sourceFieldId": N, "folder": "…", "format": "pdf" } }`.

- **Настройка** — в диалоге свойства (блок «Авто-привязка»): столбец-источник (**только поля
  типа `text`**), папка (системный выбор), формат (20 популярных + свой). Первый пункт списка
  источников — «Без авто-привязки» (обычный ручной режим).
- **Сопоставление:** для записи имя = `значение_столбца` + «.» + `формат`; ищется в папке
  **только верхний уровень, регистр учитывается, точное имя** (`Отчёт.pdf`). Нет файла или пустое
  значение источника → «файл не найден».
- **Материализация:** найденный путь **пишется в `db_field_values`**
  ([`ResolveAutoFileField`](../../../../Database/Repositories/ConstructorRepository.cs)) — поэтому
  фильтр/сортировка/поиск работают штатно. При включении правила прежние значения столбца
  **затираются** (с подтверждением в диалоге).
- **Пересчёт:** первичный проход — с окном прогресса, если долго (иначе без мелькания); правка
  столбца-источника пересчитывает файл записи реактивно (`SetFieldValue` →
  `ReactToSourceEditForAutoFile`) и **сразу обновляет файл-ячейку**: `SetFieldValue` возвращает
  побочные изменения (FieldId файл-поля → путь), а строка таблицы / панель записи применяют их к
  своему кешу и файл-редактору, не трогая редактируемое поле (каретка не сбивается). Изменения
  файлов в папке — по кнопке **«Обновить привязку»** в меню колонки. Фоновый большой проход —
  `ResolveAutoFileFieldAsync` (изолированное подключение). Значения источника **стримятся** сырым
  reader'ом (без EF-материализации всех строк — важно на миллионах); окно прогресса показывает
  **проценты** (чтение 0–90%, запись 90–100%) и кнопку **«Отмена»** (`CancellationToken`): при
  отмене транзакция откатывается, значения не меняются (статус `Cancelled`). Окно появляется
  только если операция долгая (маленькая коллекция — без мелькания).
- **Показ ячейки (read-only):** имя-ссылка (клик — открыть) / «файл не найден» / **«папка
  недоступна»** (папки нет или нет прав; клик — плашка «Папка недоступна»). Скрепки и ручного
  ввода в авто-режиме нет.
- **Не сделано на этом этапе:** подпапки, несколько форматов на столбец, слежение за папкой в
  реальном времени (только кнопка «Обновить привязку»).

## Смена типа

- «Файл» → «Текст»: путь остаётся строкой.
- «Текст» → «Файл»: строка трактуется как путь (существует — ссылка, нет — «файл не найден»).

## Осознанно не сделано

Копирование файлов в хранилище, несколько файлов на ячейку, превью изображений, фильтр по
расширениям, drag & drop — надстройки на будущее.
