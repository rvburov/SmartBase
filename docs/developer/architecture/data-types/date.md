# Свойство: «Дата» (`date`)

Часть [реестра типов свойств](overview.md). Единый источник классификации — [`FieldTypeInfo`](../../../../Core/Models/FieldTypeInfo.cs).


Каноническое значение — [`DateValue`](../../../../Core/Models/DateValue.cs). Покрывает **пять форм**: день
(`01.01.2026`), диапазон дней (`01.01.2026 - 03.01.2026`), дата+время (`03.01.2026 14:00`), время в дне
(`03.01.2026 14:00 - 15:00`), диапазон с временем.

- **Хранение** — ISO-канон `DateValue.ToStorage` (`2026-01-01`, диапазон через `/`, время через `T`),
  **показ** — `DateValue.ToDisplay` (`дд.MM.yyyy`).
- **«Весь день»** = значение без времени; конец дня фиксируется как `23:59` (`EndOfDay`).
- **Разбор** `DateValue.TryParse` — сначала ISO-канон хранилища, затем ручной ввод (regex: до двух дат
  `дд.MM.гггг` и до двух времён `чч:мм` в любом порядке). Неразбираемый ввод при смене типа остаётся как
  есть — «не дата» просто не проецируется, значение не теряется.
- **Календарь**: при флаге `IsCalStart=true` поле проецируется в календарь; таких полей-дат в коллекции
  может быть несколько, каждое непустое значение = отдельное событие (см. [«Где календарь»](#где-календарь)).
- Редактор — `DateEditor` (диапазоны, дата+время, «весь день»), один и тот же в таблице и панели.
