# Свойство: «Пользователь» (`user`)

Часть [реестра типов свойств](overview.md). Единый источник классификации — [`FieldTypeInfo`](../../../../Core/Models/FieldTypeInfo.cs).


Хранит строку-**имя** — снимок отображаемого имени (как `select`, значением, а не ссылкой на учётку).
Опции — `ConstructorRepository.GetUserOptions` (допущенные пользователи базы); новая запись по умолчанию
получает **текущего пользователя**. Редактор — `ComboBox`. Участвует в разделе «Задачи» через флаги поля
(см. [tasks/overview.md](../../features/tasks.md)):

- `IsTaskExec` — исполнитель; включает user-поле в раздел задач (задача = «запись × user-поле с непустым значением»);
- `IsTaskAssigner` — роль «Назначил» (тоже user-поле);
- `IsTaskStatus` — роль «Статус» (поле типа `status`; старые коллекции — `select`). «Назначил»/«Статус» авто-создаются при включении задач.
