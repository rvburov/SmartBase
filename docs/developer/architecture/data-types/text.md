# Свойство: «Текст» (`text`)

Часть [реестра типов свойств](overview.md). Единый источник классификации — [`FieldTypeInfo`](../../../../Core/Models/FieldTypeInfo.cs).


Хранится строкой как есть, без обработки. Редактор — `TextBox`. Ячейки однострочные; многострочный/
форматированный текст записи живёт не в свойстве, а в нижнем блоке панели записи (Markdown-описание).
