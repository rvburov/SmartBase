19.10.2026. Linux x64, .NET SDK 10.0.402, отладочная сборка. Замеры выполнены без
параллельной сборки и тестов. Они служат начальной оценкой, а не нормативом для других машин.

## Набор и результат

53 файла, 6 594 148 байт: официальные разделы NIST SP 800-63-3, C++ Core Guidelines,
правила оформления ядра Linux, руководство RISC-V и учебные PDF 2.0 от PDF Association.
RISC-V — большой настоящий технический документ; учебные PDF — дополнительные проверки
формата. Поддерживаемый разбор PDF ограничен первыми 300 страницами, как в приложении.
Исходники закреплены коммитами или версией выпуска; URL, размер и SHA-256 каждого файла
сохранены в [sources.json](library-calibration/sources.json). Сами чужие документы в репозиторий
не добавлены. Все файлы дали Ok или NoText; исключений разбора не было.

## Начальный порог

Прежние 100 мс и 600 документов опирались на синтетический набор. Для первого запуска
берется **1 с на документ**: прогретый большой PDF с записью FTS занимает около 0,7 с,
оценка округлена вверх. Окно подтверждения появляется с **60 документов**, то есть с
оценки в минуту. Мелкие текстовые разделы не должны занижать начальную оценку для библиотеки
больших PDF. Это сознательно консервативная настройка до собственного измерения.

После пяти документов разогрева и пяти измеренных очередь запоминает фактическую скорость
через `DocReadPace` и `LibrarySettings.RememberSpeed`; дальше подтверждение определяется по
этой скорости и минутной границе. Пользовательский замер имеет приоритет над начальной оценкой.
Сетевой диск, сканы и состав библиотеки могут дать другие результаты; набор не заявляется
репрезентативным для всех рабочих библиотек.

## Повторение

Загрузить файлы по манифесту в отдельную папку, сверяя SHA-256. Например, из корня репозитория:

```bash
python3 - <<'PY'
import hashlib, json, pathlib, urllib.request
root = pathlib.Path('/tmp/smartbase-official-docs')
root.mkdir(exist_ok=True)
manifest = pathlib.Path('docs/developer/architecture/performance/library-calibration/sources.json')
for item in json.loads(manifest.read_text()):
    data = urllib.request.urlopen(item['url']).read()
    assert hashlib.sha256(data).hexdigest() == item['sha256'], item['file']
    (root / item['file']).write_bytes(data)
PY
dotnet run --project Tests/Benchmarks -f net10.0 -- docread --dir /tmp/smartbase-official-docs --csv /tmp/official.csv
dotnet run --project Tests/Benchmarks -f net10.0 --no-build -- docread --count 10 --pages 2 --csv /tmp/synthetic.csv
```

Менять конфигурацию сборки между сравниваемыми запусками нельзя. Несуществующая или пустая
папка `--dir` возвращает код 1; готовые документы бенчмарк не изменяет. FTS создается во
временной папке и удаляется после замера. CSV можно сравнивать по файлу и номеру прохода.
