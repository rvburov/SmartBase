# Категории

## Назначение

Категории — это именованные цветные метки (например, «Работа», «Важное»),
хранящиеся в каждой БД. Цвет категории используется как акцент событий/записей.

## Где в коде

- Модель: [Category.cs](../../../Core/Models/Category.cs) (`Id`, `Name`, `Color`)
- Доступ: [CategoryRepository.cs](../../../Database/Repositories/CategoryRepository.cs)
- Таблица: `categories` в `database.db` (уникальный индекс по имени)
- Цвет «по умолчанию»: [EventColors.cs](../../../Core/Models/EventColors.cs)

## Как работает

### Категории по умолчанию

При открытии БД ([DatabaseManager](../../../Database/DatabaseManager.cs)) вызывается
`SeedDefaults()` — если таблица пуста, создаются восемь предустановленных категорий:

| Категория | Цвет |
|---|---|
| Работа | `#007AFF` |
| Личное | `#34C759` |
| Важное | `#FF3B30` |
| Документация | `#FF9500` |
| Производство | `#AF52DE` |
| Совещания | `#5AC8FA` |
| Контроль | `#FFCC00` |
| Праздники | `#FF2D55` |

### CRUD

`Add(name, color)` (имя уникально — дубликат вернет `null`), `Update(id, name, color)`
(тоже проверяет уникальность), `Delete(id)`, `GetAll()` (сортировка по имени),
`GetById`, `GetByName`.

### Цвет «без цвета»

[EventColors](../../../Core/Models/EventColors.cs) трактует дефолтный синий `#007AFF`
как «без цвета» и отображает его серым (`#8E8E93`) — единообразно с чекбоксами
сайдбара. Поэтому собственный цвет события виден только если он отличается от
дефолтного.
