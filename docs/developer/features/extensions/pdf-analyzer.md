# Расширение «Анализ PDF файлов»

Часть [обзора расширений](overview.md): устройство одного расширения. Общий механизм
(контракт, реестр, настройки, видимость) — там же.

## Назначение

По папке с PDF формирует Excel-отчет — ведомость или опись КД, ПД, ТД. Разбирает имена
файлов (номера КД/ПД/ТД по ГОСТ 2.201 / 19.101 / 19.103 плюс название), считает MD5, число и
форматы листов (по размерам страниц, допуск 30 мм), «листов формата А4» и объем.

> ⚠️ **Зависимости.** Это расширение добавляет в общий
> [SmartBase.csproj](../../../../SmartBase.csproj) пакет **PdfPig** (чтение PDF) и использует
> **ClosedXML** (Excel). То есть расширению, которому нужна внешняя библиотека, разрешено
> добавить NuGet-пакет в проект — в отличие от расширений, обходящихся контролами приложения.

## Как работает

### Разбор обозначений

[DocumentCodes.cs](../../../../Extensions/PdfAnalyzer/DocumentCodes.cs) держит справочники и
разбор: регэкспы извлечения номеров, базовый номер, полное наименование. В шапке класса —
шпаргалка по формированию децимального номера ТД/КД/ПД. Коды публичные, из ГОСТ, — не секрет.

**Суффиксы листов** `-ЛУ`/`-УЛ` собираются из типа основного документа и названия листа
(например `…СБ-ЛУ` → «Сборочный чертеж Лист утверждения») для **любого** кода; конкретные
комбинации с особым именем (`Д42-УЛ` = «Данные программирования…», `ТУ-ЛУ` и подобные)
остаются приоритетными исключениями.

**Тип программного документа (ПД)** определяется кодом вида документа — двузначным полем «ВВ»
номера `КОДО.РРРРР-ИИ ВВ ДД` по ГОСТ 19.101 (`PdVidCodes`). Номер без кода вида — сама
программа (`Спецификация`). Носители `…НД`/`…НДЗ` берут тип как коды из `KdNameMapping`.

### Прогон и отчет

Движок обходит папку (рекурсивно или локально), читает PDF через **PdfPig** (число страниц и
размеры), определяет форматы листов, поддерживает 3 режима сортировки и 6 типов выгрузки — КД
и ПД разведены полностью, у каждого своя ведомость и опись, отбор строк делает `ScopeRows`.
Отчет пишется в .xlsx на лист «ОПИСЬ» через ClosedXML со стилем (Times New Roman, границы,
ширины колонок); прогон отдает `IProgress` и слушает `CancellationToken`.

### Окно

Папка и файл отчета (`StorageProvider`), тип выгрузки (`ComboBox`), опции (рекурсия и
«сохранить порядок из папки» — взаимно исключающие; «наименование в несколько строк» —
**включено по умолчанию**), прогресс по файлам в фоне (`Task.Run`), по завершении —
статистика и предложение открыть папку.

### Наименование в несколько строк

Чекбокс «Наименование документа в несколько строк (изделие / тип / лист)» — флаг `splitName`
в `Run`. Он раскладывает наименование на части по строкам внутри ячейки через
`GetDocumentFullNameMultiline`; выключенный флаг дает одну строку (`GetDocumentFullName`,
поведение 1-в-1 с исходником). Высота строки в .xlsx подгоняется под число строк ячейки.

Влияет на выгрузки с наименованием — ведомость и опись КД, ведомость и опись ПД, «Все данные»;
в ТД наименование состоит только из изделия. Специальные комбинации (`ТУ-ЛУ` и подобные) тоже
разносятся: тип и лист разделяются по окончанию (`SplitSheetSuffix`).
