# Режим «Неделя»

## Назначение

Дни недели рядом — 7 (Пн–Вс) или 5 (Пн–Пт при пятидневке из настроек календаря), каждый —
вертикальная сетка часов, как в режиме «День». Сверху — общая полоса событий «весь день»
на всю неделю. Обычно окно выровнено на понедельник; режим прокрутки «по дню» сдвигает
его на день за клик (см. [overview.md](overview.md#настройки-календаря)).

## Где в коде

- View + логика: [WeekView.axaml.cs](../../../../Views/ConstructorDb/Calendar/WeekView.axaml.cs) (самый крупный из вью календаря)
- Полоса all-day — тот же общий виджет [AllDayBar](../../../../Controls/Components/) (`AllDayBarCtrl`), что и в «Дне»
- Данные: `WeekViewCtrl.Refresh(records, days, scrollToNow)`; список дней окна диктует
  контроллер (`CalendarControllerView.WeekDays()` — режим прокрутки, пятидневка,
  центрирование на «Сегодня»), сам вид понедельник не считает

## Как работает

Архитектурно «Неделя» — это «День», размноженный на **колонки дней** (`days.Count`,
7 или 5; `UniformGrid.Columns` шапки/линий/колонок ставится в `Refresh`). Подписи и
затенение выходных — по `DayOfWeek`, не по индексу колонки: окно «по дню» не выровнено
на понедельник. Все переводы «колонка → дата» (drag/resize released, hit-test) идут
через `CalendarMath.DayAtCol`: при пятидневке дни окна НЕ непрерывны, а за краями окна
экстраполяция идет видимыми днями (за пятницей — понедельник следующей недели).

- Те же метки часов (`HourLabels`, 01:00…23:00) и линия текущего времени (`_timeLineTimer` раз в минуту).
- События с временем позиционируются по минутам внутри своей колонки-дня; пересекающиеся события дня раскладываются по под-колонкам (не больше `MaxEventColumns` = 6 — сверх лимита не рисуются, см. [day.md](day.md)). Событие — один рисованный контрол `CalendarEventBlock`, как в «Дне»: неделя с днем-гигантом (1270 событий в день, видно около тысячи) строится за 0,2 с вместо 2,8 с.
- All-day и многодневные события уходят в `AllDayBarCtrl`, который растягивает бары на нужные дни недели; у полосы есть грип высоты (`AllDayResizeGrip`). Рисуется не больше `MaxRenderedEvents` (300) блоков, остальное — «+N еще» (см. [day.md](day.md)).
- Полос прокрутки **две**: у блока «весь день» своя (вместе с шапкой дней), у сетки времени своя — прокручиваются они независимо (см. [day.md](day.md), «Две полосы прокрутки»).
- Выделение хранится в `_selections` (множественное), drag/resize рисуют ghost-элементы.

Отличие от «Дня» — переключение даты идет шагом недели (`CalendarMath.StepWeekAnchor`:
по неделе / по дню / по неделе с остановкой на «Сегодня»), а события привязываются к
колонке нужного дня. Рабочие часы (если заданы) зажимают drag/создание и дают перескок
resize через границу дня — см. [overview.md](overview.md#настройки-календаря).

Операции (создание/изменение/удаление/дублирование, перенос и растяжение времени) — **на
месте** через снимок сетки (`TryApplyGridDelta`), без чтения окна и «Загрузка…»; полная
загрузка недели идет без карты счетчиков — как в «Дне» (см. [day.md](day.md)).

## Взаимодействия

Полностью совпадают с режимом «День», только в контексте 7 дней:

- **Клик по пустому слоту** → `TimeSlotCreationRequested(день + время)`.
- **Клик по полосе all-day** → `AllDayCreationRequested(день)`.
- **Перетаскивание** — перенос по времени и между днями → `RecordMoved`.
- **Ресайз** — длительность → `RecordMoved`.
- **Двойной клик** → `RecordClicked`.
- Выделение / удаление / контекстное меню — см. [interactions.md](interactions.md).

### События контрола

`RecordClicked`, `RecordMoved`, `RecordDeleteRequested`, `RecordsDeleteRequested`,
`RecordDuplicateRequested`, `AllDayCreationRequested`, `TimeSlotCreationRequested`.
