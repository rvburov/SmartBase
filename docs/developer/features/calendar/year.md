# Режим «Год»

## Назначение

Весь год — 12 мини-календарей (по месяцу). Дни с событиями подсвечены цветом,
интенсивность зависит от числа событий. Клик по числу показывает попап со списком
событий дня; двойной клик по месяцу открывает его в режиме «Месяц».

## Где в коде

- View + логика: [YearView.axaml.cs](../../../../Views/ConstructorDb/Calendar/YearView.axaml.cs)
- Данные: `YearViewCtrl.Refresh(records, year, dayTotals)`; диапазон — весь год (1 января … 1 января следующего)

## Как работает

### Счетчики дней и попап

Год (без поиска) **все события окна не читает** (см. `LoadGridAsync`): числам достаточно
карты счетчиков `dayTotals`, доезжающей **второй фазой**, — чтение всех событий года (сотни
тысяч строк, ~0.7–1.5 с) показывало оверлей «Загрузка…» при листании лет. Год открывается
мгновенно (числа без окраски), интенсивность дней тихо появляется по приходе карты. При
активном поиске события читаются как раньше — счетчики от найденного. `Refresh` считает
словарь «дата → количество» одним проходом по доставленному (+карта поверх); раскладка по
дням не хранится.

Исключение — **многодневные события**: карта считает событие по дню **НАЧАЛА**
(счет по дням начала, `GetCalendarDayCountsByRange`), поэтому запись «16.02.2026 – 26.01.2029» подсвечивала
одно число из своего диапазона вместо всех. Их Год читает отдельным запросом
(`GetCalendarSpanningRecords` — сик по EndIso-индексу, многодневность residual'ом
`substr(EndIso) <> substr(StartIso)` из того же индекса) и раскладывает по дням сам; таких
событий мало — это «проекты», а не рядовые встречи. Математика `Refresh` от этого не
меняется: она и рассчитана на ЧАСТИЧНУЮ доставку — `received` (по дню старта) вычитается из
карты, и остаток добавляется на день начала, поэтому события не удваиваются. Диапазон
обрезается показанным годом: три года иначе крутили бы тысячу дней ради 365. Контракт —
`Tests/Integration/CalendarWindowTests`. При пятидневке (настройка «Дней в неделе: 5»)
развертка многодневных пропускает Сб/Вс — выходные не подсвечиваются их диапазоном;
однодневные события выходных остаются (в Годе выходные дни видимы).

Попап дня грузится **по требованию** (`DayEventsProvider` — per-day capped-чтение сиками,
миллисекунды даже на дне-гиганте) и рисует не больше `PopupMaxEvents` (100) строк; скрытое
сверх лимита — строкой **«+N еще»** по карте счетчиков (день-гигант: «показаны первые 100»,
+N — миллионы). Второй строкой — **поиск по ВСЕМУ дню**: с дебаунсом 250 мс через
`DaySearchProvider` (фоновый SQL LIKE `SearchCalendarEventsAsync`, как в «Расписании») —
находит и то, что не показано; пустой запрос перечитывает день. Смотреть весь день —
«Расписание».

### Карточка месяца `BuildMonthCard`

- Один `UniformGrid` 7×7: строка заголовков дней недели (Пн–Вс) + 42 ячейки.
- `startOffset = ((int)firstDay.DayOfWeek + 6) % 7` — сдвиг к понедельнику.
- Каждая ячейка (`d = firstDay.AddDays(i - startOffset)`):
  - **Сегодня** — белое число в красном кружке 22×22.
  - **День с событиями** — число на цветном прямоугольнике; цвет/насыщенность по шкале `EventSteps` (4 ступени): 1 событие, 2–5, 6–8, 9+.
  - **Обычный день** — число; дни соседнего месяца серые (`#E5E5EA`), выходные — `#8E8E93`.

### Попап дня

Клик по числу текущего месяца открывает `DayPopup` (`ShowDayEvents`), привязанный
к ячейке: заголовок-дата + список событий (цветная полоска, заголовок, время или
«весь день»), отсортированных по времени. Пустой день — «Нет записей».

## Взаимодействия

- **Клик по числу** → попап со списком событий дня.
- **Двойной клик по карточке месяца** → `MonthSelected(1-е число месяца)` → контроллер переключается в режим «Месяц».

## Отрисовка

Месяц «Года» — один рисованный контрол [`YearMonthCard`](../../../../Views/ConstructorDb/Calendar/YearMonthCard.cs): название, дни недели, 42 числа с подсветкой по числу событий, кружок сегодняшнего дня. Раньше месяц собирался из ~140 контролов (1 650 на год), построение стоило 140–290 мс и повторялось по приходе чисел дней; теперь построение — миллисекунды, а числа дней обновляют уже построенные месяцы. Нажатие по числу открывает список дня под ячейкой (попап привязан к месяцу с прямоугольником ячейки), двойное нажатие по месяцу — переход в «Месяц». Кадры 2027 года (`Tests/Sections --only frames`, масштаб 1 и 2) совпадают с прежними строго (при масштабе 2 — два пикселя сглаживания).
