# Чеклист: навигация по строкам таблицы (нижняя панель)

Ручной прогон кнопок «‹‹ ‹ 10 – 50 из 125 437 › ››» в нижней панели конструктора:
индикатор видимых строк, шаг на экран, прыжки к краям, поведение при фильтре, ресайзе
и на большом объеме. Как устроено —
[features/constructor/table.md](../features/constructor/table.md#навигация-нижней-панели).

Автотестами (`TableViewportRangeTests`) закрыта **чистая логика**: текст индикатора,
гашение кнопок у краев, нормализация диапазона, арифметика шага полосы. Вручную
проверяется то, что тестами не берется: **раскладка DataGrid** — какие строки контрол
считает видимыми, и подтягивает ли виртуализация страницы после прыжка. Поведение
пришпилено к Avalonia 11.2.x двумя местами: прокрутка идет через internal
`ProcessVerticalScroll`, а строки, уехавшие за экран, но оставшиеся в дереве, отсеиваются
по непустому `Clip` (раздел 3а). **После апгрейда Avalonia чеклист прогнать целиком**:
молчаливый отказ рефлексии выглядит как «кнопки не нажимаются», а смена механики
переработки строк — как «числа врут после прыжка».

## Подготовка

- [ ] Коллекция «короткая»: записей меньше, чем влезает на экран (5–10).
- [ ] Коллекция «средняя»: 200–500 записей.
- [ ] Коллекция «большая»: 100 000+ записей (генератор — [testing/test-database.md](../testing/test-database.md)).
- [ ] Пустая коллекция (0 записей).

## 1. Индикатор

- [ ] «Средняя» коллекция, прокрутка в самом верху: показано `1 – N из <всего>`, где N —
  номер последней строки, которую видно целиком или частью.
- [ ] Числа совпадают с колонкой «№» первой и последней видимой строки.
- [ ] Разряды в «всего» отбиты пробелом (`125 437`), строка не переносится на две.
- [ ] Пустая коллекция: «Нет записей», все четыре кнопки погашены.
- [ ] «Короткая» коллекция (вся видна): диапазон `1 – N из N`, все четыре кнопки погашены.
- [ ] Число после «из» совпадает с фактическим числом записей коллекции (сверить с
  экспортом или `SELECT count(*)`): отдельного счетчика «Всего», по которому это
  сверялось раньше, в панели больше нет.
- [ ] В панели нет ничего, кроме навигации: ни кнопки «Фильтр», ни «Сортировка», ни
  надписи «Всего» — фильтр и сортировка вызываются из меню заголовка колонки.

## 2. Кнопки «‹» и «›» (экран)

- [ ] «›» из начала: первой видимой стала строка, следующая за последней видимой до нажатия
  (окно сдвинулось ровно на свою высоту, строки не перепрыгнуты и не показаны дважды).
- [ ] «‹» возвращает окно на прежнее место — индикатор показывает исходный диапазон.
- [ ] Повторные нажатия «›» доводят до конца и там останавливаются: диапазон упирается в
  `… – <всего>`, кнопки «›» и «››» гаснут.
- [ ] Обратно «‹» до самого верха: гаснут «‹‹» и «‹».
- [ ] Кнопки не «залипают»: после гашения нажатие соседней кнопки снова их зажигает.

## 3. Кнопки «‹‹» и «››» (края)

- [ ] «››» на «большой» коллекции: таблица мгновенно (без прокрутки-анимации) встает в
  конец, видна последняя запись и под ней строка «+».
- [ ] Строки в конце **прогружены** — не «Загрузка…»: виртуализация подтянула страницы
  новой позиции.
- [ ] «‹‹» возвращает в самое начало, видна строка №1.
- [ ] Прыжок в конец и обратно 5 раз подряд: индикатор каждый раз верный, таблица не
  оставляет пустых полос и не рисует чужие строки.

## 3а. Строка с фокусом и строка в правке (регрессия «529 – 647 584»)

Строку с фокусом и строку в режиме правки DataGrid **не перерабатывает**: уехав за экран,
она остается в дереве со старой раскладкой и старым номером (см.
[features/constructor/table.md](../features/constructor/table.md#строки-уехавшие-за-экран-но-оставшиеся-в-дереве)).
Без этих шагов раздел 3 проходит вслепую — **кликнуть по строке обязательно**.

- [ ] «Большая» коллекция: **кликнуть по строке** в середине (например, ~500-й), затем «››» —
  индикатор показывает номера ПОСЛЕДНЕГО экрана, а не «500 – <всего>».
- [ ] Оттуда «‹‹» — «1 – N», а не «1 – <большой номер>».
- [ ] То же колесом мыши: кликнуть по строке, прокрутить далеко вниз — в диапазоне нет
  номера строки, по которой кликали.
- [ ] Кликнуть по строке, увести фокус в сайдбар/панель записи, вернуться и прыгнуть — то же.
- [ ] **Начать правку ячейки** (двойной клик), не завершая ее прыгнуть «››» — индикатор
  показывает конец таблицы; вернуться «‹‹» — правка на месте.
- [ ] **Ручная высота строк** включена: после клика по строке и прыжка в конец полоски-
  «грипперы» стоят у границ ВИДИМЫХ строк, лишней полоски в пустом месте нет.

## 4. Согласованность с обычной прокруткой

- [ ] Прокрутка **колесом** — индикатор едет за ней вживую.
- [ ] Перетаскивание **ползунка** полосы — то же.
- [ ] **Ресайз окна** по высоте: диапазон стал шире/уже, «всего» не изменилось.
- [ ] Свернуть/развернуть **сайдбар** и панель записи — индикатор пересчитался.
- [ ] **Ручная высота строк**: сделать одну строку высокой (тянуть нижнюю границу) —
  число видимых строк уменьшилось, индикатор это отразил (счет идет по реальным строкам,
  а не делением на стандартную высоту).
- [ ] **Зум приложения** (100 % → 150 %): диапазон пересчитался, кнопки на месте.

## 5. Фильтр, сортировка, скрытые записи

- [ ] Включить фильтр колонки: «всего» стало числом отфильтрованных записей, нумерация
  идет с 1 (а не сохраняет исходные номера).
- [ ] «››» с фильтром: попадает в конец **отфильтрованного** списка.
- [ ] Снять фильтр — «всего» вернулось к полному числу.
- [ ] Сортировка по колонке: диапазон и прыжки работают в новом порядке.
- [ ] Окно «Отображение записей», часть записей скрыта: «всего» считает только видимые.

## 6. Изменения данных

- [ ] Создать запись (строка «+»): «всего» выросло, индикатор пересчитался.
- [ ] Удалить несколько записей из середины: «всего» уменьшилось, диапазон не показывает
  номера больше нового «всего».
- [ ] Удалить ВСЕ записи: «Нет записей», кнопки погашены.
- [ ] Дублировать запись, перенести запись в другую коллекцию — счетчик и индикатор верны.
- [ ] Правка ячейки не сбрасывает позицию прокрутки и диапазон.

## 7. Вид «Список» и переключение коллекций

- [ ] Переключить вид на «Список»: кнопки погашены, индикатор — «Нет записей».
- [ ] Вернуться в «Таблицу»: индикатор снова показывает диапазон.
- [ ] Переключение между коллекциями в сайдбаре: индикатор каждый раз про ТЕКУЩУЮ
  коллекцию, старые числа не мелькают.
- [ ] Коллекция не выбрана: нижняя панель скрыта целиком.

## 8. Производительность

- [ ] «Большая» коллекция: удерживать «›» нажатой (или быстро кликать 20 раз) — UI не
  подвисает, индикатор успевает.
- [ ] Прокрутка колесом на 100 000+ записей: индикатор не тормозит саму прокрутку
  (пересчет висит на `LayoutUpdated`, наверх уходит только изменение диапазона).
- [ ] Профиль → Диагностика: во время прогона в журнале нет исключений от таблицы.
