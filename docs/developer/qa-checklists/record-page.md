# Чеклист: страница записи — карточка «Название» и выделение свойств

Системное «Название» среди свойств панели записи: карточка, правка в нижнем блоке, живая
синхронизация с шапкой и таблицей, меню и клавиши; какие клики открывают свойство снизу и что
делает набор по Shift; «Без названия» как подсказка. Как устроено —
[features/constructor/record-page.md](../features/constructor/record-page.md) (разделы
«Заголовок», «Карточка «Название»» и «Выделение свойств»), для пользователя —
[record-page.md](../../user/record-page.md).

## Подготовка

- Коллекция с полем «Описание», еще одним текстовым свойством и полем-датой; запись с длинным
  названием (две-три строки при узкой панели).
- Запись, чье название пришло импортом с переводом строки (или вставлено в ячейку таблицы
  из многострочного текста).
- Новая запись без названия (кнопка «+» в таблице).

## 1. Карточка

- [ ] Открыть запись: среди свойств есть карточка «Название» с иконкой текста, в ней название
      записи; стоит там же, где колонка «Название» в таблице (по умолчанию первой).
- [ ] Нижний блок при открытии записи — по-прежнему «Описание».
- [ ] Колонку «Название» переименовать в таблице («Изменить») — подпись карточки и крошки
      поменялась сразу, без повторного открытия записи.
- [ ] Колонку «Название» сдвинуть в таблице — карточка встала на новое место.
- [ ] Многострочное название: в карточке первая строка, править ее там нельзя; снизу — полный
      текст.

## 2. Какой клик что открывает

- [ ] Клик по значению карточки «Название» — снизу «Свойство › Название», в редакторе название,
      карточка подсвечена, курсор в поле карточки.
- [ ] Клик по подписи «Название», по его иконке, по пустому месту карточки — снизу тоже
      «Название», карточка подсвечена, курсор ни в одном поле не мигает.
- [ ] То же с текстовым свойством и «Описанием»: подпись, иконка, пустое место — свойство снизу.
- [ ] Клик по ручке ⋮ — ничего не выделено и снизу ничего не сменилось.
- [ ] Клик по подписи даты — дата выделена, снизу осталось прежнее свойство.
- [ ] После клика по подписи текстового свойства Delete удаляет свойство (с подтверждением), а не
      букву.
- [ ] Открыть «Описание», Shift+клик по двум другим свойствам — выделены три, снизу по-прежнему
      «Описание». Shift+клик по «Описанию» — оно снято с выделения, снизу все еще «Описание».
- [ ] В наборе из нескольких свойств правый клик → «Удалить» / «Дублировать» / «Изменить цвет» —
      действие по всему набору; нижний блок при этом не прыгает.
- [ ] Набор из нескольких свойств, Shift+клик по «Названию» — выделено только «Название», снизу
      «Название».

## 3. Правка снизу

- [ ] Печать снизу: каждая буква сразу видна в шапке, в карточке и в строке таблицы; пробел в
      конце слова под курсором не пропадает.
- [ ] Enter снизу строку не добавляет; длинное название переносится по ширине.
- [ ] Вставить из буфера текст в две строки — осталась первая строка (в базе тоже).
- [ ] Стереть название целиком — в шапке серое «Без названия», карточка пустая с плейсхолдером,
      в таблице «Без названия».
- [ ] «Просмотр»: название «1. Позвонить» показано как есть, не списком; переключиться на
      «Описание» — Markdown оформлен как раньше, Enter снова переносит строку.
- [ ] После «Названия» кликнуть другое текстовое свойство — редактор переключился, название не
      изменилось.

## 4. Правка в шапке и в карточке

- [ ] Правка в шапке — сразу видна в карточке и (если открыто) в нижнем блоке.
- [ ] Правка прямо в карточке — сразу видна в шапке, в нижнем блоке и в таблице.
- [ ] Правка названия в ячейке таблицы — панель показывает новое везде; нижний блок, в котором
      сейчас печатают, не перетирается.

## 5. «Без названия» — подсказка

- [ ] Открыть запись без названия: в шапке серое «Без названия»; в карточке и снизу поле пустое,
      с той же серой подсказкой.
- [ ] Клик в шапку — поле пустое, печатать можно сразу; набранное видно в карточке и таблице.
- [ ] Стереть название в шапке или в карточке и уйти из поля — в базе (и в таблице, календаре,
      «Задачах») «Без названия».
- [ ] Окно события в календаре и окно задачи у записи без названия — поле «Название» пустое, с
      серой подсказкой «Без названия»; «Сохранить» с пустым полем не ругается, запись называется
      «Без названия».
- [ ] Новое событие или задача через окно с пустым названием — создана «Без названия».
- [ ] Название из импорта «Без названия 2» — обычный текст, не серое, в полях правится как есть.

## 6. Меню и клавиши

- [ ] Правый клик по карточке — меню: Изменить · Создать новое свойство · Отображение ·
      Изменить цвет · Сдвинуть вверх/вниз. Пунктов «Дублировать» и «Удалить» нет.
- [ ] «Изменить» открывает переименование подписи колонки; «Создать новое свойство» ставит
      новое свойство сразу после «Названия» (в таблице — справа от колонки).
- [ ] «Изменить цвет» красит колонку «Название» в таблице, текущий цвет отмечен в меню.
- [ ] У крайней позиции нет пункта сдвига в ту сторону; сдвиг меняет порядок и в таблице.
- [ ] Клик по подписи «Название» выделяет карточку; Delete и сочетание дубля ничего не делают;
      сочетания «изменить», «создать свойство» и сдвига работают как пункты меню.
- [ ] Выделить «Название», потом кликнуть подпись другого свойства — подсветка перешла, у
      «Названия» снялась.

## 7. Совместимость старых ограничений

- [ ] Старые маски прав не запрещают правку названия, создание и изменение свойств.
- [ ] Автоматические и вычисляемые значения сохраняют функциональный режим только чтения.
