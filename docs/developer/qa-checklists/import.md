# Чеклист: импорт таблиц

Проверка импорта во всех состояниях: форматы, ручные параметры и исключения, режимы
листов/папки, ошибки файлов, отмена, прогресс. Как устроено —
[features/import-export.md](../features/import-export/overview.md), производительность —
[architecture/performance.md](../architecture/performance/overview.md).

Автоматическая матрица (38 проверок той же логики) — `Tests/Benchmarks` (команда `import`)
(`dotnet run -c Release --project Tests/Benchmarks -- import`); вручную важнее всего визуальные и файловые
сценарии: разделы 5–10.

## 1. Форматы (тип «Стандартный»)

- [ ] .xlsx — обычный файл: заголовки в 1-й строке, данные со 2-й.
- [ ] .xlsm — файл с макросами (макросы игнорируются, данные читаются).
- [ ] .xlsb — двоичный Excel (наименее обкатанный формат — проверять на реальном файле).
- [ ] .xls — старый формат (Excel 97–2003).
- [ ] .csv — обычный файл.
- [ ] .json — массив объектов `[{...},{...}]`.
- [ ] .json — NDJSON (объект на строку, без массива).
- [ ] Описание под «Тип импорта» меняется при смене расширения в поле «Файл»
      (Excel / CSV / JSON / пусто — 4 разных текста).

## 2. Excel: содержимое

- [ ] Скрытые строки — попадают в импорт.
- [ ] Скрытые столбцы — попадают в импорт.
- [ ] Скрытый лист — импортируется (в режимах «все листы» и при указании имени вручную).
- [ ] Даты → `дд.мм.гггг`, дата+время → `дд.мм.гггг чч:мм`.
- [ ] Числа: целые, дробные, большие. Формат ячейки типа «%» или «₽» НЕ применяется —
      0,5 останется 0,5 (осознанный трейд-офф, см. import-export.md).
- [ ] Логические ячейки → TRUE/FALSE.
- [ ] Пустые ячейки названия → «Без названия 1», «Без названия 2»… (сквозная нумерация).
- [ ] Пустые строки в середине данных импортируются пустыми, хвостовые пустые —
      отбрасываются.
- [ ] Пустые столбцы в середине сохраняются как поля, за последним непустым —
      отбрасываются.
- [ ] Файл, открытый в этот момент в Excel, — импорт проходит (FileShare.ReadWrite).

## 3. CSV

- [ ] UTF-8 без BOM.
- [ ] UTF-8 с BOM.
- [ ] Windows-1251 (кириллица без BOM — автоопределение).
- [ ] Разделитель `;`.
- [ ] Разделитель — табуляция.
- [ ] Разделитель `,`.
- [ ] Кавычки: значение с разделителем внутри (`"а;б"`), с переносом строки внутри,
      экранированная кавычка `""`.
- [ ] Хвостовые пустые строки и столбцы отбрасываются.

## 4. JSON

- [ ] Разные наборы ключей у объектов → union полей в порядке первого появления,
      отсутствующие значения пустые.
- [ ] Ключ названия по приоритету: «Название» → `name` → `title` (без учета регистра) →
      первый ключ первого объекта — проверить каждый вариант.
- [ ] Вложенный объект/массив в значении → сырой JSON-текст в поле.
- [ ] `null` → пустая строка; числа и булевы → как текст.
- [ ] NDJSON с пустыми строками между объектами и пробелами в конце файла.

## 5. Ручной тип (только Excel)

- [ ] Лист по имени; пустое поле «Лист» → первый лист.
- [ ] Несуществующее имя листа → ошибка.
- [ ] Строка заголовков ≠ 1 (например, 3), строка данных ≠ 2 (например, 5).
- [ ] Столбец названия числом (3) и буквой (C) — результат одинаковый.
- [ ] Ручной тип + файл CSV/JSON → ошибка «только для Excel».

## 6. Исключения (ручной тип)

- [ ] Исключить столбцы: буквы `C, F`, числа `3, 6`, диапазон `4-9`,
      смешанно `4-9, 11, 14-28`.
- [ ] Исключить строки: одиночные, диапазоны, смешанно.
- [ ] Исключить листы по именам через запятую.
- [ ] Исключенная строка/столбец не влияет на границы и счетчики; заголовки читаются
      даже из исключенной строки.
- [ ] Столбец названия в исключениях → ошибка валидации в диалоге.
- [ ] Лист указан и в поле «Лист», и в «Исключить листы» → ошибка.
- [ ] Мусор в поле исключений (`abc`, `9-4`) → понятная ошибка валидации.

## 7. Режимы листов

- [ ] «Все листы в одну коллекцию»: разные заголовки на листах → union полей,
      совпадающие имена — в один столбец.
- [ ] «Все листы в одну» + исключенные листы — пропускаются; все исключены/пустые →
      ошибка.
- [ ] «Все листы в разные коллекции»: имена «{Название} — {Лист}»; если непустой лист
      один → просто базовое имя.
- [ ] Чекбоксы взаимоисключающие (отметка одного снимает другой).

## 8. Папка («Все файлы из папки»)

- [ ] Подпапки обходятся рекурсивно.
- [ ] Смешанные форматы в папке (xlsx + csv + json) — все импортируются.
- [ ] Посторонние файлы (.txt, .pdf) молча пропускаются.
- [ ] Имена коллекций = имена файлов; одинаковые имена в разных подпапках →
      уникализация «Имя (2)».
- [ ] Папка + ручной тип + «в разные коллекции» — Excel-файлы разворачиваются по листам.
- [ ] Пустая папка / папка без поддерживаемых файлов → ошибка.
- [ ] Битый файл в середине списка → предыдущие коллекции остаются, баннер: имя файла +
      «Импортировано коллекций до ошибки: N».
- [ ] Поле «Название коллекции» отключено, подсказка «Названия — из имен файлов».

## 9. Ошибки файлов

- [ ] Несуществующий путь → «Файл не найден…».
- [ ] Пустой файл (0 байт) → «Файл пустой…».
- [ ] Битый файл (переименовать .txt с мусором в .xlsx) → «поврежден или
      неподдерживаемый формат».
- [ ] Неподдерживаемое расширение → ошибка со списком доступных.
- [ ] Файл занят эксклюзивно → «занят другой программой». Имитация в PowerShell:
      `$f=[IO.File]::Open('путь','Open','Read','None')`, после теста `$f.Close()`.
- [ ] Нет прав → «Нет прав доступа…». Имитация: `icacls файл /deny "%USERNAME%:R"`,
      вернуть: `icacls файл /remove:d "%USERNAME%"`.
- [ ] Файл, скачанный из интернета (MOTW, «разблокировать»), — импортируется без
      вопросов.
- [ ] После любой ошибки: диалог переоткрыт с сохраненными полями, в БД нет
      коллекции-огрызка.

## 10. Отмена

- [ ] Отмена на фазе «Анализ файла…» — коллекция не создается.
- [ ] Отмена на фазе «Импорт записей…» — частичная коллекция удалена.
- [ ] Отмена при импорте папки после N готовых файлов — готовые коллекции остаются.
- [ ] После отмены диалог НЕ переоткрывается; кнопка гаснет, показывается «Отмена…».

## 11. Прогресс и результат

- [ ] Фазы «Анализ файла…» → «Импорт записей…»; при мультиимпорте «Файл N из M: имя».
- [ ] Окно прогресса не меняет позицию/размер скачками.
- [ ] Одна созданная коллекция → сразу открывается; несколько → раскрывается
      группа-родитель.
- [ ] Порядок колонок: Название → поля файла по порядку (колонки «Описание» импорт не заводит); число записей
      совпадает с файлом.
- [ ] Импорт в не-текущую БД и в конкретную группу («Расположение») — коллекция
      попадает куда указано.
- [ ] Кнопка «Отмена» НЕ появляется в других окнах прогресса
      (дублирование/удаление/перенос).

## 12. Объем (по желанию — уже замерено харнессом)

- [ ] CSV ~1 млн строк: память плоская, прогресс живой (эталон: ~2 мин).
- [ ] Повторный импорт того же файла → имя уникализируется, старая коллекция не тронута.
