# Текст не двигается при смене состояния

Проверка стандарта из [ui/theming.md](../ui/theming.md#текст-не-двигается-при-смене-состояния-стандарт):
клик по тексту не смещает его ни на пиксель.

**Чем этот прогон отличается от стенда.** Автоматический стенд
`dotnet run --project Tests/EditGeometry -f net10.0` меряет геометрию на настоящем шрифте и
масштабе 2 — он ловит расхождение боксов и отступов. Но он не видит того, что видит глаз:
реальный рендер глифов на вашем мониторе, сглаживание, поведение при зуме приложения и на
другой ОС. Стенд гоняем после каждой правки стилей, этот список — перед релизом и после правок
навбаров, ячеек таблицы, карточек записи и виджетов даты/файла.

Смотреть на текст, а не на рамку: поставить курсор мыши так, чтобы буква была прямо под ним, и
кликнуть — буква обязана остаться на месте. Дефект дает 1 физический пиксель, поэтому удобнее
сравнивать по скриншотам до/после клика.

## Названия (пара «надпись + поле»)

- [ ] Название коллекции в конструкторе: клик по тексту — не дергается ни вверх/вниз, ни вбок.
- [ ] Название записи в шапке карточки — то же.
- [ ] Название заметки — то же.
- [ ] ПУСТОЕ название (водяной знак «Без названия» / «Выберите коллекцию»): клик — подсказка и
      набираемый текст стоят на одной строке, первая буква появляется там, где была подсказка.
- [ ] Длинное название, не влезающее в шапку: при входе в правку строка не прокручивается к
      хвосту, каретка встает туда, куда кликнули (а не в конец, и текст не выделяется весь).
- [ ] Многострочное название (вставить имя с переносом через буфер): шапка не разъезжается.

## Ячейки таблицы

- [ ] Текстовая ячейка: первый клик — синяя рамка выделения; второй по той же ячейке —
      открывается правка, и рамка ОСТАЕТСЯ той же самой (не съезжает, не меняет размер).
- [ ] Текст в ячейке при этом не двигается ни по вертикали, ни по горизонтали.
- [ ] Ячейка «Ссылка» — то же.
- [ ] Ячейка «Число»: значение прижато вправо и в показе, и в правке; формат («1 234,50 ₽»,
      проценты) НЕ подменяется на сырое число при клике.
- [ ] Ячейка «Список»/«Статус»/«Пользователь»: значение не прыгает вверх при открытии
      редактора.
- [ ] Окрашенная ячейка (цвет строки/колонки/ячейки): при входе в правку не теряет заливку и
      цвет текста, не становится белой или серой.
- [ ] Плотность строк «компактная» (28): редактор не распирает строку.
- [ ] Многострочная ячейка: межстрочный шаг не изменился со времени прошлого релиза.

## Поля даты, времени, файла

- [ ] «Изменить задачу», поле «Начало»: клик в поле — дата не смещается вправо, иконка
      календаря не уезжает влево.
- [ ] «Новая запись» в календаре, «Начало»/«Конец» — то же.
- [ ] Строка быстрого добавления задачи, поле срока — то же; соседи по строке не разъезжаются.
- [ ] Клик по самой иконке календаря/часов (а не по тексту): текст на месте и при открытии
      попапа, и при его закрытии.
- [ ] Карточка «Файл» в записи: вход в правку не прокручивает путь к хвосту.
- [ ] Карточка «Дата» по высоте совпадает с соседними карточками.

## Масштаб и размер шрифта

- [ ] Зум приложения 70% и 130%: повторить по одному пункту из каждого блока выше.
- [ ] «Настройки → Размер шрифта» ±2: повторить по одному пункту из каждого блока выше
      (токены высоты строки пересчитываются на лету, без перезапуска).
- [ ] Windows (масштаб 125%/150%, другой системный шрифт): названия и ячейки таблицы.
