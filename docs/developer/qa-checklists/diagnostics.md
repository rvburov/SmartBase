# Чеклист: «Настройки → Диагностика»

Журнал приложения (`logs.db`, Serilog): таблица, панель деталей и выгрузка в CSV.
Устройство — [features/logging.md](../features/logging.md).

## 1. Таблица

- [ ] Раздел открывается из сайдбара настроек, заголовок «Диагностика»; в таблице
      колонки Время / Уровень / Сообщение / Ошибка, новые записи сверху.
- [ ] В шапке каждой колонки — иконка типа и шеврон; шеврон открывает окно фильтра
      и сортировки (значения с количеством, поиск, «Готово»), активная колонка
      помечается синей воронкой. Поведение окна — как в конструкторе, прогон —
      [filter-column.md](filter-column.md), п. 6.
- [ ] Отобрать «Уровень» = Предупреждение, открыть «Сообщение»: в списке только сообщения
      предупреждений. «От А до Я» по «Уровню» — по русским подписям: «Информация, Критическая,
      Отладка, Ошибка, Предупреждение», а не «Debug, Error, Information…»; при прокрутке через
      границу страницы строки не пропадают и не повторяются.
- [ ] Перезапустите приложение — в журнале появилась строка «Запуск SmartBase …»
      с версией и ОС.
- [ ] Если строк больше 200 — прокрутка к концу догружает следующую страницу без фриза.

## 2. Детали строки

- [ ] Клик по строке открывает справа панель «Детали» с карточками полей; клик
      по карточке показывает полное значение снизу, кнопка справа копирует его.
- [ ] Вид блока карточек — как в «Странице записи» конструктора: подложка серая,
      карточки белые, наведение чуть темнее белого (карточка не сливается с подложкой),
      выбранная — голубая с синей рамкой. Шапка «Детали» и текст снизу белые.
- [ ] Крестик закрывает панель и снимает выделение; повторный клик по строке
      открывает ее снова. Уход в другой раздел настроек тоже закрывает панель.
- [ ] Ручки: ширина панели, граница карточек и текста, ширина колонки названий.

## 3. Выгрузка в CSV

- [ ] В правом краю навбара есть кнопка со стрелкой, тултип «Выгрузить в CSV»;
      в других разделах настроек ее нет.
- [ ] Клик → окно: что выгружается, число строк, формат (CSV, UTF-8, «;»), упоминание
      фильтров; «Отмена» ничего не делает, «Подтвердить» открывает выбор файла.
- [ ] Отказ от выбора файла — ничего не создается, окон больше нет.
- [ ] Во время выгрузки видно прогресс: проценты, «N из M», через пару секунд —
      «осталось ≈ … мин»; в конце — сообщение с числом строк и путем к файлу.
- [ ] Файл открывается в Excel/Numbers без настроек: кириллица целая, колонки
      разделены, уровни по-русски («Информация», «Предупреждение»), время локальное
      с секундами, многострочный стектрейс не ломает разметку файла.
- [ ] Отфильтруйте по уровню (например Ошибка) и выгрузите — в файле только эти строки,
      их число совпадает с окном подтверждения.
- [ ] «Отмена» в прогрессе прекращает выгрузку, недописанный файл НЕ остается.
- [ ] Выберите существующий файл — система спрашивает о замене, после подтверждения
      файл перезаписан целиком (старого содержимого не осталось).
- [ ] Большой журнал (сотни тысяч строк): прогресс двигается, интерфейс отвечает,
      память приложения не растет лавинообразно.
- [ ] Отсортируйте по «Сообщение» и выгрузите — порядок в файле тот же, выгрузка
      не «висит» минутами.
- [ ] Пока идет подсчет строк, повторный клик по кнопке НЕ открывает второе окно.

## 4. Что попадает в журнал

Полный перечень — [features/logging.md → «Что логируется»](../features/logging.md#что-логируется).
Здесь — проверки, которые воспроизводятся руками.

- [ ] Запуск и выход: после перезапуска в журнале «Запуск SmartBase v…», а от прошлого сеанса —
      «Завершение SmartBase (закрытие окна): работало …, баз закрыто N». Выход из трея дает
      причину «выход из трея или Ctrl+Q».
- [ ] Монтирование: на каждую базу одна запись «База «…» открыта за N мс: sqlite, локальный
      путь …, журнал wal, файл …»; у базы в сетевой папке — «сетевой путь», «журнал delete»;
      у PostgreSQL — «сервер PostgreSQL» без строки подключения и пароля.
- [ ] Обновление схемы (открыть файл старой версии): в записи о монтировании есть «миграции
      … → … (N) за …». Раздутая локальная база: «База «…» сжата: X → Y за N мс».
- [ ] Отключить сетевую папку у смонтированной общей базы: «База «…» потеряна (связь
      потеряна)»; вернуть папку: «База «…» снова доступна через … (попытка N)».
- [ ] Первое открытие новой базы: «Пользователь … открыл базу … первым и стал ее
      администратором»; неверный пароль базы — предупреждение с именем пользователя.
- [ ] Импорт CSV: «Импорт «…»: N строк из … за N мс»; экспорт: «Экспорт «…»: N строк → …».
- [ ] Фоновый режим: включить тумблер — «Фоновый режим включен в настройках»; при
      запуске с включенным — «Фоновый режим включен: значок в трее создан…».
- [ ] Уведомления: «Служба уведомлений запущена: календарь вкл/выкл, …»; переключение
      любого из трех тумблеров дает запись.
- [ ] Медленно: открыть коллекцию на сотни тысяч записей по сети или отфильтровать ее —
      при превышении порога запись «Медленно: … — N мс при пороге M мс · база, коллекция».
      Быстрые операции записей не дают.
- [ ] Сторож: подержать UI-поток (например, долгая синхронная операция на большой базе) —
      после оттаивания «Интерфейс не отвечал N с — выполнялось: …»; перетаскивание окна за
      заголовок дольше 3 с дает запись уровня «Сведения» без операций, а не предупреждение.
- [ ] Расширения: запуск любого расширения и его ошибки в журнал НЕ попадают; только сбой
      самого открытия окна расширения («Расширение «…»: окно не создано»).
- [ ] Общая база по «локальному» пути (запуск автозапуском до восстановления сетевого диска или
      файл общей базы, открытый по локальному пути): предупреждение «путь … определен как
      локальный, но файл помечен как общий — открываю как сетевую», в записи о монтировании
      «сетевой путь» и «журнал delete», файлов `-wal`/`-shm` рядом с базой нет.
- [ ] Зависшая папка (отключить сеть у сервера, не выключая его, или подержать файл чужим
      процессом): «Монтирование «…» не начато: папка не ответила за 15 с», под именем базы
      «недоступна (папка не отвечает)», остальные базы открылись; закрыть окно — процесс
      завершается, в журнале «Завершение SmartBase … баз закрыто N из M — остальные не ответили
      за 15 с», повторный запуск открывает окно, а не молчит.
- [ ] Серия BUSY: подержать файл общей базы `BEGIN EXCLUSIVE` из стенда несколько минут —
      после пяти сигналов за десять минут одно предупреждение «отвечала BUSY 5 раз за 10 мин —
      сброс пула не помогает» и надпись «занята другим компьютером»; отпустить файл — через
      пару минут надпись снята с записью в журнале.
- [ ] Обновление при живом старом процессе: окно после перезапуска называет причину
      («предыдущий процесс SmartBase не завершился за минуту»), в журнале «Обновление не
      применилось (old-process)».

## 5. Резерв crash.log

- [ ] Заблокировать `logs.db` (открыть в DB Browser в режиме записи или сделать файл только для
      чтения) и вызвать любую запись: в `crash.log` появляется строка с пометкой `serilog` и
      причиной; не больше 20 таких строк за сеанс.
- [ ] Падение (например, из «Диагностики» разработчика) — запись и в `crash.log`
      (локальное время), и в журнале уровнем «Фатальная» (UTC).
