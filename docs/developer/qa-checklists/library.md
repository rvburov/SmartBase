# Библиотека документов — ручной прогон

Что проверять руками после правок раздела. Автотесты закрывают разметку ролей, страницы,
фильтр и кеш ([features/library.md](../features/library.md#тесты)); здесь — то, что видно
только на экране и на настоящих файлах.

## Подготовка

Папка с документами разных форматов: несколько PDF с текстовым слоем, один PDF-скан (без
текста), DOCX, XLSX, TXT в windows-1251, файл неподдержанного формата (например `.dwg`) и один
битый файл. Удобнее всего завести коллекцию расширением **«Документы в коллекцию»**.

- [ ] Стенд панели чтения: `dotnet run --project Tests/DocReader -f net10.0` — «Готово:
      расхождений нет», в сводке все разделы «в порядке». Он же идет в `./Tests/run-all.sh` и в CI,
      но после правок панели его стоит прогнать до ручной проверки: он дешевле.

## Подключение коллекции

- [ ] Свойство типа «Файл» → тумблер **«Добавить в библиотеку документов»** → сохранить.
      В коллекции появился столбец **«Тип документа»** типа «Список» и **без единого пункта** —
      виды документов заводит человек.
- [ ] Подтянуть существующий «Тип документа» со своими пунктами: пункты не изменились и не
      переставились, чужих не добавилось.
- [ ] Коллекция, где столбец «Тип документа» уже есть: при включении тумблера появилось окно
      подтягивания. **«Подтвердить»** — роль ушла на существующий столбец, второго не завелось.
- [ ] То же окно, **«Отменить»** — существующий столбец не тронут, завелся «Тип документа 2».
- [ ] Тумблер у свойства, названного «Тип документа», не включается: показана причина.
- [ ] Включить тумблер у ВТОРОГО файлового свойства — запись дает в ленте два документа,
      «Тип документа» по-прежнему один.
- [ ] Правый клик по коллекции в сайдбаре → **«Отображение свойств файла»**: галочки ставятся
      у нескольких столбцов одновременно (в отличие от «исполнителя» в задачах, где список
      гаснет). Поиск по свойствам работает.
- [ ] Там же есть строка **«(Выделить все)»**, как в «Отображении свойств даты»: отмечает и
      снимает найденное поиском подмножество, сама встает в галочку, когда отмечено все.
      Отключенную строку «Тип документа» она не трогает.
- [ ] Три подменю подряд — **«свойств даты»** (календарь), **«свойств исполнителя»** (задачи),
      **«свойств файла»** (библиотека) — выглядят одинаково: чекбоксы не прижаты к рамке
      карточки, полоса прокрутки прилегает к ее краю. Отличие ровно одно: у исполнителя нет
      строки «(Выделить все)» (исполнитель один).
- [ ] Коллекция с десятком файловых свойств: список прокручивается во всех трех подменю,
      карточка не растет выше стандартной высоты, полоса исчезает, когда мотать нечего.
- [ ] **Заглушка базы в боковой панели библиотеки** (база в очереди или недоступна — например,
      отключили сетевой диск): клик по ней объясняет, что с базой, как в конструкторе, а
      проценты подключения и «снова доступна» видны и в библиотеке.
- [ ] Сосед по общей базе завел коллекцию с файловым свойством — она появляется в боковой
      панели библиотеки без перезахода в раздел.

## Уход из раздела

- [ ] Снять тумблер — коллекция ушла из ленты, столбцы и значения на месте.
- [ ] Вернуть тумблер — все вернулось, лишних столбцов не появилось.
- [ ] Сменить тип свойства с «Файл» на «Текст» — окно предупредило о потере привязки; после
      сохранения коллекция ушла из раздела.
- [ ] Удалить файловое свойство — окно назвало последствие; коллекция ушла из раздела.
- [ ] Из двух файловых свойств удалить одно — коллекция осталась, документов стало вдвое меньше.

## Лента

- [ ] У каждой коллекции в сайдбаре есть **галочка** — панель выглядит ровно как в «Задачах» и
      «Календаре» (у групп и корней-БД галочки нет, у них шеврон).
- [ ] Клик по строке коллекции переключает галочку (а не «открывает» коллекцию).
- [ ] Снятые галочки переживают перезапуск и не влияют на те же коллекции в задачах и календаре.
- [ ] Галочки коллекций в сайдбаре меняют ленту; «Выключить все» очищает ее.
- [ ] **Чужая правка.** На другой машине к записи библиотечной коллекции общей базы прикрепили
      документ — через несколько секунд он появляется в открытой ленте с серой меткой «не
      прочитан» и учтен в подвале, без перезахода в раздел; лента не прыгает к началу.
- [ ] Настройка «Только подключенные коллекции» прячет коллекции без файлового свойства.
- [ ] Кнопка «+» в сайдбаре при включенной настройке: новая коллекция сразу видна и подключена.
- [ ] Карточка показывает название, коллекцию, базу и имя файла. У записи без названия
      заголовком стало имя файла (а не «Без названия»), и в подписи оно не повторяется.
- [ ] Во время чтения прокрутка ленты остается плавной — разбор PDF не дергает список.
- [ ] **«Открыть»** отдает файл системе; **«Прочитать»** и двойной клик открывают панель чтения
      справа (а НЕ чужую программу).
- [ ] Переименовать файл на диске мимо программы — карточка показывает красную плашку
      «файл не найден», обе кнопки действий погашены.
- [ ] Выделение: клик, Shift-клик, Ctrl+Shift-клик по диапазону.

## Плитка формата и метрики

- [ ] У PDF в плитке видна ШАПКА первой страницы (не весь лист в миниатюре), снизу красная
      лента «PDF» — светлая заливка и красная надпись, а не сплошная заливка.
- [ ] Вокруг всего документа — ОДНА рамка цветом формата: окошко и лента обведены вместе, а не
      каждое само по себе.
- [ ] **Выделить карточку** (клик): углы плитки остались скругленными, рамка видна на сером фоне
      выделения.
- [ ] Название с путем стоит у ВЕРХНЕГО края плитки, строка действий — у нижнего.
- [ ] DOCX — синяя «WORD», XLSX — зеленая «EXCEL», TXT/MD/CSV — серая «ТЕКСТ», прочее — свое
      расширение заглавными.
- [ ] Линии между окошком страницы и лентой НЕТ: заливка начинается прямо от листа.
- [ ] **Скан** (фотография листа, подписи, печати) — картинка ровная: ни наклона содержимого, ни
      черного клина снизу. Перекос дает не всякая страница, а лишь та, чья ширина после
      подгонки округляется вниз, — поэтому проверять на НЕСКОЛЬКИХ сканах, не на одном.
- [ ] **Альбомная страница** (чертеж, разворот, А3 боком) — миниатюра есть, а не серое окошко.
- [ ] Второй заход в раздел — картинки появляются сразу (кеш на диске).
- [ ] Настройка «Изображение документа» выключена — плитка ЦЕЛИКОМ в цвете формата, название
      по центру ее высоты, пустого окошка сверху нет. Высота плитки та же, что с миниатюрами:
      лента карточек при смене настройки не едет.

## Размер карточки

- [ ] «Настройки → Библиотека документов → Размер карточки»: три пункта, переключение сразу
      перестраивает ленту.
- [ ] Маленькая — одна строка найденного текста, средняя — три, большая — шесть. Проверять
      поиском по слову из середины длинного документа.
- [ ] Изображение документа растет вместе с карточкой, шапка страницы остается шапкой (не
      обрезком середины) на всех трех размерах.
- [ ] Надпись формата («PDF», «WORD») растет вместе с лентой и не выглядит потерянной на
      большой карточке. Длинное слово («EXCEL», редкое расширение) на маленькой не обрезано
      посреди буквы.
- [ ] На большом размере картинка не размыта.
- [ ] **Все карточки в ленте одной высоты** на каждом размере: и с найденным текстом, и без
      него, и с пропавшим файлом, и заглушки при быстрой прокрутке. Прокрутка не дергается.
- [ ] Прокрутили ленту к середине → «Настройки» → сменили размер карточки → вернулись: сверху
      тот же документ, что был до ухода. То же со сменой размера шрифта в «Оформлении» — и в
      выдаче поиска с цитатами, где карточка растет вместе со шрифтом.- [ ] Размер переживает перезапуск; «маленькая» не записывается в базу (это стандарт).
- [ ] «Оформление → Размер шрифта» +3 на маленьком размере: текст карточки не обрезан.
- [ ] Битый PDF не роняет ленту: у него серое окошко и лента формата.
- [ ] Справа от чипа типа виден размер файла; у прочитанных документов — еще и число страниц
      («4,2 МБ · 112 страниц»), у непрочитанных только размер.
- [ ] Серый чип «текст не прочитан» стоит у непрочитанных и исчезает после чтения.
      У сканов он меняется на «нет текстового слоя».

## Фоновые работы

- [ ] Пока ничего не идет, значка над профилем в панели разделов НЕТ.
- [ ] Во время чтения значок появился, кольцо вокруг него заполняется.
- [ ] Клик по значку открывает список работ; «Остановить» в нем прекращает чтение.
- [ ] Ушли из раздела при идущем чтении — значок остался, чтение продолжается.
- [ ] По окончании чтения значок исчез, а в правом верхнем углу появилась карточка с итогом.
- [ ] Закрытие программы во время чтения: окно закрывается сразу, а не ждет конца разбора.
- [ ] **Сбои заявляют о себе** — руками их не вызвать, проверяет стенд разделов
      (`dotnet run -c Release --project Tests/Sections -- --only libraryops --dbs main`): кеш, не
      принимающий запись, срывает чтение — кольцо красное, у значка красная точка, в списке работ
      красная строка с причиной и ссылкой «Убрать», которая гасит значок; сломанный индекс —
      подвал «Найдено N по названию. Поиск внутри текста не сработал…». Итог стенда — «Библиотека:
      все проверки прошли».

## Фильтр типов

- [ ] Кнопка «Тип документа» открывает чеклист с поиском, количествами справа и «Готово».
- [ ] Документы без типа собраны под «(Пусто)» и отмечаются.
- [ ] Снятие всех галочек дает пустую ленту (а не полную), подпись кнопки — «ничего».
- [ ] Количества совпадают с числом карточек после применения.

## Блок поиска

- [ ] Строка поиска стоит блоком НАД лентой (как строка быстрого добавления в задачах), в
      навбаре ее нет, при прокрутке ленты блок остается на месте.
- [ ] Слева в строке — лупа; при вводе она синеет вместе с рамкой блока.
- [ ] Синяя рамка при вводе ОДНА — у блока. У самого поля своей рамки нет ни при наведении,
      ни при вводе.
- [ ] Синяя рамка видна по всему периметру, в том числе в нижних углах: серый подвал и нить
      хода чтения на нее не наползают.
- [ ] Кнопка «Найти» погашена на пустом поле и горит при любом непустом запросе — в том числе
      уже выполненном: повторное нажатие перечитывает выдачу (например, после чтения
      документов). Enter делает то же, что кнопка.
- [ ] **Потолок поиска — на раздел.** Две-три базы с частым словом (замер `docfeed` строит
      такие): в ленте не больше 500 карточек суммарно, а не по 500 на базу; подвал пишет
      «показаны первые 500» только когда находок действительно больше. С фильтром типов,
      отсеивающим половину, подвал по-прежнему говорит об обрезке, если она есть.
- [ ] **Набранный текст ничего не запускает**: пока не нажали «Найти», лента прежняя.
- [ ] Крестик появляется при непустом запросе, чистит его и возвращает обычную ленту.
      Место под крестик занято всегда — кнопка «Найти» не прыгает.
- [ ] Подвал блока — ОДНА строка в любом состоянии, лента под ним не дергается.
- [ ] Слова подвала согласованы с числом: при одном непрочитанном — «1 документ не прочитан —
      внутри него…», при 21 — «21 документ не прочитан — внутри них…»; один скан — «скан без
      текстового слоя». То же в карточках о запуске и конце чтения.
- [ ] Библиотека прочитана почти вся, а запрос нашелся только по названию: подвал говорит о
      непрочитанных («10 документов не прочитаны — внутри них поиск не искал»), а не «внутри
      текста не искал».
- [ ] В навбаре нет переключателя вида, «Тип документа» стоит у правого края.

## Кнопка «Тип документа»

- [ ] Рядом положить любой обычный список (например «Список» в окне свойства): высота, рамка,
      скругление, отступ до текста и стрелка совпадают.
- [ ] Наведение — синеет ТОЛЬКО рамка; фон и текст не меняются, кнопка не темнеет при нажатии.
- [ ] Пока панель открыта, рамка кнопки остается синей; закрыли — вернулась серая.
- [ ] Между кнопкой и раскрытой панелью виден зазор, рамки не слиплись и тень панели не
      смазывает нижний угол кнопки.
- [ ] Правый край панели совпадает с правым краем кнопки. Если кажется, что не совпадает, —
      это тень попап-окна (ее на macOS не отключить); числа снимает `Tests/PopupGeometry`.
- [ ] Выбрали несколько типов — подпись стала «Тип документа: 3», но правый край кнопки
      остался на месте.

## Поиск

- [ ] Слово из НАЗВАНИЯ записи находит документ сразу, без сниппета.
- [ ] Слово, которого нет в названии, но есть ВНУТРИ PDF, находит документ со сниппетом и
      желтой подсветкой совпадения.
- [ ] Кириллица ищется в любом регистре.
- [ ] **База PostgreSQL:** латиница ищется в любом регистре — «gost» находит «GoSt» и в
      названии записи, и в имени файла, как на файловой базе.
- [ ] Поиск по префиксу: «автоматизир» находит «автоматизированных».
- [ ] Запрос со спецсимволами (`C++`, `ГОСТ-34.11`, кавычки) не роняет раздел.
- [ ] **Слово с пунктуацией внутри подсвечивается.** Документ с «ГОСТ 21.501» находится по
      «21.501» и по «21.5», и в панели чтения «21.501» желтое целиком; по «C++» желтая буква
      «C» (плюсы индекс не видит); «гост ++» находит и подсвечивает «гост».
- [ ] **Числа и даты книги ищутся так, как показаны.** Книга с датой «05.03.2024» и суммой
      «30 772,48» находится по «05.03.2024», по «30772», по «30772,48» и по «30 772»; в панели
      (и в «Тексте», и в таблице) найденное подсвечено.
- [ ] Дата словами (запись «Д ММММ ГГГГ» — «5 марта 2024») находится по «марта».
- [ ] PDF с суммой «30 772,48» находится по «30772», и в режиме «Как в документе» подсвечены
      ОБА слова суммы одним совпадением, счетчик «1 из 1».
- [ ] Файлы INI, JSON, XML, YML, YAML на плитке подписаны «ТЕКСТ», находятся по слову изнутри, и
      панель показывает их текст. После обновления программы встреченные раньше такие файлы
      один раз оказываются в непрочитанных.
- [ ] Строка форматов (пустая выдача поиска, панель чтения у чужого формата, «Настройки →
      Библиотека документов → Кеш») называет XLSM, LOG, INI, JSON, XML, YML и YAML.
- [ ] PDF-скан по содержимому не находится; пустая выдача объясняет, почему.
- [ ] Фильтр типов действует и при активном поиске.
- [ ] Очистка строки поиска возвращает обычную ленту.

## Панель чтения

- [ ] «Прочитать» открывает панель СПРАВА: лента сужается, между ними линия и ручка.
- [ ] Ручку можно тянуть; ширина переживает перезапуск и **не равна** ширине панели записи в
      конструкторе (проверить: сменить обе, перейти туда-обратно — каждая на своем месте).
- [ ] Toggle в верхней строке раздела закрывает панель и открывает ее снова НА ТОМ ЖЕ
      документе. Без единого читанного документа кнопка откатывается назад и ничего не открывает.
- [ ] Крестик в шапке панели закрывает ее; лента занимает всю ширину.
- [ ] Ушли в другой раздел и вернулись — панель на месте, с тем же документом.
- [ ] Нашли документ поиском по содержимому → «Прочитать»: панель открылась **на первом
      совпадении**, слово уже стоит в строке поиска панели, счетчик показывает «1 из N».
- [ ] Стрелки у счетчика ведут по совпадениям по кругу; текущее совпадение отличается цветом
      от остальных.
- [ ] Enter в строке поиска панели — следующее совпадение.
- [ ] Поменяли слово в строке панели — подсветка и счетчик пересчитались по новому слову.
- [ ] Новый поиск в ленте при открытой панели — подсветка в панели сменилась на новое слово.
- [ ] Документ с «ё» («учёт») находится и подсвечивается по «учет», и наоборот; запись с
      названием «Учёт…» находится по «учет» и в поиске по названию.
- [ ] «Й» и «и» различаются: по «мои» не находится и не подсвечивается «мой».
- [ ] Документ с «café» находится и подсвечивается по «cafe»; по «м²» в панели подсвечено
      только «м²», а не каждое слово на «м».
- [ ] PDF показан ПОСТРАНИЧНО с подписями «Страница N»; XLSX — по листам с подписью
      «Лист „…“»; DOCX и TXT — абзацами, и переводы строк НЕ склеены в одну строку.
- [ ] Текст строки выделяется мышью и копируется (Ctrl/Cmd+C).
- [ ] Скан без текстового слоя: вместо текста объяснение словами, а не пустая панель.
- [ ] **Обычный документ — строки «показано не все» НЕТ.**
- [ ] PDF толще 300 страниц: над текстом строка «Показаны страницы 1–300 из N» с отсылкой к
      «Открыть»; в режиме «Как в документе» — та же строка.
- [ ] Книга с листом длиннее 2 000 строк: строка называет лист и показанные строки («строки
      1–2 000 из N»); у листа шире 128 колонок — и колонки.
- [ ] **Книга со скрытым листом** (Excel → правый клик по корешку → «Скрыть»): ни в «Тексте», ни
      в таблице скрытого листа нет; строка говорит «В книге 1 скрытый лист…»; найденное поиском
      слово со скрытого листа в панели не подсвечено, и строка это объясняет.
- [ ] **Оба режима показывают одну книгу**: листы в «Тексте» идут в том же порядке, что корешки
      таблицы (проверить на книге, где лист перетащили мышью); скрытая строка не видна ни там,
      ни там; дата в «Тексте» — датой, а не числом.

### Режим «Как в документе»

- [ ] У PDF кнопка режима доступна; у DOCX и TXT — погашена, и при наведении на ПОГАШЕННУЮ
      кнопку подсказка видна и говорит почему: у текстового файла другого вида нет, у DOCX —
      «В режиме «Как в документе» показываются PDF и книги XLSX и XLSM, а DOCX — нет».
- [ ] У старой книги XLS подсказка называет XLS, а не «только PDF»; у битого XLSX — «Таблица
      этой книги не открылась», а не «В книге нет листов с данными».
- [ ] **Скан PDF:** в «Тексте» объяснение про скан → «Как в документе» — страница, надписи
      поверх нее нет → обратно в «Текст» — объяснение на месте, а не пустой список.
- [ ] **Том на сотни страниц:** перейти к страницам, пока над текстом еще «Читаю документ…»,
      шагнуть стрелкой к следующему совпадению — когда текст дочитается, позиция НЕ отскакивает
      к первому совпадению, а счетчик не начинает считать заново.
- [ ] Открыли документ из поиска → сразу «Как в документе» → «дальше»: через секунду позиция та
      же, счетчик не вернулся к «1 из N».
- [ ] Переключились: показаны НАСТОЯЩИЕ страницы на серой подложке, у каждой рамка.
- [ ] Найденные слова подсвечены **прямо на странице**, ровно поверх слов — не выше, не ниже
      и не на соседней строке (проверить и в шапке листа, и у нижнего края).
- [ ] Подсветка полупрозрачная: слово под ней читается.
- [ ] Стрелки у счетчика перелистывают панель к нужной странице; текущее совпадение отличается
      цветом.
- [ ] Прокрутка длинного PDF: страницы дорисовываются по ходу, список не дергается, ползунок не
      «дышит» (высота страницы известна заранее).
- [ ] Потянули ручку ширины: страницы перерисовались под новую ширину и остались четкими.
- [ ] Потянули ручку сразу после открытия большого PDF, пока страницы еще рисуются: ни одна не
      осталась растянутой и мутной.
- [ ] Документ на 200+ страниц: открытие не подвешивает интерфейс, память не растет
      бесконечно при прокрутке туда-обратно.
- [ ] Открыли том на 300 страниц и сразу, не дожидаясь, другой документ: новый показан без
      задержки, прежний в фоне не дочитывается.
- [ ] Слово есть только в конце длинного PDF: пока панель обходит страницы, счетчик пуст — не
      «нет» и не число прошлого слова, — потом «1 из N».
- [ ] Альбомный PDF (чертеж) показан альбомным.
- [ ] **Повернутый лист** (альбомный лист, сохраненный с поворотом, — чертеж А3, разворот):
      найденные слова подсвечены прямо на словах, как на книжном листе.
- [ ] **Надписи штампа на полях чертежа** («Инв. № подл.», «Подп. и дата»), идущие снизу вверх:
      поиск по слову из них находит его и на странице — счетчик тот же, что в «Тексте», подсветка
      стоит на надписи.
- [ ] Скан без текстового слоя в этом режиме ПОКАЗЫВАЕТСЯ (подсвечивать на нем нечего).
- [ ] Открыли другой документ — панель вернулась в режим «Текст».
- [ ] Расширение «Водяной знак» работает во время прокрутки библиотеки: обе стороны рисуют
      страницы через одну очередь, и ни одна не падает.

### Таблица Excel

- [ ] У XLSX кнопка «Как в документе» доступна и показывает ТАБЛИЦУ, а не страницы.
- [ ] Подпись выбранного режима ЧИТАЕТСЯ: «Как в документе» синим на белом, а не белым по
      белому. То же у корешка открытого листа.
- [ ] Ячейки стоят на своих местах: числа прижаты вправо, текст влево, колонки той ширины,
      что в самом файле.
- [ ] Сверху полоса с буквами колонок (A, B, C…), слева — с номерами строк. Номер совпадает с
      номером в самом Excel.
- [ ] Отступов у таблицы нет: сетка идет от самого края блока и сверху, и слева.
- [ ] Маленький лист (три строки, три колонки) занимает блок ЦЕЛИКОМ: справа и снизу дописаны
      пустые клетки со своими буквами и номерами, пустого белого места не осталось.
- [ ] Последняя строка и последняя колонка у края НЕ ужаты: они такой же величины, что и
      обычные, просто начаты — достать их дает полоса прокрутки.
- [ ] Обе полосы прокрутки на месте, а на их пересечении в правом нижнем углу — квадрат, а не
      белое пятно.
- [ ] Потянули ручку ширины панели — заполнитель пересчитался, пустого места снова нет, и
      прокрутка не прыгнула в начало.
- [ ] Увезли таблицу вбок: буквы едут вместе с колонками, полоса номеров ОСТАЕТСЯ на месте, и
      уехавшие ячейки не вылезают из-под нее.
- [ ] Ячейка с переносом текста («переносить по словам») показана НЕСКОЛЬКИМИ строками, строка
      под нее выше обычной, и буквы не обрезаны ни сверху, ни снизу.
- [ ] Ячейка с переводами строк внутри (Alt+Enter) показана в несколько строк.
- [ ] Строка, которой в книге задали свою высоту, выше обычной ровно настолько же.
- [ ] Выключка из книги соблюдена: прижатое к правому краю стоит справа, по центру — по центру.
- [ ] Пустая строка между данными осталась пустой строкой: номера строк не сбились.
- [ ] Скрытые в книге строка и колонка НЕ показываются.
- [ ] Объединенная шапка идет во всю ширину объединения, и линии сетки сквозь нее не лезут.
- [ ] Объединили две соседние ячейки в книге (A1 и B1) — в панели между ними НЕТ линии, это одна
      клетка.
- [ ] Объединение ВНИЗ (например C4:D8): линий внутри нет ни по вертикали, ни по горизонтали,
      рамка идет вокруг всего куска, а текст стоит ПОСЕРЕДИНЕ куска, а не в первой строке.
- [ ] Объединение, уходящее ниже последней заполненной строки: кусок показан целиком, а не
      обрезан по последней строке с данными.
- [ ] Прокрутка через большое объединение: текст в нем не дрожит и не двоится.
- [ ] Большая книга (несколько листов по 2 000 строк): правка слова в строке поиска панели не
      подвешивает интерфейс; пока книга обходится, счетчик пуст, потом показывает итог по всей
      книге.

### Оформление ячеек

- [ ] Заливка ячеек на месте, и на залитой ячейке линий сетки НЕ видно — как в Excel.
- [ ] Жирный, курсив, зачеркивание, цвет и размер шрифта — те же, что в книге.
- [ ] Рамки ячеек нарисованы поверх сетки; толстая рамка толще тонкой, пунктир пунктирный.
- [ ] Книга из Numbers (или любая со своей палитрой): линии СЕРЫЕ, а не красно-зеленые. Это
      проверка того, что палитра берется из самой книги, а не стандартная.
- [ ] Книга с цветами темы и осветлением: бледная шапка осталась своего оттенка, а не ушла
      в серый.
- [ ] Темная тема: ячейки без своего цвета читаются, черным по черному ничего не пропало.

### Числа в ячейках

- [ ] Дата показана датой («05.03.2024»), а не числом («45356»). Проверить и на своем формате
      ячейки, и на встроенном.
- [ ] Денежная колонка показана с разрядами и знаком валюты: «30 772,48 ₽», а не «30772,48».
- [ ] Проценты показаны процентами: «15 %», а не «0,15».
- [ ] Отрицательные в формате с «[Red]» показаны красными и со своими скобками.
- [ ] Дата и время — по СВОЕЙ записи: «Д ММММ ГГГГ» — «5 марта 2024», «ММ.ГГ» — без дня,
      «чч:мм:сс» — с секундами, «[ч]:мм» у полутора суток — «36:00».
- [ ] Книга, сохраненная со счетом дат от 1904 года (параметр книги «система дат 1904»): даты
      те же, что в самой книге, а не на четыре года раньше.
- [ ] Число в дробном формате («# ?/?») показано обычным числом («3,5»), а не обрывком «4 /».
- [ ] Код, который вернула формула, с нулями впереди («00123») показан с нулями.
- [ ] Книга с несколькими листами: корешки листов сверху, переключение работает. У книги с
      ОДНИМ листом полоса стоит на месте и показывает имя этого листа.
- [ ] Полоса корешков прижата к краям блока: полей вокруг нее нет, слева она начинается там же,
      где полоса номеров строк, справа доходит до края.
- [ ] Между корешками короткая линия — не во всю высоту полосы.
- [ ] Книга на полтора десятка листов: подписи уезжают под стрелки, стрелки листают книгу, а
      открытый лист полоса подвозит к глазам сама.
- [ ] Стрелки гаснут на краях книги, но не пропадают: ширина полосы от листа к листу не скачет.
- [ ] Счетчик считает по ВСЕЙ книге: стрелка «дальше» и Enter сами открывают нужный лист.
- [ ] Найденное подсвечено ячейкой целиком; текущее совпадение отличается цветом.
- [ ] Совпадение в дальней колонке (скажем, в J при видимых A–F): панель увозит таблицу ВБОК
      к нему, а не только вниз. Ячейка не прячется под полосой номеров строк и не упирается
      в край окна.
- [ ] Совпадение уже на виду — панель НЕ дергается: место, на котором стоял человек, остается.
- [ ] Книга на полтора десятка листов разной высоты: пожать Enter десяток раз подряд, переходя с
      листа на лист. На экране ТОЛЬКО строки открытого листа — ни строк прошлого поверх нынешних,
      ни двух строк на одном месте, ни пропавших строк.
- [ ] Широкая таблица: горизонтальная полоса внизу дает достать правые колонки.
- [ ] Лист на тысячу строк прокручивается плавно, полоса номеров при этом не мигает.
- [ ] Файл переименовали мимо программы и открыли панель — сказано, что файла нет на диске.
- [ ] Большой PDF (сотни страниц): панель показывает «Читаю документ…», интерфейс не замирает,
      прокрутка после загрузки плавная.
- [ ] Открыли один документ, тут же другой — показан ВТОРОЙ (ответ первого разбора не
      перерисовывает панель).
- [ ] Зум приложения 110 % и увеличенный шрифт: текст панели и подсветка не разъезжаются.

## Чтение документов

- [ ] Первый заход в раздел на большой папке: **чтение НЕ начинается само**. В подвале написано,
      сколько документов не прочитано, и стоит «Прочитать документы».
- [ ] Нажали — пошло чтение: подвал пишет «Читаю документы: N из M», по нижней кромке блока
      идет нить, отдельной плашки под блоком НЕТ.
- [ ] Через несколько документов в подвале появляется «осталось около …» — и это замер, а не
      круглое число.
- [ ] **«Остановить»** прекращает чтение; повторный запуск продолжает с того же места, а не с нуля.
- [ ] Больших объемов: перед чтением появилось окно подтверждения с числом документов.
      «Отмена» — ничего не началось.
- [ ] Правый клик по коллекции в сайдбаре → **«Прочитать документы»** читает только ее.
- [ ] То же **во время чтения**: карточка говорит, сколько документов добавлено (или что они
      уже в очереди), счетчик в подвале не сбрасывается на ноль, и добавленные документы
      дочитываются в том же прогоне.
- [ ] **«Остановить», сразу «Прочитать документы»** — чтение начинается заново, а не пропадает
      молча.
- [ ] Правка документа на диске (изменился размер) — он снова считается непрочитанным, и после
      чтения поиск находит по новому тексту, а не по старому.
- [ ] **После обновления программы** уже прочитанные книги (XLSX) один раз считаются
      непрочитанными: подвал предлагает «Прочитать остальные», а PDF и DOCX остаются
      прочитанными. До перечитывания поиск находит книги по словам, после — и по датам и
      суммам так, как они показаны.
- [ ] Порог размера: файл тяжелее порога не читается.
- [ ] В «Настройках → Библиотека документов» НЕТ тумблера «Индексировать текст документов» и
      строк про виды.
- [ ] **Настройки → Библиотека документов → Кеш документов**: числа сходятся с тем, что в
      папке; «Очистить» спрашивает подтверждение, после него поиск по содержимому пуст, а
      в подвале снова появилось «Прочитать документы». Окно подтверждения говорит про кнопку
      в разделе, а не про «следующий заход в раздел».
- [ ] **«Очистить» во время чтения**: окно не замирает, на время очистки кнопка погашена и
      стоит «Очищаю кеш…», после нее сводка показывает нули — ни одного «недоочищенного»
      документа не осталось.
- [ ] **Уборка сирот**: прочитать документы, затем удалить два-три файла с диска (или
      переименовать их), перезапустить программу и зайти в библиотеку. После переписи сводка
      кеша в настройках показывает на столько же меньше разобранных, а в «Диагностике» есть
      запись «убрано сирот». Поиск по содержимому остальных документов работает как раньше.
- [ ] **Общая папка недоступна** (выключен сервер или отключен диск): зайти в раздел и
      перезапустить программу — сводка кеша НЕ обнулилась, ничего не убрано. После возврата
      папки поиск по содержимому работает без повторного чтения.
- [ ] **Поврежденный кеш**: закрыть программу, записать в `docs_index.db` мусор (например
      `cmd /c echo сломано> docs_index.db`), открыть программу — в «Настройках» сводка кеша
      обычная (файл пересоздан), поиск по содержимому работает после повторного чтения.
      Если сводка все же говорит «кеш не открылся», кнопка «Очистить» не погашена и открывает
      кеш заново.

## Производительность

Стенд строит замер ленты: `dotnet run -c Release --project Tests/Benchmarks -- docfeed --docs
500000 --files 20000 --db ~/TestData/docfeed.db` — база с четырьмя коллекциями, где поле «Файл»
включено в раздел, и 20 000 настоящих файлов рядом. Базу подключить в программе. Стенд
`perf_main.db` для раздела не годится: ни один его профиль не включает поле в библиотеку.

- [ ] Открытие раздела не фризит окно; строка «Собираю ленту…» в подвале появляется не раньше
      400 мс, а прежняя лента остается на экране.
- [ ] Прокрутка ленты плавная, карточки-заглушки оживают на месте, лента не дергается.
- [ ] Прыжок ползунком в конец и обратно не роняет раздел и не оставляет пустых строк.
- [ ] Переключение галочек коллекций и типов не заставляет ждать.
- [ ] Возврат в раздел после правки в конструкторе перечитывает ленту тихо, без волны
      «Загрузка…» и с сохранением места прокрутки.
- [ ] Документы на сетевой папке: прокрутка не встает на каждой новой странице, серые чипы и
      плашка «файл не найден» приезжают вместе с карточкой, а не после нее.
- [ ] Библиотека, где еще ничего не прочитано: серый чип «текст не прочитан» виден сразу, не
      дожидаясь первого чтения.
