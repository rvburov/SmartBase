# Библиотека документов — ручной прогон

Что проверять руками после правок раздела. Автотесты закрывают разметку ролей, страницы,
фильтр и кеш ([features/library.md](../features/library.md#тесты)); здесь — то, что видно
только на экране и на настоящих файлах.

## Подготовка

Папка с документами разных форматов: несколько PDF с текстовым слоем, один PDF-скан (без
текста), DOCX, XLSX, TXT в windows-1251, файл неподдержанного формата (например `.dwg`) и один
битый файл. Удобнее всего завести коллекцию расширением **«Документы в коллекцию»**.

## Подключение коллекции

- [ ] Свойство типа «Файл» → тумблер **«Добавить в библиотеку документов»** → сохранить.
      В коллекции появился столбец **«Тип документа»** типа «Список» и **без единого пункта** —
      виды документов заводит человек.
- [ ] Подтянуть существующий «Тип документа» со своими пунктами: пункты не изменились и не
      переставились, чужих не добавилось.
- [ ] Коллекция, где столбец «Тип документа» уже есть: при включении тумблера появилось окно
      подтягивания. **«Подтвердить»** — роль ушла на существующий столбец, второго не завелось.
- [ ] То же окно, **«Отменить»** — существующий столбец не тронут, завелся «Тип документа 2».
- [ ] Тумблер у свойства, названного «Тип документа», не включается: показана причина.
- [ ] Включить тумблер у ВТОРОГО файлового свойства — запись дает в ленте два документа,
      «Тип документа» по-прежнему один.
- [ ] Правый клик по коллекции в сайдбаре → **«Отображение свойств файла»**: галочки ставятся
      у нескольких столбцов одновременно (в отличие от «исполнителя» в задачах, где список
      гаснет). Поиск по свойствам работает.
- [ ] Там же есть строка **«(Выделить все)»**, как в «Отображении свойств даты»: отмечает и
      снимает найденное поиском подмножество, сама встает в галочку, когда отмечено все.
      Отключенную строку «Тип документа» она не трогает.
- [ ] Три подменю подряд — **«свойств даты»** (календарь), **«свойств исполнителя»** (задачи),
      **«свойств файла»** (библиотека) — выглядят одинаково: чекбоксы не прижаты к рамке
      карточки, полоса прокрутки прилегает к ее краю. Отличие ровно одно: у исполнителя нет
      строки «(Выделить все)» (исполнитель один).
- [ ] Коллекция с десятком файловых свойств: список прокручивается во всех трех подменю,
      карточка не растет выше стандартной высоты, полоса исчезает, когда мотать нечего.

## Уход из раздела

- [ ] Снять тумблер — коллекция ушла из ленты, столбцы и значения на месте.
- [ ] Вернуть тумблер — все вернулось, лишних столбцов не появилось.
- [ ] Сменить тип свойства с «Файл» на «Текст» — окно предупредило о потере привязки; после
      сохранения коллекция ушла из раздела.
- [ ] Удалить файловое свойство — окно назвало последствие; коллекция ушла из раздела.
- [ ] Из двух файловых свойств удалить одно — коллекция осталась, документов стало вдвое меньше.

## Лента

- [ ] У каждой коллекции в сайдбаре есть **галочка** — панель выглядит ровно как в «Задачах» и
      «Календаре» (у групп и корней-БД галочки нет, у них шеврон).
- [ ] Клик по строке коллекции переключает галочку (а не «открывает» коллекцию).
- [ ] Снятые галочки переживают перезапуск и не влияют на те же коллекции в задачах и календаре.
- [ ] Галочки коллекций в сайдбаре меняют ленту; «Выключить все» очищает ее.
- [ ] Настройка «Только подключенные коллекции» прячет коллекции без файлового свойства.
- [ ] Кнопка «+» в сайдбаре при включенной настройке: новая коллекция сразу видна и подключена.
- [ ] Карточка показывает название, коллекцию, базу и имя файла. У записи без названия
      заголовком стало имя файла (а не «Без названия»), и в подписи оно не повторяется.
- [ ] Во время чтения прокрутка ленты остается плавной — разбор PDF не дергает список.
- [ ] **«Прочитать документ»** и двойной клик открывают файл системой.
- [ ] Переименовать файл на диске мимо программы — карточка показывает красную плашку
      «файл не найден», «Прочитать документ» скрыто.
- [ ] Выделение: клик, Shift-клик, Ctrl+Shift-клик по диапазону.

## Плитка формата и метрики

- [ ] У PDF в плитке видна ШАПКА первой страницы (не весь лист в миниатюре), снизу красная
      лента «PDF» — светлая заливка и красная надпись, а не сплошная заливка.
- [ ] Вокруг всего документа — ОДНА рамка цветом формата: окошко и лента обведены вместе, а не
      каждое само по себе.
- [ ] **Выделить карточку** (клик): углы плитки остались скругленными, рамка видна на сером фоне
      выделения.
- [ ] Название с путем стоит у ВЕРХНЕГО края плитки, «Прочитать документ» — у нижнего.
- [ ] DOCX — синяя «WORD», XLSX — зеленая «EXCEL», TXT/MD/CSV — серая «ТЕКСТ», прочее — свое
      расширение заглавными.
- [ ] Линии между окошком страницы и лентой НЕТ: заливка начинается прямо от листа.
- [ ] **Скан** (фотография листа, подписи, печати) — картинка ровная: ни наклона содержимого, ни
      черного клина снизу. Перекос дает не всякая страница, а лишь та, чья ширина после
      подгонки округляется вниз, — поэтому проверять на НЕСКОЛЬКИХ сканах, не на одном.
- [ ] **Альбомная страница** (чертеж, разворот, А3 боком) — миниатюра есть, а не серое окошко.
- [ ] Второй заход в раздел — картинки появляются сразу (кеш на диске).
- [ ] Настройка «Изображение документа» выключена — плитка ЦЕЛИКОМ в цвете формата, название
      по центру ее высоты, пустого окошка сверху нет. Высота плитки та же, что с миниатюрами:
      лента карточек при смене настройки не едет.

## Размер карточки

- [ ] «Настройки → Библиотека документов → Размер карточки»: три пункта, переключение сразу
      перестраивает ленту.
- [ ] Маленькая — одна строка найденного текста, средняя — три, большая — шесть. Проверять
      поиском по слову из середины длинного документа.
- [ ] Изображение документа растет вместе с карточкой, шапка страницы остается шапкой (не
      обрезком середины) на всех трех размерах.
- [ ] Надпись формата («PDF», «WORD») растет вместе с лентой и не выглядит потерянной на
      большой карточке. Длинное слово («EXCEL», редкое расширение) на маленькой не обрезано
      посреди буквы.
- [ ] На большом размере картинка не размыта.
- [ ] **Все карточки в ленте одной высоты** на каждом размере: и с найденным текстом, и без
      него, и с пропавшим файлом, и заглушки при быстрой прокрутке. Прокрутка не дергается.
- [ ] После смены размера лента показана с начала (прокрутка не «уехала» на чужой документ).
- [ ] Размер переживает перезапуск; «средняя» не записывается в базу (это стандарт).
- [ ] «Оформление → Размер шрифта» +3 на маленьком размере: текст карточки не обрезан.
- [ ] Битый PDF не роняет ленту: у него серое окошко и лента формата.
- [ ] Справа от чипа типа виден размер файла; у прочитанных документов — еще и число страниц
      («4,2 МБ · 112 страниц»), у непрочитанных только размер.
- [ ] Серый чип «текст не прочитан» стоит у непрочитанных и исчезает после чтения.
      У сканов он меняется на «нет текстового слоя».

## Фоновые работы

- [ ] Пока ничего не идет, значка над профилем в панели разделов НЕТ.
- [ ] Во время чтения значок появился, кольцо вокруг него заполняется.
- [ ] Клик по значку открывает список работ; «Остановить» в нем прекращает чтение.
- [ ] Ушли из раздела при идущем чтении — значок остался, чтение продолжается.
- [ ] По окончании чтения значок исчез, а в правом верхнем углу появилась карточка с итогом.
- [ ] Закрытие программы во время чтения: окно закрывается сразу, а не ждет конца разбора.

## Фильтр типов

- [ ] Кнопка «Тип документа» открывает чеклист с поиском, количествами справа и «Готово».
- [ ] Документы без типа собраны под «(Пусто)» и отмечаются.
- [ ] Снятие всех галочек дает пустую ленту (а не полную), подпись кнопки — «ничего».
- [ ] Количества совпадают с числом карточек после применения.

## Блок поиска

- [ ] Строка поиска стоит блоком НАД лентой (как строка быстрого добавления в задачах), в
      навбаре ее нет, при прокрутке ленты блок остается на месте.
- [ ] Слева в строке — лупа; при вводе она синеет вместе с рамкой блока.
- [ ] Синяя рамка при вводе ОДНА — у блока. У самого поля своей рамки нет ни при наведении,
      ни при вводе.
- [ ] Синяя рамка видна по всему периметру, в том числе в нижних углах: серый подвал и нить
      хода чтения на нее не наползают.
- [ ] Кнопка «Найти» погашена на пустом поле, загорается при вводе и гаснет снова, когда запрос
      выполнен. Enter делает то же, что кнопка.
- [ ] **Набранный текст ничего не запускает**: пока не нажали «Найти», лента прежняя.
- [ ] Крестик появляется при непустом запросе, чистит его и возвращает обычную ленту.
      Место под крестик занято всегда — кнопка «Найти» не прыгает.
- [ ] Подвал блока — ОДНА строка в любом состоянии, лента под ним не дергается.
- [ ] В навбаре нет переключателя вида, «Тип документа» стоит у правого края.

## Кнопка «Тип документа»

- [ ] Рядом положить любой обычный список (например «Список» в окне свойства): высота, рамка,
      скругление, отступ до текста и стрелка совпадают.
- [ ] Наведение — синеет ТОЛЬКО рамка; фон и текст не меняются, кнопка не темнеет при нажатии.
- [ ] Пока панель открыта, рамка кнопки остается синей; закрыли — вернулась серая.
- [ ] Между кнопкой и раскрытой панелью виден зазор, рамки не слиплись и тень панели не
      смазывает нижний угол кнопки.
- [ ] Правый край панели совпадает с правым краем кнопки. Если кажется, что не совпадает, —
      это тень попап-окна (ее на macOS не отключить); числа снимает `Tests/PopupGeometry`.
- [ ] Выбрали несколько типов — подпись стала «Тип документа: 3», но правый край кнопки
      остался на месте.

## Поиск

- [ ] Слово из НАЗВАНИЯ записи находит документ сразу, без сниппета.
- [ ] Слово, которого нет в названии, но есть ВНУТРИ PDF, находит документ со сниппетом и
      желтой подсветкой совпадения.
- [ ] Кириллица ищется в любом регистре.
- [ ] Поиск по префиксу: «автоматизир» находит «автоматизированных».
- [ ] Запрос со спецсимволами (`C++`, `ГОСТ-34.11`, кавычки) не роняет раздел.
- [ ] PDF-скан по содержимому не находится; пустая выдача объясняет, почему.
- [ ] Фильтр типов действует и при активном поиске.
- [ ] Очистка строки поиска возвращает обычную ленту.

## Чтение документов

- [ ] Первый заход в раздел на большой папке: **чтение НЕ начинается само**. В подвале написано,
      сколько документов не прочитано, и стоит «Прочитать документы».
- [ ] Нажали — пошло чтение: подвал пишет «Читаю документы: N из M», по нижней кромке блока
      идет нить, отдельной плашки под блоком НЕТ.
- [ ] Через несколько документов в подвале появляется «осталось около …» — и это замер, а не
      круглое число.
- [ ] **«Остановить»** прекращает чтение; повторный запуск продолжает с того же места, а не с нуля.
- [ ] Больших объемов: перед чтением появилось окно подтверждения с числом документов.
      «Отмена» — ничего не началось.
- [ ] Правый клик по коллекции в сайдбаре → **«Прочитать документы»** читает только ее.
- [ ] Правка документа на диске (изменился размер) — он снова считается непрочитанным, и после
      чтения поиск находит по новому тексту, а не по старому.
- [ ] Порог размера: файл тяжелее порога не читается.
- [ ] В «Настройках → Библиотека документов» НЕТ тумблера «Индексировать текст документов» и
      строк про виды.
- [ ] **Настройки → Библиотека документов → Кеш документов**: числа сходятся с тем, что в
      папке; «Очистить» спрашивает подтверждение, после него поиск по содержимому пуст, а
      в подвале снова появилось «Прочитать документы».

## Производительность

На стенде `~/TestData/perf_main.db` с коллекцией на сотни тысяч документов:

- [ ] Открытие раздела не фризит окно; оверлей «Загрузка…» появляется не раньше 400 мс.
- [ ] Прокрутка ленты плавная, карточки-заглушки оживают на месте, лента не дергается.
- [ ] Прыжок ползунком в конец и обратно не роняет раздел и не оставляет пустых строк.
- [ ] Переключение галочек коллекций и типов не заставляет ждать.
- [ ] Возврат в раздел после правки в конструкторе перечитывает ленту тихо, без волны
      «Загрузка…» и с сохранением места прокрутки.

## Смежное

- [ ] Раздел виден в панели навигации между «Заметки» и «Расширения».
- [ ] «Оформление» умеет скрыть модуль; скрытый не выбирается стартовым.
- [ ] «Библиотека документов» выбирается стартовым разделом и переживает перезапуск.
- [ ] Инструкция пользователя открывает страницу раздела.
- [ ] Масштаб приложения и размер шрифта («Оформление») перестраивают ленту без артефактов.
