# Чеклист: фильтр по дате — дерево «год → месяц → день»

Ручной прогон чеклиста дат в окне фильтра колонки: раскрытие веток, каскад галочек,
поиск, порядок под сортировку и совпадение результата с таблицей. Как устроено —
[features/constructor/table.md](../features/constructor/table.md#фильтр-колонки-чеклист-значений)
и [data-types/date.md](../architecture/data-types/date.md).

Автотестами (`DateFilterTreeTests`) закрыта **чистая логика**: группировка, счетчики,
порядок, поиск, состояние галочки. Вручную проверяется склейка с UI — раскрытие,
виртуализация, применение фильтра к строкам и то, что во всех трех экранах он одинаков.

Дерево стоит в трех местах, каждый пункт проходить в каждом:

1. **Конструктор** → колонка со свойством типа «Дата» (сырое значение со временем).
2. **Настройки → Диагностика** → колонка «Время».
3. **Профиль → История изменений** → колонка «Дата и время».

## Подготовка

- [ ] Коллекция с полем «Дата»: записи минимум за два года, в одном году — два месяца,
      в одном месяце — несколько дней.
- [ ] Среди них: запись «весь день», запись с временем, запись с диапазоном на несколько
      дней (2–5 августа), запись с пустой датой.
- [ ] Коллекция с 5000+ записей-дат — для проверки скорости и прокрутки.

## 1. Вид дерева

- [ ] Шеврон в шапке колонки-даты открывает окно; вместо плоского списка значений —
      дерево: годы верхнего уровня, внутри месяцы, внутри дни.
- [ ] Сырых значений вида `2026-08-02T10:00/2026-08-02T11:00` в списке **не осталось**.
- [ ] Месяцы названы по-русски («Август»), дни — числом, годы — четырьмя цифрами.
- [ ] Счетчик справа: у дня — число записей за день, у месяца и года — сумма внутри.
- [ ] Сумма счетчиков всех дней = числу записей колонки (запись с диапазоном посчитана
      один раз — в дне начала).
- [ ] Записи с пустой датой собраны в «(Пусто)» **в конце** списка.
- [ ] Клик по стрелке раскрывает и сворачивает ветку; стрелка меняется с «›» на «⌄».
- [ ] Стрелка того же размера, что в дереве сайдбара, и стоит вплотную перед чекбоксом.
- [ ] Чекбоксы года, месяца и дня идут ровной лесенкой — шаг между уровнями одинаковый;
      у дня стрелки нет, но его чекбокс не съезжает влево (слот стрелки остается).
- [ ] «(Пусто)» стоит на уровне годов.
- [ ] Когда год в списке один, он раскрыт сразу; когда их несколько — свернуты.

## 2. Галочки и каскад

- [ ] Галочка на дне отмечает только его; **повторный клик снимает** — квадрат пустой,
      а не закрашенный.
- [ ] Галочка на месяце отмечает все его дни; повторный клик — снимает все.
- [ ] Галочка на годе отмечает все месяцы и дни года.
- [ ] Снять один день внутри отмеченного месяца → **галочка месяца и года пропала**
      (промежуточного состояния нет: ветка отмечена, только когда отмечено все внутри).
- [ ] Вернуть этот день → галочки месяца и года встали обратно.
- [ ] Клик по месяцу без галочки (часть дней отмечена) отмечает ветку целиком.
- [ ] Галочки везде обычные: белая галочка на акцентном квадрате или пустой квадрат —
      закрашенных квадратов без галочки нет нигде.
- [ ] «(Выделить все)» ставит и снимает галочки по всему дереву; при частичном выборе
      сам показывает снятое состояние.

## 3. Применение фильтра

- [ ] Отметить один день → «Готово»: в таблице остались только записи этого дня, включая
      записи с разным временем внутри дня.
- [ ] Отметить месяц → в таблице все записи месяца.
- [ ] Запись с диапазоном 2–5 августа проходит фильтр по **2 августа** и не проходит по
      3, 4 и 5 августа.
- [ ] Снять «(Пусто)» → записи без даты исчезли из таблицы.
- [ ] Отметить все → шеврон колонки перестал быть синей воронкой (фильтр снят целиком).
- [ ] Закрыть окно мимо «Готово» → ничего не изменилось.
- [ ] Фильтр по дате вместе с фильтром другой колонки — условия складываются.

## 4. Поиск

- [ ] «2026» — остался только этот год со всеми месяцами.
- [ ] «август» — только август, ветки раскрыты.
- [ ] «23» — все месяцы, где есть 23-е число, каждый со своим днем.
- [ ] «23.08.2026» — конкретный день.
- [ ] Несуществующее значение → «Ничего не найдено» вместо пустой белой карточки.
- [ ] Отметить найденное и нажать «Готово»: фильтр = отмеченное **среди найденного**
      (Excel-режим «Заменить»), остальные значения отсекаются.
- [ ] Очистка поиска возвращает все дерево, галочки не потерялись.

## 5. Порядок и сортировка

- [ ] «Сначала старые» → годы, месяцы и дни идут по возрастанию.
- [ ] «Сначала новые» → все три уровня переворачиваются.
- [ ] Переключение сортировки прямо в открытом окне сразу перестраивает дерево.
- [ ] Дни внутри месяца упорядочены как числа: 2, 9, 10 (а не 10, 2, 9).
- [ ] «Снять сортировку» → дерево осталось в календарном порядке (дерево всегда
      упорядочено по датам, даже когда у колонки сортировки нет).

## 6. Объем и производительность

- [ ] Коллекция с 5000+ дат: окно открывается без задержки, дерево строится сразу
      после «Загрузка…».
- [ ] Прокрутка длинного дерева плавная (свернутые ветки в список не попадают).
- [ ] Раскрыть все годы, прокрутить до конца и обратно — нет фризов и пустых строк.
- [ ] Профиль → Диагностика: во время прогона в журнале нет исключений.

## 7. Единообразие трех экранов

- [ ] Дерево в «Диагностике» и «Истории изменений» выглядит и ведет себя так же
      (там сырое значение — сама дата, поэтому у дня всегда одно значение).
- [ ] Колонки НЕ-даты во всех трех экранах остались плоским списком значений.
