# Чеклист: раздел «Заметки»

Раздел трогает НАСТОЯЩИЕ файлы пользователя на диске, поэтому проверять надо не только «получилось»,
но и «ничего лишнего не потерялось». Как устроено — [features/notes.md](../features/notes.md).

Автоматика покрывает правила по отдельности: что скрыто и в каком порядке (`VaultRulesTests`),
имена и «(копия)» (`VaultNamesTests`), чтение с диска (`VaultScannerTests`), операции вместе с
сохранностью BOM и переводов строк (`VaultOperationsTests`), список «Расположение»
(`VaultLocationsTests`), сверку снимков (`NoteAutosaveTests`), ключи настроек
(`NotesSettingsTests`), разбор разметки (`NoteMarkupScannerTests`) и команды форматирования
(`NoteFormatTests`). А вот их сборка в живом интерфейсе — вид дерева, три режима, скрытие маркеров,
автосохранение по таймеру — автоматикой не проверяется. Этот чеклист закрывает ровно эту дыру.

## Подготовка стенда

- [ ] Папка с вложенностью не меньше трех уровней, в ней и `.md`, и другие файлы (`.pdf`, `.txt`).
- [ ] Внутри — папка `.obsidian` и файл `.DS_Store` (проверка отсева скрытого).
- [ ] Отдельно: заметка с текстом в кодировке UTF-8 с BOM и переводами строк `\r\n`.
- [ ] Отдельно: файл `.md` размером больше 512 КБ и файл больше 5 МБ.
- [ ] Папка на съемном или сетевом диске — для проверки пропажи хранилища.

## 1. Первый запуск и настройка

- [ ] Хранилище не задано: раздел показывает подсказку про «Настройки → Заметки», сайдбар пуст,
      кнопка режима внизу неактивна, но полоса футера и ее линия на месте (тело не сдвинулось).
- [ ] Кнопка «Открыть настройки» открывает именно раздел «Заметки», и кнопка «Настройки» в панели
      слева при этом подсвечена (подсветка не разъехалась с показанным разделом).
- [ ] «Обзор…» открывается в текущей папке хранилища, если она задана.
- [ ] После выбора папки дерево появляется сразу, без перезапуска.
- [ ] Строка состояния под полем: «Папка найдена». Вписать несуществующий путь руками → «Папка не
      найдена», дерево пустое с подсказкой.
- [ ] «Отключить» очищает путь; файлы на диске остаются.

## 2. Дерево — вид

- [ ] Отступы, высота строк и линии-разделители неотличимы от дерева конструктора (сравнить
      наложением скриншотов на одном зуме).
- [ ] Файлы, которые нельзя открыть, показаны приглушенным текстом.
- [ ] `.obsidian`, `.DS_Store` и прочее с точкой в начале в дереве отсутствуют.
- [ ] Зум 70 % и 130 %: линии в один физический пиксель, строки не копят сдвиг вниз.
- [ ] «Настройки → Оформление → Размер шрифта» ±3: строки заметок перерисовываются, ширина строки
      пересчитывается (горизонтальная полоса не врет).
- [ ] Длинное имя в глубокой вложенности: появляется горизонтальная полоса, при вертикальной
      прокрутке она НЕ дергается.

## 3. Дерево — поведение

- [ ] Раскрытие папки дочитывает содержимое; повторное раскрытие мгновенное.
- [ ] «Развернуть все» раскрывает дерево целиком, повторный клик сворачивает.
- [ ] Очень большое хранилище (за 20 000 элементов): «Развернуть все» показывает всплывашку про
      предел, дерево остается рабочим.
- [ ] Сортировка переключает А → Я и Я → А; папки в обоих случаях остаются выше файлов; порядок
      переживает перезапуск.
- [ ] Клик по `.md` открывает заметку; клик по `.pdf` — пояснение вместо содержимого, файл ничем
      не запускается.
- [ ] Shift/Ctrl/Cmd-клик набирает несколько строк, подсветка видна у всех.
- [ ] Свернуть и развернуть сайдбар, потянуть ручку ширины — строки не разъезжаются.

## 4. Открытие и режимы

- [ ] Клик по кнопке футера открывает список трех режимов ВВЕРХ, галочка стоит у текущего; иконка и
      тултип кнопки называют текущий режим.
- [ ] Полоса прокрутки одна, идет от линии шапки до линии футера и перецепляется при смене режима.
- [ ] Отступы во всех трех режимах одинаковые: 16 сверху, снизу, слева и справа. Переключить режим
      на неподвижной заметке — текст не сдвигается ни на пиксель.
- [ ] Отступ сверху и снизу прокручивается вместе с текстом: в начале заметки он есть, при листании
      строки доходят вплотную до линий шапки и футера и обрезаются по ним, а не раньше.
- [ ] Просвет над первой строкой и под последней на глаз одинаковый. Проверить на файле с переводом
      строки в конце и на файле без него — в обоих случаях поровну.
- [ ] Длинная заметка, прокрутка в самый низ: под последней строкой ровно отступ, пустого экрана
      нет — во всех трех режимах.
- [ ] Пустая заметка: подсказка стоит там же, где встала бы первая строка.
- [ ] Файл больше 512 КБ открывается БЕЗ оформления (режим не понижается), больше 5 МБ — не
      открывается, показано пояснение.
- [ ] Выбранный режим переживает перезапуск.
- [ ] Последняя открытая заметка восстанавливается при запуске. Закрыть ее (выбрать другой раздел
      и вернуться) — она НЕ открывается заново сама.

### Динамический просмотр

- [ ] `**жирный**` жирный, `*курсив*` курсивом, `~~зачеркнутый~~` зачеркнут, `` `код` ``
      моноширинный на фоне.
- [ ] `# Заголовок` крупнее и жирнее; H1 и H2 отличаются размером, H3–H6 идут базовым.
- [ ] `- пункт` показан точкой, номера нумерованного списка на месте, цитата приглушена курсивом.
- [ ] Блок кода закрашен целиком, ограждения ``` не видны.
- [ ] Поставить каретку на оформленную строку — служебные знаки проявились приглушенными; увести —
      спрятались. Стрелки вверх-вниз НЕ проваливают каретку внутрь спрятанного.
- [ ] Выделить несколько строк мышью — знаки видны на всех выделенных.
- [ ] Набор длинного абзаца не спотыкается; оформление догоняет через мгновение.
- [ ] Скопировать оформленный кусок — в буфер попала разметка со знаками, а не голый текст.
- [ ] «Просмотр исходного кода» — тот же текст без оформления, ВСЕ знаки на месте.
- [ ] Зум 70 / 100 / 130 % — каретка и фон блока кода не размываются, строки не съезжают.
- [ ] «Настройки → Оформление → Размер шрифта» — заголовки в редакторе меняются сразу.

### Меню и клавиши

- [ ] Правый клик мимо выделения переносит каретку, и команда применяется к нужному месту.
- [ ] Подменю «Форматирование», «Абзац», «Вставка» не наезжают на родителя.
- [ ] Каждая команда: на пустом выделении, на слове, на нескольких строках.
- [ ] Повторное применение снимает оформление (жирный → обычный, список → без списка).
- [ ] Ctrl+Z откатывает команду ОДНИМ шагом, Ctrl+Y возвращает.
- [ ] Ctrl+B/I/E/K, Ctrl+Shift+K, Ctrl+Shift+L, Ctrl+1..6, Ctrl+0 — работают; Ctrl+S сохраняет.
- [ ] Ctrl+F ничего не открывает (панели поиска у редактора быть не должно).
- [ ] Вырезать / Копировать / Вставить / Выделить все — по-русски и работают.
- [ ] Кликнуть мимо редактора (в дерево, в шапку, в другой раздел) — приложение не падает.
      Путь через системный ввод: именно на нем ломалась AvaloniaEdit 11.0.0.

## 5. Сохранение

- [ ] Набрать текст, подождать секунду, посмотреть файл снаружи — правка на диске.
- [ ] Набрать текст и сразу переключиться на другую заметку → текст сохранен.
- [ ] Набрать текст и сразу уйти в другой раздел → сохранен.
- [ ] Набрать текст и переключиться в другую программу → сохранен.
- [ ] Набрать текст и закрыть SmartBase → сохранен.
- [ ] Ctrl+S (Cmd+S) сохраняет немедленно.
- [ ] Заметка с BOM и `\r\n`: после правки в файле остались и BOM, и `\r\n` (проверить
      `git diff` — изменена одна строка, а не весь файл).
- [ ] Рядом с заметкой не остается файлов `.sbtmp`.

## 6. Внешние правки

- [ ] Открыть заметку, изменить тот же файл другим редактором, вернуться и напечатать символ →
      появляется вопрос «Перезаписать / Сохранить копию».
- [ ] «Перезаписать» — на диске ваша версия.
- [ ] «Сохранить копию» — рядом появился файл «Имя (конфликт …).md» с вашим текстом, а на экране
      версия с диска. Ни один вариант не потерян.
- [ ] Создать файл в папке снаружи, вернуться в раздел из другого раздела → он появился в дереве.

## 7. Операции

- [ ] «+» кладет новую вещь в выделенную папку (или в папку выделенной заметки, или в корень).
- [ ] Новая заметка открывается сразу после создания.
- [ ] Создание с занятым именем: отказ с баннером в окне, файл на диске не тронут.
- [ ] Запрещенное имя (`а/б`, `CON`, точка в конце, пустое) — отказ с понятным текстом.
- [ ] Переименование из контекстного меню и из шапки дают одинаковый результат.
- [ ] Переименование в занятое имя: заголовок откатывается, ошибка показана у него же, соседний
      файл не перезаписан.
- [ ] Переименование только регистра (`заметка.md` → `Заметка.md`) проходит; файлов `.sbren` не
      остается.
- [ ] Дубль папки копирует всю вложенность.
- [ ] Перенос в папку с занятым именем: вещь легла как «(копия)», показана всплывашка, чужой файл
      цел.
- [ ] Папку нельзя перенести внутрь себя (в списке «Расположение» ее поддерева нет).
- [ ] Открытая заметка после переноса остается открытой, заголовок показывает новое имя.

## 8. Удаление

- [ ] Удаление заметки: файл в корзине системы, из дерева исчез.
- [ ] Удаление папки: подтверждение предупреждает про вложенное; папка целиком в корзине.
- [ ] Удаление открытой заметки закрывает ее в правой области.
- [ ] Delete по выделению работает так же, как пункт меню.
- [ ] Клик в дереве заметок → Delete → выделенная коллекция конструктора НЕ удаляется.
- [ ] Клик в таблице → Delete → выделение в дереве заметок НЕ удаляется.
- [ ] Хранилище на носителе, где корзина недоступна: предложено безвозвратное удаление; отказ
      ничего не удаляет.

## 9. Пропажа хранилища

- [ ] Отключить диск с хранилищем при открытой заметке → раздел показывает «Папка хранилища
      недоступна», приложение не падает.
- [ ] Автосохранение в этом состоянии не сыплет всплывашками без конца.
- [ ] Вернуть диск, зайти в раздел заново → дерево и заметка на месте.
- [ ] Путь в настройках при пропаже папки НЕ стирается.

## 10. Оболочка

- [ ] «Настройки → Оформление → Отображение раздела навигации»: «Заметки» скрываются и
      возвращаются; остальные кнопки панели при этом не сдвигаются.
- [ ] «Заметки» выбираются стартовым разделом, и выбор переживает перезапуск.
- [ ] Раздел «Заметки» есть в инструкции пользователя (Настройки → Инструкция пользователя).
