# Модуль «Профиль»

## Назначение

Раздел Activity bar (иконка-пользователь над Настройками) для многопользовательской
работы: данные текущего пользователя, управление доступом к базам и журнал изменений.
Архитектура прав/журнала — [users-permissions.md](../architecture/users-permissions.md).

## Устройство

Точное зеркало паттерна Настроек: реестр разделов
[ProfileRegistry](../../Settings/ProfileRegistry.cs) → общий `SidebarList` →
[ProfileView](../../Views/Profile/ProfileView.axaml.cs) переключает панели по ключу
(`ShowCategory`), шапка — `NavbarProfile` (56px). Кнопка в
[ActivityBar](../../Controls/Components/ActivityBar.axaml) задокирована `Bottom`
ПОСЛЕ SettingsBtn — в DockPanel второй Bottom-элемент ложится выше первого, поэтому
«Профиль» стоит над «Настройками».

## Разделы

### Общие данные

- **Имя компьютера** и идентификатор `учётка@компьютер` — определяются автоматически
  (`Utils/CurrentUser`), не редактируются.
- **Фамилия/Имя/Отчество** — автосохранение при уходе фокуса в app.db (`profile.*`);
  «Отображаемое имя» показывает, как пользователь виден другим (ФИО или идентификатор).

### Панель администратора

Видна содержательно только администраторам (иначе — заглушка-пояснение).

- **База данных** — выпадающий список баз, где текущий пользователь администратор.
- **Пароль базы данных** — установить/сменить/убрать ([PasswordDialog](../../Controls/Dialogs/PasswordDialog.axaml.cs),
  два поля с повтором); пароль даёт новым пользователям self-service-доступ.
- **Пользователи** — все, кто открывал базу: ожидающие допуска сверху с кнопкой
  «Допустить», у допущенных — «Отозвать допуск»; клик по строке выбирает пользователя.
- **Права пользователя** — область («Вся база данных» или коллекция; настройки
  коллекции приоритетнее) + чекбоксы действий в трёх группах (Коллекции/Записи/Свойства).
  Изменение пишется сразу (`PermissionService.SetMask`) и применяется живо (`Reload`).

### История изменений

Журнал выбранной базы (только допущенные базы): «{Имя} {создал/изменил/удалил/
дублировал/импортировал/перенёс} {объект}» + дата-время, новые сверху. Фильтр по типу
объекта, keyset-страницы по 200 с кнопкой «Показать ещё» — миллионы строк без фриза.
