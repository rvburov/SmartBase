# Режим «Диаграмма»

## Назначение

Диаграмма Ганта на календарный месяц: слева панель коллекций со сворачиваемыми
группами и строками записей, справа таймлайн месяца — полосы-«пилюли» в цветах
коллекций с подписями длительности, кольца для точечных событий, суммарные бары
групп, подсветка выходных и красная линия «сейчас». Полосы переносятся и
растягиваются мышью с шагом «целый день».

## Где в коде

- View + вся логика: [DiagramView.axaml.cs](../../../Views/ConstructorDb/Calendar/DiagramView.axaml.cs) (`UserControl`, рисует вручную на Canvas)
- Данные приходят от [CalendarControllerView](../../../Views/ConstructorDb/Calendar/CalendarControllerView.axaml.cs) через `DiagramViewCtrl.Refresh(records, currentDate, scrollToNow)`
- Диапазон — ровно календарный месяц (`GetDateRange`, индекс 6), не 42-дневная сетка Месяца

## Как работает

Разметка — фиксированная шапка (заголовок «ВСЕ КОЛЛЕКЦИИ» + Canvas дней месяца)
и ОДИН вертикальный `ScrollViewer` с телом: левая панель (`LeftRowsCanvas`) и
таймлайн (`TimelinePane` со слоями `BgCanvas` → `BarsCanvas` → `TodayOverlay` →
`DragOverlay`) едут вместе, шапка стоит. Горизонтального скролла нет: месяц всегда
растянут на всю ширину, `dayW = ширина таймлайна / дней в месяце`. Вся раскладка
пересобирается при `Refresh` и `SizeChanged` (как в Месяце/Неделе).

### Группировка и строки

Каркас групп — **все отмеченные коллекции всех допущенных БД** (контроллер передаёт
их в `Refresh` из `GetAllCollections`, фильтруя по галкам сайдбара): коллекция видна
строкой даже без событий в показанном месяце (счётчик 0, без суммарного бара).
Порядок — порядок БД, внутри БД — `Position` коллекции (как в сайдбаре). События
раскладываются по своим группам по `(DbId, CollectionId)` и сортируются по `StartDt`;
события без коллекции образуют группу «Без коллекции» в конце. Строка группы —
шеврон + цветная точка + имя + счётчик; сворачивание (клик по строке слева) прячет
записи, но оставляет строку с суммарным баром; свёрнутость переживает `Refresh`,
но не перезапуск. При активном поиске пустые группы скрываются (шум).

Кэпы против дней-гигантов (окно месяца может отдать до 31×`GridDayCap` событий):
`MaxRecordsPerCollection` (200) — сверх лимита серая строка «+N ещё»;
`MaxTotalRows` (1000) — сверх лимита обрезаются группы целиком, последняя строка
«+N коллекций ещё». Счётчик группы и её суммарный бар считаются по **всем**
доставленным записям, включая обрезанные кэпом строк. Смотреть всё —
Расписание/Журнал (у них виртуализация).

### Геометрия таймлайна

- Геометрия — **по ячейкам дней**, как бары Месяца: блок занимает колонки от
  первого до последнего дня события целиком (`x = индексДня × dayW`), время суток
  на позицию не влияет. Красная линия «сейчас» — единственный время-пропорциональный
  элемент (показывает текущий момент внутри дня).
- **Бар записи** — блок в стиле баров Месяца (`MakeBlock`, зеркало `_AddSpanBar`):
  белая подложка + полупрозрачный цвет коллекции, скругление 5 только на реальных
  краях события, цветной акцент слева — только у его начала (обрезанный месяцем
  край — прямой и без акцента); высота 20, строка — `RowHeightStandard` (как
  таблица конструктора). Подпись длительности тёмным цветом (`FontSizeBase`):
  внутри бара, не влезла — справа, у края месяца — слева; всегда показывает
  **истинную** длительность, даже если бар обрезан краем месяца.
- **Кольцо** — однодневное событие (timed или all-day; у all-day подпись
  «24 часа»); рисуется по центру ячейки своего дня (по ширине и высоте строки),
  подпись рядом.
- **Суммарный диапазон группы** рисуется как событие тем же рендером:
  min(начало)…max(конец) записей — блок по ячейкам дней, однодневный охват —
  кольцо по центру ячейки; подпись — суммарный охват дней и времени
  («30 минут», «1 день 3 часа 30 минут»); полностью all-day группа — «N дней»/«24 часа».
- Длительность форматируется по-русски с ненулевыми частями: «10 дней 2 часа
  15 минут», «45 минут», all-day — «N дней»/«24 часа» (хелперы `RuDuration`/`Plural`
  внутри вида).
- Фон: заливка колонок Сб/Вс (`BrushSecondaryBg`), лёгкий тинт строк групп цветом
  коллекции, линии дней/строк — пустые Border с `EdgeMode=Aliased` +
  `LineUseLayoutRounding` (см. [theming.md](../../ui/theming.md)); линия «сейчас» —
  красная вертикаль, обновляется минутным `DispatcherTimer`, рисуется только
  когда показанный месяц содержит текущий момент.

### Взаимодействие

Слои таймлайна не хит-тестятся — указатель принимает `TimelinePane`, попадание
ищется вручную по хит-листу `BarEntry` (паттерн Недели):

- **Клик** — как в Месяце: одиночный клик по блоку/кольцу выделяет (заливка
  цветом, у блока с подписью внутри текст становится белым), **двойной клик**
  (ClickCount ≥ 2) → `RecordClicked` → окно записи — даже по уже выделенному;
  наведение подсвечивает (полупрозрачная заливка ярче); drag и клик по пустому
  месту снимают выделение. Выделение одиночное и не переживает пересборку.
  Клик по строке записи слева открывает окно сразу.
- **Перенос** (drag за середину бара, порог 5 px) — **целыми днями**: при ширине
  дня в десятки пикселей минутная точность недостижима; время суток и длительность
  сохраняются (семантика горизонтального drag в `AllDayBar`). Ghost рисуется на
  `DragOverlay`, оригинал приглушается; центр события не может покинуть месяц.
- **Растяжение** за края бара (зона 6 px, курсор ↔) — тоже целыми днями: меняется
  день начала/конца, время суток края сохраняется, инвариант `EndDt > StartDt`.
  Обрезанный краем месяца край не ресайзится; кольца не ресайзятся.
- **Коммит** — `RecordMoved` → контроллер (`UpdateCalendarRecord` + дельта
  `[(r,−1),(r,+1)]` + `TryApplyGridDelta`) — правка видна сразу, без перезагрузки.
- Множественного выделения (Shift), контекстного меню и Delete в этом режиме пока
  нет — паритет с остальными видами возможен отдельным шагом.

Поиск и галки коллекций сайдбара работают как во всей сетке — данные приходят
уже отфильтрованными; «Нет записей» показывается, когда нет ни одной группы
(ни отмеченных коллекций, ни событий — либо поиск ничего не нашёл).
