# Режим «Неделя»

## Назначение

Семь дней (Пн–Вс) рядом, каждый — вертикальная сетка часов, как в режиме «День».
Сверху — общая полоса событий «весь день» на всю неделю. Неделя начинается с
понедельника.

## Где в коде

- View + логика: [WeekView.axaml.cs](../../../Views/ConstructorDb/Calendar/WeekView.axaml.cs) (самый крупный из вью календаря)
- Полоса all-day — тот же общий виджет [AllDayBar](../../../Controls/Components/) (`AllDayBarCtrl`), что и в «Дне»
- Данные: `WeekViewCtrl.Refresh(records, currentDate, scrollToNow)`; диапазон — 7 дней от `StartOfWeek` (понедельник)

## Как работает

Архитектурно «Неделя» — это «День», размноженный на **7 колонок**:

- Те же метки часов (`HourLabels`, 01:00…23:00) и линия текущего времени (`_timeLineTimer` раз в минуту).
- События с временем позиционируются по минутам внутри своей колонки-дня; пересекающиеся события дня раскладываются по под-колонкам (не больше `MaxEventColumns` = 6 — сверх лимита не рисуются, см. [day.md](day.md)).
- All-day и многодневные события уходят в `AllDayBarCtrl`, который растягивает бары на нужные дни недели; у полосы есть грип высоты (`AllDayResizeGrip`). Рисуется не больше `MaxRenderedEvents` (300) блоков, остальное — «+N ещё» (см. [day.md](day.md)).
- Выделение хранится в `_selections` (множественное), drag/resize рисуют ghost-элементы.

Отличие от «Дня» — переключение даты идёт неделями (±7 дней), а события
привязываются к колонке нужного дня.

Операции (создание/изменение/удаление/дублирование, перенос и растяжение времени) — **на
месте** через снимок сетки (`TryApplyGridDelta`), без чтения окна и «Загрузка…»; полная
загрузка недели идёт без карты счётчиков — как в «Дне» (см. [day.md](day.md)).

## Взаимодействия

Полностью совпадают с режимом «День», только в контексте 7 дней:

- **Клик по пустому слоту** → `TimeSlotCreationRequested(день + время)`.
- **Клик по полосе all-day** → `AllDayCreationRequested(день)`.
- **Перетаскивание** — перенос по времени и между днями → `RecordMoved`.
- **Ресайз** — длительность → `RecordMoved`.
- **Двойной клик** → `RecordClicked`.
- Выделение / удаление / контекстное меню — см. [interactions.md](interactions.md).

### События контрола

`RecordClicked`, `RecordMoved`, `RecordDeleteRequested`, `RecordsDeleteRequested`,
`RecordDuplicateRequested`, `AllDayCreationRequested`, `TimeSlotCreationRequested`.
