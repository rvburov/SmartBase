# Режим «Журнал»

## Назначение

Лента событий, сгруппированных по дням, с прокруткой. Сегодняшний день всегда
присутствует (даже без событий) и подсвечен; при открытии лента
автопрокручивается к сегодня. Навигация ← → прыгает к соседней группе-дню.

## Где в коде

- View + логика: [JournalView.axaml.cs](../../../Views/ConstructorDb/Calendar/JournalView.axaml.cs)
- Группа дня — класс `JournalGroup`, элемент — `JournalItem` (там же)
- Данные: `JournalViewCtrl.Refresh(records, currentDate)`; диапазон от контроллера — примерно ±1 год

## Как работает

### Группировка

`Refresh(events, currentDate)` сортирует события по времени, группирует по
`StartDt.Date` в `JournalGroup`. Заголовок группы — «день_недели – число месяц»;
цвет: сегодня — красный, прошлое — серое, будущее — тёмное. Если сегодня нет в
списке, пустая группа «сегодня» вставляется в правильное место.

После построения через `Dispatcher.UIThread.Post` лента прокручивается так, чтобы
группа «сегодня» оказалась сверху.

### Навигация (особая для Журнала)

В отличие от других режимов, контроллер не сдвигает дату, а вызывает методы
самого контрола, которые **плавно прокручивают** (`AnimateScroll`, easing 300 мс):

- `GoNext()` — к следующей группе ниже текущего скролла;
- `GoPrev()` — к предыдущей группе выше;
- `GoToday()` — к группе «сегодня».

## Взаимодействия

- **Клик / Shift+клик** — выделение (одиночное / множественное).
- **Двойной клик по событию** → `RecordClicked`.
- **Двойной клик по фону** / меню фона → `CreateRequested(дата под курсором)` (`GetDateForY` определяет день по вертикальной позиции).
- **Delete/Backspace** — удалить выделенное.
- **Правый клик** — контекстное меню (как в «Расписании»).
