# Режим «Год»

## Назначение

Весь год — 12 мини-календарей (по месяцу). Дни с событиями подсвечены цветом,
интенсивность зависит от числа событий. Клик по числу показывает попап со списком
событий дня; двойной клик по месяцу открывает его в режиме «Месяц».

## Где в коде

- View + логика: [YearView.axaml.cs](../../../Views/ConstructorDb/Calendar/YearView.axaml.cs)
- Данные: `YearViewCtrl.Refresh(records, year)`; диапазон — весь год (1 января … 1 января следующего)

## Как работает

### Индексация событий по дням

`Refresh(events, year)` раскладывает события по дням (`_eventsByDay`): каждое
событие добавляется во все дни от `StartDt.Date` до `EndDt.Date` (`EachDay`).
Из этого строится словарь «дата → количество событий».

### Карточка месяца `BuildMonthCard`

- Один `UniformGrid` 7×7: строка заголовков дней недели (Пн–Вс) + 42 ячейки.
- `startOffset = ((int)firstDay.DayOfWeek + 6) % 7` — сдвиг к понедельнику.
- Каждая ячейка (`d = firstDay.AddDays(i - startOffset)`):
  - **Сегодня** — белое число в красном кружке 22×22.
  - **День с событиями** — число на цветном прямоугольнике; цвет/насыщенность по шкале `EventSteps` (4 ступени): 1 событие, 2–5, 6–8, 9+.
  - **Обычный день** — число; дни соседнего месяца серые (`#E5E5EA`), выходные — `#8E8E93`.

### Попап дня

Клик по числу текущего месяца открывает `DayPopup` (`ShowDayEvents`), привязанный
к ячейке: заголовок-дата + список событий (цветная полоска, заголовок, время или
«весь день»), отсортированных по времени. Пустой день — «Нет записей».

## Взаимодействия

- **Клик по числу** → попап со списком событий дня.
- **Двойной клик по карточке месяца** → `MonthSelected(1-е число месяца)` → контроллер переключается в режим «Месяц».
