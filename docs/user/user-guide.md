# Руководство пользователя

Приложение — это календарь-планировщик поверх «конструктора данных»: можно вести
события в календаре и строить собственные таблицы (коллекции) с произвольными полями.

## Первый запуск

На чистой установке (когда ещё нет ни одной базы данных) программа заводит коллекцию
«Задачи» с вводным чек-листом — по задаче на каждый раздел, со сроком, исполнителем и
описанием того, что в разделе можно сделать. Эти задачи — обычные записи: правьте,
переносите и удаляйте их как свои. Удалённый чек-лист больше не возвращается, а базы,
которые уже существовали, он не трогает вовсе. Подробности —
[../developer/features/intro-seed.md](../developer/features/intro-seed.md).

## Календарь

Семь режимов переключаются в верхней панели; навигация ← **Сегодня** → работает в
контексте выбранного режима:

- **Расписание** — список дел на один день.
- **Журнал** — лента по дням с прокруткой к сегодня.
- **День** / **Неделя** — сетка по часам; события «весь день» — в полосе сверху.
- **Месяц** — классическая сетка (по умолчанию).
- **Год** — 12 мини-месяцев; дни с событиями подсвечены.
- **Диаграмма** — гант на месяц, год, 5 или 10 лет (кнопки «−»/«+» в шапке):
  строки по коллекциям, полосы с длительностью.

Подробно про каждый режим — [../features/calendar/](../developer/features/calendar/).

### Работа с событиями

- **Создать:** двойной клик по пустому месту/дню, кнопка «+» в панели, или клик по слоту времени (День/Неделя).
- **Открыть/редактировать:** двойной клик по событию.
- **Перенести:** перетащить событие (в Месяце — на другой день; в Дне/Неделе — по времени; в Диаграмме — по дням); за край — изменить длительность.
- **Выделить:** клик; **Shift+клик** — несколько; **Delete** — удалить выделенное.
- **Правый клик** — меню (создать/редактировать/дублировать/удалить).

## Конструктор данных

Слева — группы и коллекции (таблицы). Коллекцию можно открыть как **таблицу** или
**список**. В таблице добавляются записи (строки) и свойства (колонки) разных типов
(текст, число, дата, выбор, чекбокс, ссылка). Деталь записи открывается справа —
свойства сверху, описание в Markdown снизу; всё сохраняется автоматически.

Подробно — [../features/constructor-db/](../developer/features/constructor/).

## Несколько баз данных

В настройках → «Управление базой данных» можно создать новую БД, подключить
существующий `.db` (в т.ч. из сетевой папки) или базу на сервере PostgreSQL
(установка сервера и подключение — [postgresql-setup.md](../developer/guides/postgresql-setup.md)).
События календаря показываются из всех подключённых баз. Отключение базы не удаляет
файл. См. [../features/settings.md](../developer/features/settings.md).

## Настройки

- **Оформление** — масштаб интерфейса.
- **Управление базой данных** — список и подключение БД.
- **О программе** — версия.
