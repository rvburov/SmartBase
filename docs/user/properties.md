# Свойства и их типы

Свойство — это колонка коллекции. Создать: кнопка **«+»** в правом краю таблицы,
пункт «Создать новое свойство» в меню заголовка или строка «Добавить свойство»
на [[record-page]].

В окне свойства задаются название и тип; у части типов появляются дополнительные
настройки.

## Все типы

| Тип | Для чего | Настройки |
|---|---|---|
| **Текст** | произвольный текст | — |
| **Число** | количества, суммы, проценты | формат, разделитель, знаки после запятой, разряды, валюта |
| **Дата** | даты и время, срок | «Отображать в календаре» |
| **Чекбокс** | да или нет | — |
| **Список** | выбор одного значения из своего набора | пункты списка |
| **Статус** | состояние записи | пункты списка (по умолчанию три) |
| **Мультисписок** | выбор нескольких значений | пункты списка, формат записи значений |
| **Ссылка** | адрес в интернете | — |
| **Файл** | ссылки на файлы на диске | автоподстановка файлов |
| **Связь** | ссылка на записи другой коллекции | поиск и показ по свойствам, ручной или автоматический подбор |
| **Свойство связанной записи** | значение из записи, выбранной через связь | поле-связь и свойство цели; только чтение |
| **Итог по связанным записям** | количество, сумма, среднее, минимум или максимум | поле-связь, свойство цели и вид итога; только чтение |
| **Пользователь** | человек | «Добавить в раздел задач» |
| **Дата создания** | когда запись создана | — (заполняется само) |
| **Дата изменения** | когда изменена | — (заполняется само) |
| **Создание пользователем** | кто создал | — (заполняется само) |
| **Изменение пользователем** | кто изменил последним | — (заполняется само) |

В выпадающем списке типы разделены чертами на четыре группы — ровно в том порядке,
что и в таблице выше:

1. **Текст, Число, Дата, Чекбокс** — значение вводится руками, настраивать нечего.
2. **Список, Статус, Мультисписок** — выбор из своего набора: нужно завести пункты.
3. **Ссылка, Файл, Связь, Пользователь** — значение указывает на что-то за пределами
   ячейки: адрес в интернете, файл на диске, другую запись, человека.
4. **Дата создания, Дата изменения, Создание/Изменение пользователем** — значения
   программа проставляет сама, вручную они не редактируются.

## Число

| Настройка | Варианты |
|---|---|
| Формат числа | Обычное число · Число с разрядами · Деньги · Проценты |
| Десятичный разделитель | Запятая · Точка |
| Знаков после запятой | Авто · 0 · 1 · 2 · 3 · 4 |
| Разделять разряды | вкл. / выкл. |
| Валюта (для «Денег») | обозначение + «Символ после числа» или «Символ перед числом» |

> **Формат меняет только показ.** Само значение не пересчитывается: «Проценты» не
> умножают число на 100, а возврат к обычному формату вернет исходный вид.
> Единственное исключение — десятичный разделитель: он приводит уже сохраненные
> значения к выбранному символу.

## Дата

Значение — дата и время; поддерживаются диапазон «Начало — Конец» и признак
**«Весь день»**.

Тумблер **«Отображать в календаре»** (у новых свойств включен) определяет, попадут ли
записи с этой датой в раздел «Календарь». Полей-дат у коллекции может быть несколько —
какие из них показывать, выбирается в сайдбаре: правый клик по коллекции →
«Отображение свойств даты».

## Список, Статус, Мультисписок

Все три хранят набор своих пунктов: поле поиска, список, **«+ Добавить пункт»**,
удаление пункта.

- **Список** — одно значение из набора.
- **Статус** — то же, но у нового свойства сразу заведены «Запланировано»,
  «В работе», «Выполнено». Именно статус связывает записи с фильтрами раздела
  «Задачи» — см. [[tasks]].
- **Мультисписок** — несколько значений; настройка **«Формат записи значений»**
  задает, как они выглядят одной строкой: через запятую, точку, пробел, точку
  с запятой, с новой строки, а также варианты без пробела.

## Файл

Значение — ссылка на файл на диске. При нескольких найденных файлах их имена показаны
через запятую; каждое имя открывает свой файл системной программой. Файлы остаются на
своих местах и никуда не копируются.

Тумблер **«Автоподстановка файлов»** включает автоматическое заполнение колонки. У нового
свойства он выключен: файл выбирается вручную. Прежние корректные правила автоподбора
остаются включенными. Если выключить тумблер и сохранить, найденные пути и настройки
сохранятся, а колонку снова можно будет редактировать вручную.

| Настройка | Что задает |
|---|---|
| Столбец-источник | по какому свойству искать имя файла |
| Папка с файлами | где искать |
| Искать во вложенных папках | просматривать и подпапки; у нового правила включено |
| Формат файла | расширение: pdf, docx, xlsx, xlsm, csv, png, zip и другие, либо «Свой формат…» |
| Частичное совпадение имени | искать значение столбца внутри имени файла; по умолчанию выключено |

По умолчанию файл ищется по точному имени «значение столбца.формат» — например, значение
«Отчет» и формат `pdf` подберут `Отчет.pdf`. При одинаковом имени в разных подпапках
в этом режиме выбирается первый перечисленный файл.

Включите **«Частичное совпадение имени»**, чтобы подобрать все файлы, в имени которых
есть значение столбца: «Отчет» найдет и `Отчет.pdf`, и `Отчет за октябрь.pdf`, и
`2026 Отчет, подписан.pdf`. Выбранное расширение сохраняется: при формате `pdf` файлы
`xlsx` не подойдут. Само расширение не участвует в поиске подстроки, регистр букв
учитывается. Пустое значение столбца ничего не подбирает. При включенном поиске во
вложенных папках учитываются и файлы из них, включая одноименные файлы из разных папок.

Настройте правило и нажмите **«Сохранить»**: только тогда программа применит настройки
и заново подберет файлы для колонки. Переключение тумблера или галочек до сохранения
значения не меняет. Подбор выполняется в фоне; долгую операцию можно отменить.

Если для одной ячейки найдено больше **10 000 файлов** или список путей превышает
**4 × 1024 × 1024 символов**, программа предложит уточнить поиск. Она не обрезает список
и сохраняет прежние значения. Недоступная папка, отмена или изменение исходных данных
во время подбора также не стирают прежние ссылки.

В ячейке показаны первые **8 отдельных ссылок**, все пути можно просмотреть в списке
с подгрузкой при прокрутке по кнопке **`+N`**. Варианты фильтра содержат отдельные файлы: запись подходит,
если в ней есть хотя бы один выбранный полный путь. Одинаковые имена из разных папок
остаются разными файлами. Ранее сохраненный фильтр по целому набору файлов сохраняет
прежнее точное сопоставление набора, а не выбирает каждую из его ссылок отдельно.

Если источник уже заполнен при создании записи, программа сразу запускает подбор по включенному
правилу. Это работает и при создании из календаря. Если источник пустой, подбор начнется после
его заполнения. Выключенный тумблер не запускает подбор при создании и правках.

Для автоподстановки нужны права просмотра коллекции и изменения записей. Одного права
создания записей для автоподбора недостаточно.

> **При включенной автоподстановке колонка только для чтения.** Правка источника запускает
> фоновый подбор. Чтобы перечитать изменения папки, выберите **«Обновить привязку»** в меню
> заголовка колонки или сохраните включенное правило. Постоянного слежения за папкой нет.

## Связь

Ссылка на записи другой коллекции — в том числе в **другой базе данных**.

| Настройка | Что задает |
|---|---|
| Целевая база | база, где лежит нужная коллекция |
| Целевая коллекция | куда ссылаемся |
| Показывать свойство | значение какого столбца видно в ячейке связи |
| Искать по свойству | по какому столбцу искать нужную запись |
| Режим связи | ручной выбор или автоматический подбор по совпадению свойств |
| Количество связей | «Одну» или «Несколько» |
| Разделитель названий | как перечисляются названия связанных записей |

**Ручной выбор.** Выберите свойства для поиска и показа, затем нажмите **«Сохранить»**.
Например, клиента можно искать по ИНН, а в ячейке показывать компанию. В списке рядом с
выбранным свойством остается название записи, чтобы различать совпадающие значения.
Связь ведет к самой записи: изменение ее названия или ИНН не выбирает другого клиента.
Нажатие на связанную запись открывает ее; без права изменения связи доступны только для чтения.

**Связь с другой базой.** Цель может лежать в другой базе — SQLite или PostgreSQL. Связь
работает одинаково на всех компьютерах, где открыты обе базы, и сохраняется, если базу отключить
и подключить снова или перенести ее файл в другую папку. Пока база недоступна, в ячейке видно
«(база недоступна)», а сами связи остаются на месте.

Если связи сделаны прежней версией программы на другом компьютере и базу здесь определить не
удалось, в ячейке видно **«(база не определена)»**. Откройте окно свойства, выберите
**«Целевая база»** и нажмите **«Сохранить»** — программа проверит, что все связанные записи
есть в выбранной базе.

**Автоматический режим.** Выберите **«Автоматически по совпадению свойств»**, затем
**«Свойство этой коллекции»** и **«Совпадает со свойством целевой коллекции»**.
Например, `Заказы.ИНН` сопоставляется с `Клиенты.ИНН`. По **«Сохранить»** программа сначала
покажет число добавлений, изменений и очисток; **«Применить»** сохраняет настройку и результат
вместе. Отмена ничего не меняет. Повторное сохранение заново проверяет данные.

Сравнение точное и учитывает тип: формат показа числа не влияет на результат, у текста
учитывается регистр. Мультисписки и наборы файлов сравниваются целиком; у файла учитывается
полный путь, у пользователя — сохраненное имя. Пустые значения не связываются.
В режиме **«Одну»** несколько совпадений считаются неоднозначностью: прежние связи остаются
на месте. В режиме **«Несколько»** подбираются все подходящие записи. Автоматические связи
нельзя менять вручную; изменение значений источника или цели запускает повторный подбор.
Недоступная база, отказ доступа или ошибка чтения не очищают прежние связи.

**Вывод других свойств цели.** Создайте **«Свойство связанной записи»**, выберите поле-связь
и нужный столбец цели, например телефон клиента. Значение обновляется из связанной записи;
при нескольких целях выводятся их значения. Сортировка идет по показанному тексту.

**Итоги.** Создайте **«Итог по связанным записям»** и выберите **«Количество»**, **«Сумма»**,
**«Среднее»**, **«Минимум»** или **«Максимум»**. Для числового итога выберите числовое свойство
цели. Итоги пересчитываются и сортируются как числа; редактировать их вручную нельзя.

Дублирование поля сохраняет его связи. При дублировании коллекции или группы внутренние
ссылки ведут в копию, внешние — к прежним целям. Табличная выгрузка показывает значения
связей; JSON-выгрузка коллекции со связями дополнительно сохраняет структуру и ссылки для
обратного импорта. Неопределенные внешние цели не восстанавливаются по случайно совпавшему ID.

## Пользователь

Значение — человек из списка пользователей базы.

Тумблер **«Добавить в раздел задач»** превращает коллекцию в источник задач: **все ее
записи** попадают в раздел «Задачи», а это свойство становится исполнителем (пустое
значение показывается прочерком). При первом включении программа сама создает свойства
**«Назначил»**, **«Статус»**, **«Дата»** и **«Описание»** — без них задача неполная.

Исполнитель у коллекции только один: пока тумблер стоит на одном свойстве, у остальных
свойств типа «Пользователь» он недоступен, и окно называет текущего носителя роли.

## Свойство «Название»

Системное: есть у каждой коллекции. Его можно переименовать, но нельзя удалить
и нельзя сменить ему тип.

## Смена типа

Тип меняется в окне «Изменение свойства». Значения по возможности сохраняются:
например, «Текст ↔ Дата» конвертируется без потери. Если значение не подходит
новому типу, оно остается как есть и показывается без форматирования.

У связи смена типа выполняется с проверкой: переход в текст сохраняет показанные значения,
обратный переход требует однозначного сопоставления целей. Неоднозначность отменяет
преобразование. Чтобы включить **«Одну»** при нескольких сохраненных целях, сначала оставьте
по одной связи. Смена целевой коллекции у заполненного ручного поля требует очистки связей.

**Свойство, привязанное к календарю или задачам, теряет привязку.** Роль работает только
на своем типе: «Статус» — на «Списке» или «Статусе», «Исполнитель» и «Назначил» — на
«Пользователе», срок — на «Дате», «Описание» — на «Тексте». Перед сохранением программа
предупредит, что именно перестанет отображаться в разделе. **Значения столбца при этом
остаются на месте** — теряется только показ в календаре или задачах. Вернуть привязку
обратной сменой типа нельзя: ее вернет следующее создание записи из раздела.
