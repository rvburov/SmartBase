# Задачи

Раздел собирает задачи из всех коллекций, отмеченных галочкой в боковой панели,
и группирует их по коллекциям.

## Откуда берутся задачи

Задачами становятся **все записи коллекции**, в которой есть свойство типа
**«Пользователь»** с включенным тумблером **«Добавить в раздел задач»** — это свойство
и есть исполнитель. Заполнять его не обязательно: запись без исполнителя тоже видна
в списке, в строке карточки стоит прочерк «—». Так нераспределенная работа не теряется:
ее видно и можно раздать.

При первом включении программа сама заводит спутников: **«Назначил»**, **«Статус»**,
**«Дата»** (срок) и **«Описание»**.

Чтобы завести задачи в своей коллекции:

1. Создайте свойство типа «Пользователь», включите «Добавить в раздел задач».
2. Отметьте коллекцию галочкой в боковой панели раздела «Задачи».

Свойство «Дата» для срока появится само — как и остальные спутники.

> **Исполнитель в коллекции только один.** Пока тумблер стоит на одном свойстве,
> у остальных он недоступен. Чтобы передать роль другому свойству, сначала снимите
> переключатель с текущего.

Если коллекций-источников несколько, задачи из них показываются вместе, каждая
под заголовком своей коллекции.

## Быстрое добавление

Строка вверху списка: название → **Enter** (или кнопка **«Добавить»**). Рядом —
поля «Срок», «Исполнитель» и «Коллекция», чтобы не открывать окно задачи.

## Фильтры

В верхней панели — список фильтров со счетчиками; счетчик считается по текущему
набору коллекций и поиску.

| Фильтр | Что показывает |
|---|---|
| Все задачи | все |
| Сегодня | задачи, у которых сегодняшний день попадает в срок |
| Мне назначено | задачи, где исполнитель — вы |
| Без срока | задачи без даты начала |
| Просрочено | срок истек, а статус не «Выполнено» |
| Выполнены | статус «Выполнено» |

Рядом с фильтрами — поле **«Поиск...»** по названию задачи.

## Статусы

Три состояния: **«Запланировано»**, **«В работе»**, **«Выполнено»**. Меняются
в окне задачи или прямо в таблице коллекции.

> **Приоритетов у задач нет.** Если нужна важность — заведите в коллекции свое
> свойство типа «Список» и фильтруйте по нему в таблице.

## Группировка и сроки

Задачи сгруппированы по коллекциям в том же порядке, что и в боковой панели;
записи без коллекции — в конце. Внутри группы сортировка по сроку, задачи без даты
уходят вниз.

Клик по заголовку группы сворачивает ее; рядом показан счетчик вида «N из M».

Срок отмечен чипом: «Сегодня», «Осталось N дн.», «Просрочено на N дн.», «без даты».

## Действия над задачей

| Действие | Как выполнить |
|---|---|
| Открыть | двойной клик по карточке |
| Изменить | правый клик → «Изменить» |
| Дублировать | правый клик → «Дублировать» |
| Удалить | **Delete** или **Backspace**, либо правый клик → «Удалить» |

Выделение: **клик**, **Shift + клик** — добавить или снять, **Ctrl + Shift + клик** —
диапазон. Действие применяется ко всему выделению.

## Окно задачи

| Поле | Что задает |
|---|---|
| Название | имя задачи |
| Статус | состояние |
| Исполнитель | кто делает |
| Назначил | кто поставил |
| «Без даты» / «Весь день» | признаки срока |
| Начало / Конец | срок |
| База данных, Коллекция | где лежит задача |
| Описание | текст в Markdown |

> **Задачу без срока нельзя перенести в другую коллекцию.** Сначала задайте дату,
> потом меняйте коллекцию.

## Задачи и календарь — одни и те же записи

Задача со сроком одновременно является событием календаря. Изменение срока в одном
разделе тут же видно в другом — см. [[calendar]].
