# Календарь

Календарь показывает записи, у которых заполнено свойство типа «Дата» с включённым
тумблером **«Отображать в календаре»**. Такая запись называется событием.

В календарь попадают коллекции, отмеченные галочкой в боковой панели, — из всех
подключённых баз данных сразу. Цвет события — цвет его коллекции.

> **У одной записи может быть несколько событий.** Если у коллекции несколько
> свойств-дат, запись видна в календаре столько раз, сколько дат заполнено. Какие
> поля-даты показывать, задаётся в сайдбаре: правый клик по коллекции →
> «Отображение свойств даты».

## Верхняя панель

| Элемент | Назначение |
|---|---|
| **+** | создать событие |
| «Сегодня» | вернуться к текущей дате |
| ← / → | предыдущий и следующий период |
| Заголовок | текущий период |
| «Поиск...» | отбор событий по названию |
| Переключатель вида | выбор режима |

## Режимы

| Режим | Что показывает |
|---|---|
| **Расписание** | дела одного дня списком |
| **Журнал** | лента по дням с прокруткой к сегодня |
| **День** | сетка часов и полоса «весь день» сверху |
| **Неделя** | семь колонок Пн–Вс, сетка часов и полоса «весь день» |
| **Месяц** | классическая сетка (открывается по умолчанию) |
| **Год** | 12 мини-месяцев, дни с событиями подсвечены |
| **Диаграмма** | полосы длительности по коллекциям |

Какие режимы показывать в переключателе — «Настройки → Оформление».

### Переходы между режимами

- **Месяц**: двойной клик по числу или ячейке — перейти в «День».
- **Год**: клик по числу — список событий дня; двойной клик по месяцу — перейти в «Месяц».
- **Диаграмма**: кнопки **«−»** и **«+»** меняют масштаб — месяц, год, 5 лет, 10 лет.

## Создать событие

| Способ | Где работает |
|---|---|
| Кнопка **«+»** в верхней панели | везде |
| Двойной клик по пустому месту | Расписание, Журнал |
| Двойной клик по свободному слоту времени | День, Неделя (округляется до 30 минут) |
| Клик по **«+»** в кружке числа | Месяц (появляется при наведении) |
| Клик по полосе «весь день» | День, Неделя |
| Правый клик по пустому месту → «Создать запись» | везде |

## Действия над событием

| Действие | Как выполнить |
|---|---|
| Открыть | двойной клик по событию |
| Изменить | правый клик → «Изменить» |
| Дублировать | правый клик → «Дублировать» |
| Удалить | **Delete** или **Backspace**, либо правый клик → «Удалить» |
| Перенести | перетащить: в Месяце — на другой день, в Дне и Неделе — по времени и между днями, в Диаграмме — по дням |
| Изменить длительность | потянуть за край блока (День, Неделя, Диаграмма) |

Выделение: **клик** — одно событие; **Shift + клик** — добавить или снять;
**Ctrl + Shift + клик** — весь диапазон между событиями (Расписание, Журнал,
Диаграмма). Клик по пустому месту снимает выделение.

Дублирование и удаление действуют на всё выделение сразу; в подтверждении указано
количество. Для больших наборов показывается окно с прогрессом.

> **Удаляется вся запись, а не одна её дата.** Если у записи было несколько
> событий, исчезнут все.

## Окно события

Открывается по двойному клику или при создании.

| Поле | Что задаёт |
|---|---|
| Название | имя записи |
| «Весь день» | событие без времени |
| Начало / Конец | дата и время |
| База данных | в какой базе лежит запись (если баз несколько) |
| Коллекция | к какой коллекции относится |
| Дата записи | в какое свойство-дату записать дату |
| Описание | текст в Markdown |

Кнопки: **«Удалить»** (только при изменении), **«Отмена»**, **«Сохранить»**.

> **Смена коллекции или базы — это перенос записи.** Значения свойств переносятся
> по совпадению названий; свойств, которых нет в целевой коллекции, программа
> не создаёт — эти значения будут потеряны.

Перенос даты в другое свойство делается списком **«Дата записи»**: старое поле
очищается, новое заполняется.

## Уведомления

Если в «Настройки → Общее» включены **«Уведомления календаря»**, в момент начала
события появляется системное уведомление, а на значке программы — число напоминаний.
Клик по уведомлению открывает окно **«Напоминание»** с названием, временем,
коллекцией и описанием; кнопка **«Принято»** его закрывает.

Пропущенных событий много — программа покажет одну сводку вместо потока окон.

Чтобы напоминания приходили при закрытом окне, включите **«Фоновый режим»**, а чтобы
не запускать программу вручную — **«Автозапуск при входе в систему»**; см. [[settings]]
и [[install-update]].

> **Повторяющихся событий в программе нет.** Каждое событие — отдельная запись;
> повторы заводятся копированием («Дублировать») с изменением даты.
