# Календарь

Календарь показывает записи, у которых заполнено свойство типа «Дата» с включенным
тумблером **«Отображать в календаре»**. Такая запись называется событием.

В календарь попадают коллекции, отмеченные галочкой в боковой панели, — из всех
подключенных баз данных сразу. Цвет события — цвет его коллекции.

> **У одной записи может быть несколько событий.** Если у коллекции несколько
> свойств-дат, запись видна в календаре столько раз, сколько дат заполнено. Какие
> поля-даты показывать, задается в сайдбаре: правый клик по коллекции →
> «Отображение свойств даты».

## Верхняя панель

| Элемент | Назначение |
|---|---|
| **+** | создать событие |
| «Сегодня» | вернуться к текущей дате |
| ← / → | предыдущий и следующий период |
| Заголовок | текущий период |
| «Поиск...» | отбор событий по названию |
| Переключатель вида | выбор режима |

## Режимы

| Режим | Что показывает |
|---|---|
| **Расписание** | дела одного дня списком |
| **Журнал** | лента по дням с прокруткой к сегодня |
| **День** | сетка часов и полоса «весь день» сверху |
| **Неделя** | колонки дней (Пн–Вс или Пн–Пт при пятидневке), сетка часов и полоса «весь день» |
| **Месяц** | классическая сетка (открывается по умолчанию) |
| **Год** | 12 мини-месяцев, дни с событиями подсвечены (у записи на несколько дней подсвечен весь ее диапазон, чем больше событий в дне — тем насыщеннее цвет) |
| **Диаграмма** | полосы длительности по коллекциям |

Какие режимы показывать в переключателе и какой открывается по умолчанию — раздел
«Настройки → Календарь». Там же настраиваются рабочая неделя (7 или 5 дней), рабочие
часы дня, прокрутка недели и длительность нового события — подробности в [[settings]].

### Пятидневка и рабочие часы

При **«Дней в неделе: 5»** режимы «Расписание», «День» и «Неделя» листают только Пн–Пт,
многодневные события во всех режимах обходят выходные, а перетягивание и растягивание
перепрыгивает их: тянете событие за пятницу — оно продолжается с понедельника, событие
через полночь пятницы заканчивается уже в понедельнике. «Месяц», «Год» и «Журнал»
показывают выходные с их событиями, но новые записи на выходные не попадают — создание
с субботы или воскресенья предлагает понедельник, а выходные даты в календаре окна
записи не кликаются.

Если заданы **рабочие часы** (например, 09:00–18:00), границы дня работают как полночь:
хвост перетягивания и растягивания за конец дня продолжается с начала следующего —
двухчасовое событие, поставленное в 17:00, закончится в 10:00 следующего дня (при
пятидневке с пятницы — в понедельник) и нарисуется двумя блоками: 17:00–18:00 и
09:00–10:00, ночные часы между ними не закрашиваются. Растягивать можно и дальше, на
несколько дней: событие остается в часовой сетке блоками по дням (серединные дни заняты
целиком рабочими часами), в полосу «весь день» оно не уходит. В окне записи времена вне
периода гаснут в выпадающем списке. Шкала часов показывается целиком, существующие
события вне периода остаются на своих местах.

**Прокрутка недели** кнопками ← / → настраивается там же: по целой неделе (стандарт),
по одному дню, либо по неделе с остановкой на «Сегодня» — шаг через сегодняшний день
сначала ставит его в середину окна.

### Переходы между режимами

- **Месяц**: двойной клик по числу или ячейке — перейти в «День».
- **Год**: клик по числу — список событий дня; двойной клик по месяцу — перейти в «Месяц».
- **Диаграмма**: кнопки **«−»** и **«+»** меняют масштаб — месяц, год, 5 лет, 10 лет.

### Диаграмма: коллекции

Слева — список коллекций, справа — полосы длительности. Коллекции **открываются
свернутыми**: видно строку коллекции, счетчик записей и общую полосу от самого
раннего события до самого позднего. Клик по строке раскрывает записи, повторный —
сворачивает; стрелка слева показывает состояние.

Свернутость держится, пока вы работаете с текущим периодом; листание на другой
месяц сворачивает коллекции снова. При поиске коллекции с совпадениями
раскрываются сами.

Событие на шкале — **кружок** в начале и полоса, дорастающая вправо на всю
длительность. Чем крупнее масштаб, тем короче полоса: на «10 годах» несколько
дней занимают доли пикселя, поэтому от события всегда остается хотя бы кружок —
событие видно на любом масштабе, а точную длительность показывает подпись рядом.
Кружок без полосы переносится мышью целиком, но не растягивается за края —
для этого уменьшите масштаб.

## Создать событие

| Способ | Где работает |
|---|---|
| Кнопка **«+»** в верхней панели | везде |
| Двойной клик по пустому месту | Расписание, Журнал |
| Двойной клик по свободному слоту времени | День, Неделя (округляется до 30 минут) |
| Клик по **«+»** в кружке числа | Месяц (появляется при наведении) |
| Клик по полосе «весь день» | День, Неделя |
| Правый клик по пустому месту → «Создать запись» | везде |

## Действия над событием

| Действие | Как выполнить |
|---|---|
| Открыть | двойной клик по событию |
| Изменить | правый клик → «Изменить» |
| Дублировать | правый клик → «Дублировать» |
| Удалить | **Delete** или **Backspace**, либо правый клик → «Удалить» |
| Перенести | перетащить: в Месяце — на другой день, в Дне и Неделе — по времени и между днями, в Диаграмме — по дням |
| Изменить длительность | потянуть за край блока (День, Неделя, Диаграмма) |

Выделение: **клик** — одно событие; **Shift + клик** — добавить или снять;
**Ctrl + Shift + клик** — весь диапазон между событиями (Расписание, Журнал,
Диаграмма). Клик по пустому месту снимает выделение.

Дублирование и удаление действуют на все выделение сразу; в подтверждении указано
количество. Для больших наборов показывается окно с прогрессом.

> **Удаляется вся запись, а не одна ее дата.** Если у записи было несколько
> событий, исчезнут все.

## Окно события

Открывается по двойному клику или при создании.

| Поле | Что задает |
|---|---|
| Название | имя записи |
| «Весь день» | событие без времени |
| Начало / Конец | дата и время |
| База данных | в какой базе лежит запись (если баз несколько) |
| Коллекция | к какой коллекции относится |
| Дата записи | в какое свойство-дату записать дату |
| Описание | текст в Markdown |

Кнопки: **«Удалить»** (только при изменении), **«Отмена»**, **«Сохранить»**.

> **Смена коллекции или базы — это перенос записи.** Значения свойств переносятся
> по совпадению названий; свойств, которых нет в целевой коллекции, программа
> не создает — эти значения будут потеряны.

Перенос даты в другое свойство делается списком **«Дата записи»**: старое поле
очищается, новое заполняется.

## Уведомления

Если в «Настройки → Общее» включены **«Уведомления календаря»**, в момент начала
события появляется системное уведомление, а на значке программы — число напоминаний.
Клик по уведомлению открывает окно **«Напоминание»** с названием, временем,
коллекцией и описанием; кнопка **«Принято»** его закрывает.

Пропущенных событий много — программа покажет одну сводку вместо потока окон.

Этот переключатель отвечает только за напоминания о событиях. Уведомления о том, что вам
назначили задачу или что у задачи сменилась стадия, включаются отдельно — см. [[tasks]].

Чтобы напоминания приходили при закрытом окне, включите **«Фоновый режим»**, а чтобы
не запускать программу вручную — **«Автозапуск при входе в систему»**; см. [[settings]]
и [[install-update]].

> **Повторяющихся событий в программе нет.** Каждое событие — отдельная запись;
> повторы заводятся копированием («Дублировать») с изменением даты.
