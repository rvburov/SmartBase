# Обзор программы

SmartBase — планировщик поверх конструктора данных. Вы сами описываете, что хотите
хранить (какие таблицы и какие колонки в них), а программа показывает эти данные
с разных сторон: таблицей, календарем и списком задач.

> **Одна запись — три взгляда.** Строка таблицы, у которой заполнена дата, — это
> событие календаря. Она же, если у нее есть исполнитель, — карточка в разделе
> «Задачи». Данные одни, представления разные.

## Из чего состоит окно

| Зона | Где | Что делает |
|---|---|---|
| Панель активности | узкая полоса слева | переключение разделов программы |
| Боковая панель (сайдбар) | рядом с панелью активности | дерево баз, групп и коллекций либо список разделов |
| Верхняя панель (навбар) | сверху | заголовок, поиск, переключатель вида, кнопки раздела |
| Рабочая область | центр | таблица, календарь, список задач |
| Страница записи | справа | свойства выбранной записи и ее описание |
| Нижняя строка | снизу | счетчик записей и постраничная навигация |

## Разделы программы

Кнопки панели активности сверху вниз:

| Кнопка | Раздел |
|---|---|
| Боковая панель | показать или скрыть сайдбар |
| Календарь | события всех отмеченных коллекций в семи режимах |
| Задачи | задачи всех отмеченных коллекций с фильтрами и сроками |
| Конструктор базы данных | таблицы: записи, свойства, фильтры |
| Расширения | встроенные обработчики файлов |
| Заметки | папка с файлами Markdown на компьютере: дерево, редактор, просмотр |
| Профиль | ваши данные, права доступа, история изменений |
| Настройки | параметры программы и эта инструкция |

Наведите указатель на кнопку — появится подпись.

## Первый запуск

На чистой установке программа создает коллекцию **«Задачи»** с вводным чек-листом:
по одной задаче на каждый раздел, со сроком, исполнителем и описанием того, что
в разделе можно сделать.

Это обычные записи — правьте, переносите и удаляйте их как свои. Одна и та же задача
видна сразу в трех разделах: в календаре, в задачах и в таблице коллекции.

> **Чек-лист не возвращается.** Если вы его удалили, следующий запуск ничего
> не создаст заново. К базам, которые уже существовали, чек-лист не добавляется.

## С чего начать

1. Откройте **Конструктор базы данных** и создайте свою коллекцию — см. [[data-structure]].
2. Добавьте в нее свойства нужных типов — см. [[properties]].
3. Заполните записи в таблице — см. [[table]].
4. Отметьте коллекцию галочкой в сайдбаре разделов **Календарь** и **Задачи**, чтобы
   ее записи появились там — см. [[calendar]] и [[tasks]].

## Где хранятся данные

Данные лежат в файле базы данных на вашем компьютере. Программа не требует интернета
и ничего никуда не отправляет. Баз может быть несколько, в том числе на сервере
PostgreSQL — см. [[settings]] и [[postgresql]].

Путь к папке с данными показан в «Настройки → О программе → Папка с данными».
