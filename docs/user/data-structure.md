# Базы, группы, коллекции и записи

## Из чего состоят данные

| Что | Это | Пример |
|---|---|---|
| **База данных** | файл `.db` на диске или подключение к серверу PostgreSQL | «Работа», «Личное» |
| **Группа** | папка для коллекций, может быть вложенной | «Проекты 2026» |
| **Коллекция** | таблица | «Задачи», «Договоры», «Оборудование» |
| **Запись** | строка коллекции | один договор |
| **Свойство** | колонка коллекции | «Срок», «Статус», «Ответственный» |

Баз данных может быть подключено несколько одновременно — в сайдбаре каждая
показана своим корневым узлом. Подключение и отключение баз — в [[settings]].

## Боковая панель

В разделе **Конструктор базы данных** сайдбар показывает дерево: база → группы →
коллекции. Клик по коллекции открывает ее в рабочей области.

В разделах **Календарь** и **Задачи** у каждой коллекции появляется галочка: снятая
галочка убирает записи коллекции из раздела. Состояние галочек сохраняется
до следующего запуска.

### Кнопки над деревом

| Кнопка | Действие |
|---|---|
| Создать | окно «Создать»: тип (коллекция или группа), название, база данных, расположение |
| Развернуть все / Свернуть все | раскрыть или закрыть все дерево |
| Сортировка | переключается по кругу: по порядку → **А → Я** → **Я → А** |
| Включить все / Выключить все | снять или поставить все галочки (только в Календаре и Задачах) |
| Импорт/Экспорт | окно обмена файлами — см. [[import-export]] |

## Создать коллекцию или группу

1. Нажмите **«Создать»** над деревом (или правый клик по пустому месту →
   «Создать коллекцию» / «Создать группу»).
2. Выберите тип, введите название.
3. Укажите базу данных и расположение — корень базы или существующую группу.

Новая коллекция открывается сразу и содержит одно свойство — «Название».

## Действия над коллекцией и группой

Правый клик по строке дерева:

| Пункт | Что делает |
|---|---|
| Изменить | переименовать |
| Расположение | перенести в другую группу или **в другую базу данных** |
| Дублировать | копия со всеми свойствами и записями |
| Удалить | удаляет вместе со всеми записями, спрашивает подтверждение |
| Изменить цвет | цвет коллекции в календаре и задачах (только в этих разделах) |
| Отображение свойств даты | какие поля-даты этой коллекции показывать в календаре |
| Отображение свойств исполнителя | какие поля-пользователи считать исполнителем задачи |

> **Перенос между базами — это копирование и удаление.** Коллекция сначала
> копируется в целевую базу, потом удаляется из исходной. На больших коллекциях
> это занимает время; окно с прогрессом показывает ход. Пока идет копия, в исходную
> базу записать нельзя, а целевой можно пользоваться. Если программу закрыть посреди
> копии, недописанная копия удалится при следующем подключении базы; если посреди
> удаления из исходной базы — при следующем подключении исходной базы удалится ее
> остаток, а полная копия останется в целевой.

## Выделение и удаление

- **Клик** — открыть коллекцию.
- **Shift + клик**, **Ctrl + клик** — добавить или снять строку из выделения.
- **Delete** — удалить все выделенное; в подтверждении указано количество.

Групп и коллекций можно выделить сразу несколько — действие применится ко всем.

> **Перетаскивания в дереве нет.** Чтобы переместить коллекцию или группу,
> используйте пункт «Расположение».

## Порядок в дереве

Порядок задается кнопкой сортировки над деревом: собственный порядок, по алфавиту
от А до Я или от Я до А. Выбранный режим действует на все дерево.
