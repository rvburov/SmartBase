# Настройки

Раздел открывается кнопкой **«Настройки»** внизу панели активности. Слева — список
разделов, справа — их содержимое.

## Общее

Три независимых переключателя.

| Переключатель | Что делает |
|---|---|
| **Уведомления календаря** | системное уведомление в момент начала события; на значке программы — число напоминаний |
| **Автозапуск при входе в систему** | программа стартует сама при входе, чтобы напоминания приходили без ручного запуска |
| **Фоновый режим** | закрытие окна не завершает программу: она сворачивается в значок системной области и продолжает работать |

При включенном фоновом режиме окно возвращается кликом по значку, а завершает
программу пункт **«Выход»** в его меню.

> **Автозапуск доступен только установленной программе.** Если вы запустили копию
> из произвольной папки или сборку для разработки, переключатель серый: распоряжаться
> автозапуском вправе только установленная копия, иначе при входе в систему
> запускалась бы не та программа. Подробности — [[install-update]].

## Оформление

Настройки идут двумя группами: сначала **что открывается по умолчанию**, затем **что вообще
показывать**.

### Что открывается по умолчанию

| Настройка | Что задает |
|---|---|
| Отображение по умолчанию раздела навигации | какой раздел открывается при запуске программы |
| Отображение по умолчанию раздела календаря | какой из режимов открывается при переходе в календарь |
| Отображение по умолчанию раздела задач | какой вид открывается при переходе в задачи |
| Отображение по умолчанию раздела конструктора | какой вид открывается в конструкторе. Если у коллекции выбран свой вид, он сохраняется за ней |

В этих списках предлагаются **только показываемые** пункты: вид, скрытый галочкой ниже,
стартовым выбрать нельзя.

### Что показывать

| Настройка | Что задает |
|---|---|
| Отображение раздела навигации | какие разделы показывать в панели слева |
| Отображение раздела календаря | какие режимы показывать в переключателе календаря |
| Отображение раздела задач | какие виды показывать в переключателе задач |
| Отображение раздела конструктора | какие виды коллекции показывать в конструкторе |

Каждая из них — выпадающий список с галочками: снимите галочку, и пункт исчезнет из
переключателя. На кнопке видно, сколько пунктов показано.

Два правила, о которых стоит знать заранее:

- **Последнюю галочку снять нельзя.** Раздел без единого вида работать не может, поэтому у
  последнего оставшегося пункта галочка становится неактивной.
- **Скрыли пункт, который стоял «по умолчанию»** — умолчание само переедет на первый
  оставшийся. Настройка не будет указывать на то, чего вы больше не видите.

**«Настройки» и «Профиль» скрыть нельзя** — иначе, спрятав настройки, вернуть их было бы
неоткуда.

### Масштаб и шрифт

| Настройка | Что задает |
|---|---|
| **Уровень масштабирования** | размер всего интерфейса: 70–130 %, шаг 10 % |
| **Размер шрифта** | текст крупнее или мельче: от −3 до +3 пикселей |

У обеих шкал есть кнопка **«Сбросить»**.

> **Темной темы в программе нет** — оформление ограничено масштабом и размером шрифта.

## Управление базой данных

Список подключенных баз: название, путь, метки «PostgreSQL» и «По умолчанию», статус.

| Кнопка | Действие |
|---|---|
| «Добавить базу данных» (в верхней панели) | меню: «Создать базу данных SQLite», «Подключить базу данных SQLite», «Подключить сервер PostgreSQL» |
| «Подключить заново» | вернуть базу, ставшую недоступной |
| «Отключить (файл не удаляется)» | убрать базу из программы |

**Создать базу данных SQLite** — окно с названием и папкой: программа создает новый
файл `.db`. Занятое имя дает ошибку, перезаписи существующего файла не бывает.

**Подключить базу данных SQLite** — выбор существующего файла, в том числе из сетевой
папки. Уже подключенный файл повторно не добавляется.

**Подключить сервер PostgreSQL** — см. [[postgresql]].

> **Отключение не удаляет данные.** Файл `.db` остается на диске, данные на сервере
> PostgreSQL — на сервере. Базу по умолчанию отключить нельзя.

Подключение идет в фоне: программа не блокируется, статус виден в строке списка.

## Расширения

Раздел собирает настройки тех расширений, которым есть что запоминать между запусками. Если
расширению настройки не нужны, его в списке не будет. Расширение, убранное из программы,
пропадает отсюда вместе со своими настройками — ничего вычищать вручную не требуется.

Сейчас здесь два расширения — **«Сравнение составов изделий»** и **«Расчет сборочных
единиц»**. Каждому нужен **файл-шаблон**: готовая книга `.xlsm`, в которую записывается
результат. Изначально поля пустые.

Заполнять их вручную не обязательно: проще один раз выбрать шаблон кнопкой **«Обзор»** прямо
в окне расширения — путь запомнится сам и подставится при следующем открытии. Поля здесь
нужны, чтобы посмотреть текущий путь, поправить его или очистить.

Программа не проверяет файл заранее — сетевая папка может быть временно недоступна. Если к
моменту запуска шаблона на месте нет, расширение сообщит «Файл-шаблон не найден».

Подробнее о самих расширениях — [[extensions]].

## Инструкция пользователя

Этот самый текст. Слева — документ, справа — панель **«Содержание»**: клик по пункту
прокручивает к нужному месту. Ширина панели меняется ручкой у ее левого края.

## Диагностика

Журнал работы программы — то, что нужно приложить к обращению, если что-то пошло не так.

| Колонка | Что показывает |
|---|---|
| Время | когда произошло |
| Уровень | важность записи |
| Сообщение | что произошло |
| Ошибка | техническая расшифровка, если она есть |

Колонки фильтруются и сортируются так же, как в таблице коллекции — см.
[[filters-sorting]]. Клик по строке открывает панель **«Детали»** с полным текстом,
его можно скопировать. Кнопка в верхней панели выгружает журнал в CSV.

Очистка журнала и автоочистка — в разделе «Профиль», см. [[profile-access]].

## О программе

| Блок | Что показывает |
|---|---|
| Версия | номер версии и дата сборки |
| Обновления | путь к папке обновлений, кнопка «Проверить», переключатель «Автообновление» |
| Папка с данными | где лежат файлы программы, кнопка «Открыть» |
| Система | операционная система и платформа |

Подробнее об обновлении — [[install-update]].

## Что программа помнит сама

Часть состояния сохраняется без всяких настроек: выбранный вид календаря и
конструктора, ширина панелей, галочки коллекций в разделах «Календарь» и «Задачи»,
порядок и ширина колонок каждой коллекции.
