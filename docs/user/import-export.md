# Импорт и экспорт

Окно открывается кнопкой **«Импорт/Экспорт»** над деревом в боковой панели.
Переключатель **«Режим»** вверху выбирает направление: импорт или экспорт.

## Импорт

Создает коллекцию из файла.

| Поле | Что задает |
|---|---|
| Файл | путь к файлу, кнопка «Обзор…» |
| «Все файлы из папки (включая подпапки)» | импортировать пачкой; на каждый файл — своя коллекция |
| Название коллекции | как назвать результат |
| База данных | куда положить |
| Расположение | корень базы или группа |
| Тип импорта | «Стандартный» или «Ручной (только Excel)» |

Поддерживаются Excel (`.xlsx`, `.xlsm`, `.xlsb`, `.xls`), CSV и JSON.

### Стандартный импорт

| Формат | Как разбирается |
|---|---|
| Excel | берется первый лист; первая строка — заголовки колонок; первый столбец — название записи; данные со второй строки |
| CSV | так же; разделитель и кодировка определяются автоматически |
| JSON | ключи объектов становятся свойствами; название берется из ключа «Название», `name` или `title` |

Все колонки создаются свойствами типа «Текст» — нужные типы назначаются после
импорта в окне свойства (см. [[properties]]).

Скрытые строки, столбцы и листы Excel импортируются наравне с видимыми.
Пустой заголовок колонки или пустое название записи заменяются на «Без названия»
с номером — строки не пропускаются.

### Ручной импорт Excel

Нужен, когда таблица не начинается с первой строки или в ней есть лишние листы.

| Параметр | Что задает |
|---|---|
| Лист | имя листа |
| Строка заголовков | номер строки с названиями колонок |
| Строка данных | с какой строки начинаются записи |
| Столбец названия | какой столбец становится названием записи |
| Исключить столбцы / строки / листы | что пропустить |
| Все листы в одну коллекцию / в разные | как разложить многолистовую книгу |

## Экспорт

Выгружает коллекции в файл.

| Поле | Что задает |
|---|---|
| Выгрузить в папку | куда сохранить |
| Название файла | имя результата |
| Формат файла | `.xlsx`, `.xlsm`, `.csv`, `.json` |
| Коллекция | выбор нескольких: поиск, «(Выделить все)», «Готово» |
| Тип экспорта | «Стандартный» или «Ручная выгрузка Excel» |

Параметры ручной выгрузки: имя листа, исключаемые столбцы, а также флажки
**«Без строки заголовков»**, **«Включать скрытые записи и столбцы»** и
**«Все коллекции в один файл (лист на коллекцию)»**.

По завершении папка с результатом открывается автоматически.

**Выгрузка оставляет след.** Каждый созданный файл записывается в журнал безопасности: кто, когда,
какие коллекции, сколько записей, куда лег файл и его отпечаток. Сами данные туда не попадают —
только названия столбцов. Смотреть его — «Настройки» → «Интеграции» → «Журнал» → «Безопасность»
(см. [[settings]]). Это не ограничение, а память: метка «Закрытый контур» у базы закрывает ей
отправку по сети, но выгружать в файл и печатать отчеты по-прежнему можно.

## Ход выполнения и отмена

Длинные операции показывают окно с прогрессом. У импорта есть кнопка **«Отмена»**:
недописанная коллекция удаляется целиком, уже готовые остаются.

При ошибке окно «Импорт/Экспорт» открывается заново с прежними значениями,
а текст ошибки показан в баннере.

## Частые сообщения

| Ситуация | Что делать |
|---|---|
| «Файл … занят другой программой» | закройте файл и повторите |
| «Нет прав доступа к …» | выберите другую папку или измените разрешения |
| «… — нет данных для импорта» | файл или лист пуст — проверьте номер строки данных |
| «Формат файла не поддерживается» | сохраните исходник в один из поддерживаемых форматов |
| «Недостаточно места на диске» | освободите место; частичные данные уже удалены |
| «Все столбцы коллекции … исключены» | снимите лишние исключения в ручном режиме |
| «Недостаточно прав: просмотр коллекции … запрещен» | обратитесь к администратору базы — см. [[profile-access]] |
| «Журнал безопасности не открылся, и выгрузка отменена» | сообщите ответственному за интеграции: без журнала файл с данными не создается |

## Перенос коллекции в другую базу

Копировать через файл не нужно: правый клик по коллекции в боковой панели →
**«Расположение»** → выберите другую базу данных. См. [[data-structure]].
