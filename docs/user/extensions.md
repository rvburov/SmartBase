# Расширения

Расширения — встроенные обработчики файлов для инженерных задач: они читают папку
с документами и выдают отчёт или новую коллекцию.

Раздел открывается кнопкой **«Расширения»** в панели активности. Слева — список
расширений, справа — описание выбранного, в верхней панели — кнопка **«Запустить»**.

## Встроенные расширения

| Расширение | Что делает |
|---|---|
| **Переименование PDF** | пакетно переименовывает PDF-файлы по правилу «оставить часть имени до первого пробела» |
| **Сравнение составов изделий** | сравнивает два Excel-состава и выдаёт отчёт с различиями |
| **Расчёт сборочных единиц** | переносит данные списка КД и ТД в шаблон Excel с макросами |
| **Анализ PDF файлов** | обходит папку с PDF и собирает отчёт по ведомостям и описям документации |
| **Документы в коллекцию** | собирает файлы папки в новую коллекцию со свойствами «Наименование», «Название папки», «Формат файла», «Файл» |
| **Сводная трудоёмкость** | обходит папку с файлами расчётов и собирает из них сводную таблицу трудоёмкости в шаблон Excel с макросами |

## Как работать

1. Выберите расширение в списке слева.
2. Прочитайте описание — там указано, какие файлы и папки нужны.
3. Нажмите **«Запустить»** и укажите исходные файлы или папку.
4. Дождитесь окончания: ход работы виден в окне расширения.

Результат — файл отчёта в указанной папке либо новая коллекция в выбранной базе
данных (у расширения «Документы в коллекцию»).

> **Расширения работают с копиями данных.** Отчёты создаются отдельными файлами;
> исходные документы расширения не изменяют — кроме «Переименования PDF», которое
> по назначению меняет имена файлов на диске.

## Файл-шаблон

«Сравнение составов изделий», «Расчёт сборочных единиц» и «Сводная трудоёмкость» пишут результат
в готовый файл-шаблон `.xlsm`. При первом запуске поле **«Шаблон»** пустое — укажите файл кнопкой
**«Обзор»**. Выбранный путь запоминается и подставляется дальше сам; посмотреть, поменять или
очистить его можно в разделе **Настройки → Расширения** (см. [[settings]]).

Если к моменту запуска шаблона по сохранённому пути нет — например, сетевая папка сейчас
недоступна, — расширение сообщит «Файл-шаблон не найден».

## Сводная трудоёмкость

Заменяет кнопку **«Обновить»** в контекстном меню книги «Таблица трудоёмкости». Укажите папку
с расчётами (файлы вида `Проект_ГГГГ.ММ.ДД_ФИО.xlsm`), при необходимости включите
**«Рекурсивный поиск»**, выберите файл-шаблон с листом «Таблица» и папку для результата.

Расчёты читаются по четыре одновременно, поэтому сетевая папка обходится заметно быстрее, чем
из Excel. Ход работы виден на индикаторе: сколько файлов прочитано, какой обрабатывается сейчас
и сколько примерно осталось. Кнопка **«Остановить»** прерывает прогон — файл результата тогда
не создаётся.

### Что делать с журналом

По окончании в журнале появляется разбор файлов, с которыми что-то не так:

| Секция | Что означает | Что делать |
|---|---|---|
| ⚠️ **Открыты другим пользователем** | книга сейчас открыта в Excel у коллеги (по возможности указано, у кого) | ничего: данные прочитаны с диска, но без правок, которые коллега ещё не сохранил |
| ❌ **Не открылись** | файл повреждён, заблокирован другой программой или нет прав доступа | проверить файл вручную и повторить прогон |
| ⏭️ **Пропущены** | нет листа «Расшифровка», имя не по образцу `Проект_ГГГГ.ММ.ДД_ФИО.xlsm` или нет подходящих строк | переименовать файл или убрать его из папки, если он не расчёт |

Строки этих файлов (кроме открытых у коллег) в свод **не попали** — по журналу видно, чего
именно не хватает в результате.

### Результат

Файл `Трудоёмкость (ГГГГ-ММ-ДД_ЧЧ-ММ).xlsm` в выбранной папке: свод отсортирован по обозначению,
дате и наименованию; одинаковые обозначения идут группами с чередующейся заливкой, а расхождения
трудоёмкости выделены красным. Колонка **«Ссылка»** открывает исходный расчёт на нужной строке.
