# Страница записи

Панель справа показывает одну запись целиком: сверху — свойства, снизу — текстовое
описание. Открывается кликом по первой колонке строки или кнопкой **«Открыть запись»**
в верхней панели.

Все сохраняется автоматически — кнопки «Сохранить» нет.

## Заголовок

Имя записи вверху панели. Клик превращает его в поле ввода: **Enter** — сохранить,
**Escape** — отменить. У записи без имени показано серое «Без названия» — это подсказка:
печатать можно сразу, стирать ее не нужно. Если стереть имя целиком, запись снова получит
«Без названия».

То же имя есть и среди свойств — карточкой **«Название»** (подпись берется из колонки
таблицы, стоит на ее месте). Длинное название удобнее править там: клик по карточке
открывает его в нижнем блоке на всю ширину. Название пишется одной строкой — **Enter**
перенос не добавляет, текст сам переносится по ширине, а из вставленного текста с
переносами остается первая строка. Правка в любом из трех мест — в шапке, в карточке,
снизу — сразу видна в двух других и в таблице.

## Свойства

Каждое свойство — карточка: иконка типа, название, значение. Тип значения задает вид
поля ввода: текст, число, выбор из списка, чекбокс, дата с временем и признаком
«весь день», чеклист мультисписка, названия связанных записей. Полный разбор типов —
[[properties]].

Под свойствами — строка **«Добавить свойство»**: создает колонку прямо отсюда, не
открывая таблицу. Ниже нее — блок «Ссылаются на эту запись» (см. ниже).

### Выделение свойств

- **Клик** по карточке выделяет свойство. Текстовое свойство (и «Название») при этом
  открывается в нижнем блоке — куда бы вы ни кликнули: по значению, по подписи или по пустому
  месту карточки. Клик по значению сразу ставит курсор для правки, клик мимо значения —
  нет, и **Delete** и сочетания клавиш работают с выделенным свойством.
- **Shift + клик** добавляет свойство к выделению или снимает его. Так собирают несколько
  свойств, чтобы удалить, дублировать или покрасить их разом. Нижний блок при этом не
  меняется: в нем остается свойство, открытое последним обычным кликом.
- «Название» в такой набор не входит — его нельзя удалить или дублировать. **Shift + клик**
  по нему работает как обычный клик.
- Нетекстовые свойства (дата, список, связь и другие) нижний блок не переключают.

### Ручки размера

- **Вертикальная ручка ⋮** между названием и значением меняет ширину колонки названий.
- **Горизонтальная ручка-пилюля** под списком свойств меняет высоту блока: тянете
  вниз — свойств видно больше, описание сжимается; тянете вверх — наоборот, а список
  свойств получает прокрутку.

Выбранные размеры сохраняются, пока программа открыта, и переносятся между записями.

## Описание

Нижний блок — редактор одного текстового свойства. По умолчанию это свойство с ролью
**«Описание»**; клик по любой другой текстовой карточке, в том числе по «Названию»,
переключает редактор на нее (см. «Выделение свойств» выше). Над редактором показана крошка «Свойство › [тип] Имя».

Если у коллекции описания еще нет, вместо имени свойства стоит синяя ссылка
**«+ Добавить описание»** — она создает нужное свойство одним кликом.

### Разметка Markdown

Описание пишется в Markdown, кнопка в нижней строке переключает вид:

| Кнопка | Что показывает |
|---|---|
| «Динамический просмотр» | оформленный текст: заголовки, списки, таблицы, ссылки |
| «Просмотр исходного текста» | исходную разметку для правки |

Основное, что пригодится: `# Заголовок`, `**жирный**`, `*курсив*`, `- пункт списка`,
`[текст ссылки](адрес)`, `> цитата`.

«Название» разметку не несет: в просмотре оно показано простым текстом, и «1. Позвонить»
не превращается в список.

Меню правой кнопки у карточки «Название» — как у его колонки в таблице: «Изменить»
(переименовать подпись), «Создать новое свойство», «Отображение», «Изменить цвет»,
«Сдвинуть вверх/вниз». Дублировать и удалить название нельзя.

## Переход по связям

Значение свойства типа «Связь» — названия связанных записей через разделитель; пустая связь —
серое «связи нет». Чтобы открыть связанную запись:

1. Нажмите значок связи справа в карточке свойства — откроется список записей.
2. Нажмите карандаш в строке нужной записи.

Запись откроется в панели — в том числе из другой базы данных. Удаленная запись из названий
пропадает; если база отключена, вместо названия стоит «(база недоступна)».

## Кто ссылается на запись

Под «Добавить свойство» — блок **«Ссылаются на эту запись»**. В нем по карточке на каждое
свойство-связь, которое ведет в коллекцию записи: «Счета · Клиент» — коллекция и свойство, справа
— сколько записей ссылаются и названия первых трех, сначала новые: «3 записи: Счет №41, Счет
№40, Счет №39». Если ссылок нет — «ссылок нет». Ссылки из другой подключенной базы — отдельным
разделом «Ссылаются на эту запись из базы «…»». Блок появляется через мгновение после открытия
записи: число считается, пока вы уже работаете с записью.

Чтобы открыть запись, которая ссылается:

1. Нажмите карточку ссылок — откроется список записей, сначала новые.
2. Если записей много, наберите часть названия в поле «Поиск по названию…» или прокрутите
   список вниз — он догружается.
3. Нажмите строку нужной записи (или карандаш в ней, или Enter).

Под списком написано, сколько записей показано из скольких. Связь ставят и снимают в самой
записи, которая ссылается, — в ее карточке свойства-связи. Кнопка с глазом внизу панели прячет
и карточки без ссылок. Связи коллекций, которые вам закрыты, в блоке не показываются; ссылки из
неподключенных баз тоже не видны — подключите базу, и ее раздел появится.

## Таблица и панель показывают одно и то же

Правка в панели тут же видна в таблице, правка в таблице — в панели. Новое свойство,
созданное в таблице, появляется в списке свойств сразу.
