# Страница записи

Панель справа показывает одну запись целиком: сверху — свойства, снизу — текстовое
описание. Открывается кликом по первой колонке строки или кнопкой **«Открыть запись»**
в верхней панели.

Все сохраняется автоматически — кнопки «Сохранить» нет.

## Заголовок

Имя записи вверху панели. Клик превращает его в поле ввода: **Enter** — сохранить,
**Escape** — отменить. У записи без имени показано серое «Без названия».

## Свойства

Каждое свойство — карточка: иконка типа, название, значение. Тип значения задает вид
поля ввода: текст, число, выбор из списка, чекбокс, дата с временем и признаком
«весь день», чеклист мультисписка, чипы связей. Полный разбор типов — [[properties]].

Внизу списка — строка **«Добавить свойство»**: создает колонку прямо отсюда, не
открывая таблицу.

### Ручки размера

- **Вертикальная ручка ⋮** между названием и значением меняет ширину колонки названий.
- **Горизонтальная ручка-пилюля** под списком свойств меняет высоту блока: тянете
  вниз — свойств видно больше, описание сжимается; тянете вверх — наоборот, а список
  свойств получает прокрутку.

Выбранные размеры сохраняются, пока программа открыта, и переносятся между записями.

## Описание

Нижний блок — редактор одного текстового свойства. По умолчанию это свойство с ролью
**«Описание»**; клик по любой другой текстовой карточке переключает редактор на нее.
Над редактором показана крошка «Свойство › [тип] Имя».

Если у коллекции описания еще нет, вместо имени свойства стоит синяя ссылка
**«+ Добавить описание»** — она создает нужное свойство одним кликом.

### Разметка Markdown

Описание пишется в Markdown, кнопка в нижней строке переключает вид:

| Кнопка | Что показывает |
|---|---|
| «Динамический просмотр» | оформленный текст: заголовки, списки, таблицы, ссылки |
| «Просмотр исходного текста» | исходную разметку для правки |

Основное, что пригодится: `# Заголовок`, `**жирный**`, `*курсив*`, `- пункт списка`,
`[текст ссылки](адрес)`, `> цитата`.

## Переход по связям

Значение свойства типа «Связь» показано чипами. Клик по чипу открывает связанную
запись — в том числе в другой базе данных. Если запись удалена или база отключена,
чип покажет «(запись удалена)» или «(база недоступна)».

## Таблица и панель показывают одно и то же

Правка в панели тут же видна в таблице, правка в таблице — в панели. Новое свойство,
созданное в таблице, появляется в списке свойств сразу.
