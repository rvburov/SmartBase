# Клавиши и жесты мыши

Сводка того, что работает с клавиатуры и мыши. Подробности — в документах разделов.

## Клавиши

| Клавиши | Где | Что делает |
|---|---|---|
| **Delete** | таблица | удалить выделенные записи; если выделены колонки — свойства |
| **Delete**, **Backspace** | календарь, задачи, колонки таблицы | удалить выделенное |
| **Delete** | боковая панель | удалить выделенные группы и коллекции |
| **Delete** | дерево заметок | переместить выделенные папки и файлы в корзину системы |
| **Ctrl+S**, **Cmd+S** | заметка | сохранить сразу (иначе сохранится само) |
| **Enter** | строка быстрого добавления задачи | создать задачу |
| **Enter** | окна с полем «Название» или «Пароль» | подтвердить |
| **Enter**, **Escape** | правка заголовка коллекции или записи | сохранить / отменить |
| **Escape** | окно подключения PostgreSQL | закрыть |
| **Ctrl+X**, **Ctrl+C**, **Ctrl+V** | текстовые поля | вырезать, копировать, вставить |
| **Ctrl+Q** | главное окно | завершить программу, в том числе в фоновом режиме |

Удаление всегда спрашивает подтверждение и называет количество.

## Мышь

| Жест | Где | Что делает |
|---|---|---|
| Клик | боковая панель | открыть коллекцию |
| Клик | дерево заметок | открыть заметку; по папке — раскрыть или свернуть |
| Клик | имя заметки в шапке | переименовать файл |
| Клик | таблица (первая колонка) | открыть страницу записи |
| Двойной клик | ячейка таблицы | редактировать значение |
| Двойной клик | событие, задача | открыть окно записи |
| Двойной клик | пустое место календаря | создать событие на эту дату и время |
| Правый клик | везде | контекстное меню |
| **Shift + клик** | списки, таблица, календарь, задачи | добавить или снять из выделения |
| **Ctrl + клик** | боковая панель, таблица | то же |
| **Ctrl + Shift + клик** | Расписание, Журнал, Диаграмма, задачи | выделить диапазон |
| Перетаскивание | календарь | перенести событие |
| Перетаскивание за край | День, Неделя, Диаграмма | изменить длительность |
| Перетаскивание границы | таблица | ширина колонки или высота строки (в ручном режиме) |
| Перетаскивание ручки-пилюли | панели | ширина или высота панели |

## Чего нет

- Сочетаний для масштаба: размер интерфейса меняется только в «Настройки →
  Оформление» — см. [[settings]].
- Перетаскивания в боковой панели: перемещение — через пункт «Расположение».
- Глобального поиска по всем данным: поиск есть в календаре, задачах и внутри окон.
