# Таблица и записи

Коллекция открывается в разделе **Конструктор базы данных**. Вид переключается
в верхней панели: **«Таблица»** или **«Список»**.

## Устройство таблицы

| Колонка | Что это |
|---|---|
| **№** | номер строки, служебная |
| **Название** | системное свойство записи: переименовать можно, удалить или сменить тип — нет |
| остальные | ваши свойства — см. [[properties]] |
| **+** | последняя колонка: создать новое свойство |

Последняя строка таблицы — строка добавления записи.

Заголовок коллекции в верхней панели редактируется кликом: **Enter** — сохранить,
**Escape** — отменить.

## Работа с записями

| Действие | Как выполнить |
|---|---|
| Создать | клик по последней строке таблицы, либо правый клик по номеру строки → «Создать запись» |
| Изменить значение | двойной клик по ячейке; сохраняется сразу, кнопки «Сохранить» нет. **Enter** — закончить правку, ячейка остается выделенной; **Escape** — отменить |
| Перенос строки в тексте | **Alt+Enter** во время правки текстовой ячейки или ссылки |
| Открыть запись целиком | клик по номеру строки в колонке **№** — откроется [[record-page]] справа; то же дает пункт «Изменить» в меню номера строки |
| Дублировать | правый клик по номеру строки → «Дублировать»; копия встает сразу под исходной |
| Перенести | правый клик по номеру строки → «Расположение» — в другую коллекцию или базу данных |
| Удалить | правый клик по номеру строки → «Удалить» либо клавиша **Delete** при выделенных записях |
| Сдвинуть | правый клик по номеру строки → «Сдвинуть вверх» / «Сдвинуть вниз» |
| Отправить наружу | правый клик по номеру строки → «Действия» → нужный обмен; уходят все выделенные записи |

Меню записи открывается правым кликом по **номеру строки**. Правый клик по ячейке значения
открывает меню самой ячейки — см. разделы «Значения: копирование, вставка, очистка» и «Цвет»
ниже.

Многострочный текст показывается в ячейке столькими строками, сколько помещается в ее высоту:
в строке стандартной высоты видна первая строка, остальные — в строке, растянутой вручную
(«Ручная высота строк»), и в панели записи.

> **Сдвиг работает только без фильтра и сортировки.** Пока они включены, пункты
> «Сдвинуть вверх/вниз» скрыты: порядок строк на экране задан не вами, и сдвиг
> означал бы не то, что видно. Снимите сортировку и фильтр — пункты вернутся.

### Действия обмена

Если для коллекции настроен обмен с другой программой (см. [[settings]]), он приходит туда, где
лежат данные, — ходить в настройки не нужно.

Куда нажать, зависит от того, **что именно отправляете**:

| Нужно отправить | Где |
|---|---|
| Выделенные записи | правый клик по строке → «Действия» |
| Всю коллекцию | правый клик по коллекции в боковой панели → «Действия» |
| Одну открытую запись | кнопка в нижней полосе записи, рядом с переключателем markdown |

Сценарии, которые запускают руками, живут там же, где и вся коллекция, — в боковой панели.
Отправить коллекцию можно, даже не открывая ее.

Пункта и кнопки нет, пока для коллекции ничего не настроено. Перед отправкой программа
спрашивает подтверждение и показывает, сколько записей, куда и какие поля уходят.

## Работа со свойствами

Правый клик по заголовку колонки:

| Пункт | Что делает |
|---|---|
| Изменить | название, тип и настройки свойства |
| Дублировать | копия свойства со всеми настройками |
| Создать новое свойство | добавляет колонку сразу после текущей |
| Отображение | окно «Отображение свойств» — видимость и порядок колонок |
| Копировать / Вставить / Очистить значения | работа со значениями всей колонки — см. раздел «Значения: копирование, вставка, очистка» ниже |
| Сдвинуть вправо / влево | переставить колонку |
| Удалить | удаляет колонку вместе со значениями во всех записях |

У свойства типа «Файл» с включенной авто-привязкой добавляется пункт
**«Обновить привязку»** — перечитать папку с файлами.

У колонки **«Название»** пунктов «Дублировать» и «Удалить» нет.

## Выделение

Выделять можно три разные вещи, и от этого зависит, на что подействуют **Delete** и пункты меню.

| Что выделяете | Как | Как выглядит |
|---|---|---|
| **Ячейки** | клик по ячейке значения, протягивание мышью | синяя прямоугольная рамка; если ячеек несколько, они под рамкой слегка затонированы |
| **Записи** | клик по номеру строки в колонке **№** | строка подсвечена целиком |
| **Колонки** | клик по заголовку колонки | колонка залита голубым |

Наведение подсвечивает серым **ячейку** под курсором, а не строку целиком: курсор ходит по
значениям, и видно ту ячейку, в которую вы попадете. Пока выделены ячейки, голубой подсветки
строки нет — выделена ячейка, а не запись.

Во время правки ячейки рамка выделения уступает место рамке редактора, чтобы их не было двух.
После **Enter** рамка возвращается на ту же ячейку: значение записано, и следующие
**Ctrl+C** или **Delete** работают по ней. **Tab** тоже записывает значение, но рамка
переходит на ячейку правее (**Shift+Tab** — левее).

**Ячейки.**

- **Клик** — выделить одну ячейку.
- **Протягивание** — нажать на ячейке и вести мышь, не отпуская кнопку: прямоугольник тянется
  за курсором.
- **Shift + клик** — дотянуть прямоугольник от ячейки, с которой начали, до той, по которой
  кликнули: сколько угодно строк на сколько угодно столбцов, одним куском и одной рамкой.
- **Ctrl+A** — выделить всю таблицу.

Выделение всегда сплошной прямоугольник, поэтому рамка всегда одна и «прямоугольника в
прямоугольнике» не бывает. Набрать ячейки вразнобой нельзя.

Когда выделено больше одной ячейки, в нижней панели рядом с навигацией по строкам виден размер:
**«Выделено: 3 × 2»** — три строки на два столбца.

Выделять можно только ячейки значений: служебные колонки **№** и **+** в выделение не попадают.

**Ячейки с клавиатуры.** Когда в таблице выделена ячейка, выделение двигается клавишами:

| Клавиши | Что делает |
|---|---|
| **Стрелки** | перейти на соседнюю ячейку |
| **Shift + стрелки** | растянуть выделение; ячейка, с которой начали, остается на месте |
| **Ctrl + стрелки** | к краю таблицы: к первой или последней строке, к первому или последнему столбцу |
| **Home**, **End** | к первому или последнему столбцу строки |
| **Ctrl+Home**, **Ctrl+End** | в левый верхний или правый нижний угол таблицы |
| **PageUp**, **PageDown** | на экран вверх или вниз |
| **Tab**, **Shift+Tab** | на ячейку правее или левее; с края строки — на соседнюю строку |
| **Ctrl+A** | выделить всю таблицу |
| **Enter**, **F2** | начать правку ячейки, с которой начато выделение |
| **Escape** | снять выделение |

**Shift** растягивает выделение и вместе с остальными клавишами: **Shift+End** — до конца строки,
**Ctrl+Shift+End** — до правого нижнего угла таблицы. Скрытые в «Отображении» колонки клавиши
перешагивают. Таблица сама прокручивается к ячейке, на которую перешло выделение.

Таблица может поменяться прямо под выделением: вы ее отсортировали или отфильтровали, коллега
поправил запись, колонку передвинули. Рамка переезжает вслед за теми же записью и колонками. Если
записи на экране больше нет, выделение снимается: рамка на чужих данных опаснее пустой — **Delete**
стер бы не то, что выделяли.

**Записи.**

- **Клик по номеру** — выделить строку и открыть запись.
- **Shift + клик**, **Ctrl + клик** по номеру — добавить или снять строку из выделения,
  не открывая ее.

**Колонки.**

- **Клик по заголовку** — выделить колонку; **Shift + клик** — несколько колонок.

Все три выделения гасят друг друга: выделили ячейки — подсветка строк и колонок снимается, и
наоборот. Так **Delete** всегда означает одно и то же: при выделенных ячейках очищает значения,
при выделенных записях удаляет записи, при выделенных колонках удаляет свойства.

Клавиши работают, только пока таблица на экране и курсор в ней. Ушли в другой раздел или
печатаете в панели записи — **Delete** и **Ctrl+V** до выделенных ячеек не доходят.

Пункт меню номера строки применяется ко всем выделенным записям, если строка в них входит.

## Значения: копирование, вставка, очистка

Три действия работают по выделенным ячейкам и доступны из трех мест: меню самой ячейки,
меню записи и меню колонки. Меню записи расширяет выделение на всю строку, меню колонки —
на весь столбец; дальше все одинаково.

| Действие | Клавиши | Что делает |
|---|---|---|
| **Копировать значения** | **Ctrl+C** (**Cmd+C**) | кладет значения в буфер обмена |
| **Вставить значения** | **Ctrl+V** (**Cmd+V**) | заполняет ячейки из буфера |
| **Очистить значения** | **Delete** или **Backspace** | стирает значения, оставляя записи и колонки на месте |

Клавиши подписаны справа от пунктов меню. Пункты стоят отдельной группой, подальше от «Удалить»:
очистка значений и удаление записи — разные вещи. Если в буфере обмена пусто, пункт «Вставить
значения» неактивен.

Еще два действия — только с клавиатуры:

| Клавиши | Что делает |
|---|---|
| **Ctrl+X** (**Cmd+X**) | вырезать: скопировать значения в буфер и сразу очистить ячейки; если скопировать не вышло, ничего не стирается |
| **Ctrl+Z** (**Cmd+Z**) | отменить последнюю вставку, очистку или вырезание — см. «Отмена» ниже |

**Меню ячейки** — правый клик по ячейке значения. В нем только то, что касается значений и
их вида: три пункта выше и «Изменить цвет» (см. раздел «Цвет» ниже). Все, что касается самой
записи, — в меню номера строки.

За один раз обрабатывается до 100 000 строк и до 200 000 ячеек. Если выделено больше (например,
весь столбец коллекции в миллион записей), программа скажет об этом и ничего не изменит —
выделите меньше строк или сузьте таблицу фильтром.

Большое выделение обрабатывается не мгновенно. Если работа не укладывается в полсекунды,
открывается окно с ходом работы, а таблица ждет, пока оно закроется. Чтение выделенных строк
можно прервать — тогда ничего не скопируется и не изменится. Запись в базу прервать нельзя:
начатую запись программа доводит до конца.

**Копирование.** Значения уходят в буфер в том виде, в каком вы их видите на экране, столбцы
разделены табуляцией, строки — переводом строки. Это обычный формат таблиц: вставьте в любой
табличный редактор — получите готовые столбцы, а не одну склеенную строку. Из буфера текст
никуда не девается: вставлять его можно сколько угодно раз и куда угодно. Связь копируется
названиями связанных записей через разделитель свойства — так, как ее показывает ячейка.

Пустые ячейки копируются как пустые — в тексте это выглядит как несколько табуляций подряд
или пустые строки. Так и задумано: место пустой ячейки обязано сохраниться, иначе значения
справа от нее съехали бы на чужие столбцы. Скопировали строку целиком — в буфере будет вся
строка, включая незаполненные свойства и те, что заполняются сами (автор, даты создания и
изменения).

Скрытые в окне «Отображение» колонки не копируются и не заполняются вставкой: в таблице их
нет, и попадать в буфер или молча принимать значения они не должны. Вставка их просто
перешагивает — значения ложатся в видимые колонки по порядку, поэтому скопированный блок
возвращается на свои места, даже если между колонками есть скрытые.

**Вставка.** Выделенная ячейка — левый верхний угол блока, дальше он разливается вниз и вправо.
Можно выделить одну ячейку и вставить в нее блок 10 × 3. Вставлять можно и то, что скопировано
в другой программе.

Если **выделено больше ячеек, чем лежит в буфере**, блок размножается по выделению:

| В буфере | Выделено | Что получится |
|---|---|---|
| одно значение | столбец из 20 ячеек | все 20 заполнены этим значением |
| два значения | столбец из 6 ячеек | два, снова два, снова два |
| строка из 3 значений | прямоугольник 4 × 3 | строка повторится четыре раза |

Выделение, не кратное блоку, обрывается по своему краю — вставка просто заполняет сколько
влезло. Если выделение меньше блока, оно не в счет: блок ложится целиком от левого верхнего угла.

Новых строк вставка не создает никогда. Все, что не поместилось в таблицу, отбрасывается —
иначе одно нажатие могло бы молча завести сотни записей.

Значения приводятся к типу колонки:

| Колонка | Что понимает вставка |
|---|---|
| **Число** | и то, что показывает таблица, и запись из других программ: пробелы или апострофы между разрядами, знак валюты или процента, минус или скобки — `1 234,50 ₽`, `1,234.50`, `12 %`, `(500)`. Значение ляжет с разделителем этой колонки. Если запись вроде `1.234` можно понять двояко, решает разделитель колонки |
| **Дата** | дата должна занимать ячейку целиком: `01.02.2026`, `1.2.2026`, `01/02/2026`, `2026-02-01`, дата со временем. Из «Отчет от 01.02.2026» дата не вынимается — такая ячейка пропускается, иначе слова пропали бы молча |
| **Галочка** | `✓`, `да`, `1`, `истина`, `вкл`, `true` — поставить; `нет`, `0`, `ложь`, `выкл`, `false` — снять |
| **Список**, **Статус** | только значение из списка допустимых, в его точном написании: `в работе` станет `В работе` |
| **Мультисписок** | значения из списка через разделитель колонки, запятую, точку с запятой или с новой строки; значение, в котором само есть запятая («Ул. Ленина, 5»), не разваливается. Если хотя бы одного значения нет в списке, ячейка пропускается целиком — иначе половина скопированного пропала бы без следа |
| **Пользователь** | только имя пользователя, допущенного к базе |
| **Связь** | названия записей связанной коллекции — см. ниже |
| **Текст**, **ссылка** | как есть, вместе с пробелами по краям |

**Связи** вставляются по названиям записей — в том виде, в каком их показывает ячейка, поэтому
скопированная из своей таблицы связь ложится обратно без правок. Название ищется точно, с учетом
регистра. Сначала весь текст ячейки ищется как одно название: у записи в названии может быть
запятая («Иванов, Петров и партнеры»). Не нашлось — текст делится на части по разделителю
свойства, запятой, точке с запятой или переводу строки, и найтись должна каждая часть. Если под
названием несколько записей-тезок или хоть одна часть не нашлась, ячейка пропускается, и это
названо в итоге: угадывать, какую из тезок имели в виду, программа не станет. Пустое значение
снимает связи. Если связь допускает одну запись, из нескольких названий ляжет первое.

Если в буфере одни пробелы, вставка ничего не делает: случайный пробел не сотрет выделенный
столбец.

Что не примется — пропускается, а внизу появляется итог с причинами, например
«Вставлено 40 значений, пропущено 6: 4 не подходят типу столбца, 2 нет в списке допустимых».
Пропускаются:

| Что | Почему |
|---|---|
| Вычисляемые свойства: дата создания, автор | заполняются сами |
| Файлы | выбираются в своем окне, а не текстом |
| Связи с коллекцией из другой базы | записи другой базы по названию отсюда не найти |
| Связь, чье название не нашлось или принадлежит нескольким записям | угадывать нельзя |
| Текст не по типу: `абв` в число, `вчера` в дату | не превращается в значение |
| Значение не из списка допустимых, незнакомый пользователь | иначе в колонке завелось бы то, чего нет в фильтре |
| Пустое значение в колонке **«Название»** | запись без названия теряется в списках и связях |
| Все, что вышло за края таблицы | строки не добавляются |

Если кто-то другой удалил запись, пока ее строка была у вас на экране, ее значения просто не
запишутся — остальная вставка пройдет.

Вставка не спрашивает подтверждения: ее отменяет **Ctrl+Z**. Исключение — вставка больше 100 000
значений: столько изменений не запоминается, и перед записью программа спросит.

**Очистка.** Стирает значения и снимает связи; сами записи и колонки остаются — их удаляет
«Удалить». Названия записей очистка не трогает: запись без названия становится «Без названия» и
теряется в списках и связях. Переименовать ее можно вставкой или правкой самой записи.

Если очищается больше десяти ячеек, программа спрашивает подтверждение — при включенной
настройке «Спрашивать подтверждение при удалении» (см. [[settings]], раздел «Конструктор базы
данных»). Больше 100 000 ячеек — спрашивает всегда: такую очистку уже не отменить.

**Отмена.** **Ctrl+Z** возвращает значения, какими они были до последней вставки, очистки или
вырезания в этой таблице, — вместе со связями и названиями. Нажмите еще раз — отменится
предыдущее действие, и так до двадцати шагов назад. Курсор при этом должен быть в таблице,
выделять ячейки не нужно.

Отмена бережет чужую работу: ячейку, которую после вставки уже поменял коллега или вы сами в
панели записи, она не трогает и говорит в итоге, сколько таких ячеек осталось. Действия
помнятся, пока открыта эта коллекция, — переход в другую их забывает. Вернуть отмененное
нельзя: отмененную вставку просто повторите.

**Что остается в журналах.** Вставка, очистка, вырезание и отмена ложатся в историю изменений
одной строкой на действие — с числом изменений и первыми правками «было → стало» (см.
[[profile-access]]).

> **Копирование оставляет след в журнале безопасности.** Как и выгрузка в файл: способ вынести
> данные наружу не должен оставаться бесследным. Администратор увидит, кто, когда, из какой
> коллекции, какие столбцы и сколько ячеек скопировал, объем текста и его отпечаток; самих
> значений там нет. Если журнал безопасности недоступен, копирование не выполняется. В историю
> изменений копирование не попадает — это не правка.

## Ширина колонок и высота строк

По умолчанию размеры стандартные: колонки делят ширину окна поровну, строки одной высоты.
Чтобы менять их мышью, включите в контекстном меню **«Ручная ширина столбцов»** (меню
заголовка) или **«Ручная высота строк»** (меню строки). Чтобы эти режимы были включены
у новых коллекций сразу, а сами стандартные размеры стали другими, — см.
«Настройки → Конструктор базы данных» в [[settings]].

Включение режима вид таблицы не меняет — просто у правых границ заголовков появляются
места захвата: наведите на границу, курсор станет «↔», и тяните.

**Как ведут себя соседние столбцы.**

| Куда тянете | Что происходит |
|---|---|
| **Вправо** (расширяете) | столбец растет, остальные сохраняют свою ширину и уезжают вправо; когда таблица перестает помещаться в окно, внизу появляется горизонтальная прокрутка |
| **Влево** (сужаете) | столбцы справа расширяются и занимают освободившееся место — пустоты справа не остается |

Столбцы левее того, что вы тянете, не меняются никогда. Самый правый столбец сузить
можно только до момента, когда таблица ровно заполняет окно, — дальше место отдавать некому.
Кнопка **«+»** для создания свойства всегда остается у правого края, пока таблица
помещается в окно; если таблица шире окна, «+» стоит в самом конце и доезжает прокруткой.

Ширины запоминаются для каждой коллекции и сохраняются между запусками, переезжают вместе
с коллекцией при дублировании, переносе в другую базу и экспорте. Вернуть равномерные
столбцы — **«Стандартная ширина столбцов»** (заданные ширины при этом стираются).
Для строк то же самое — «Стандартная высота строк».

## Цвет

Цвет выбирается пунктом **«Изменить цвет»** — в меню номера строки или в меню ячейки:

| Где | Пункт | Что красит |
|---|---|---|
| правый клик по номеру строки | **Фон строки** | заливка всей строки |
| правый клик по номеру строки | **Цвет текста строки** | текст всей строки |
| правый клик по ячейке | **Фон ячейки**, **Цвет текста ячейки** | все выделенные ячейки; если кликнули вне выделения — эту ячейку |

Правый клик по **заголовку колонки** → «Изменить цвет» красит всю колонку целиком —
**Фон колонки** и **Цвет текста колонки**.

Что стоит знать:

- Цвет — настройка **этой таблицы**. В календаре, задачах, виде «Список» и в панели записи
  он не появится: там цвет по-прежнему берется у коллекции.
- Если выделено несколько строк или несколько колонок, цвет применяется ко всем сразу —
  как удаление и дублирование. Выделение колонок после этого снимается, чтобы был виден
  результат: под голубой заливкой выделения цвет читается плохо.
- Более точное перебивает более общее: цвет ячейки сильнее цвета строки, цвет строки —
  сильнее цвета колонки. Фон и цвет текста считаются отдельно.
- Заливка полупрозрачная: выделение строки и наведение видны сквозь цвет.
- Убрать цвет — пункт **«Без цвета»** в начале списка.
- Палитра — те же девять цветов, что и у коллекций в боковой панели.

## Отображение свойств и записей

Оба окна открываются пунктом **«Отображение»** и устроены одинаково: список строк
с поиском, чекбоксом видимости и кнопками перемещения вверх и вниз.

**«Отображение свойств»** дополнительно умеет уровни. Справа — панель уровней
(до 14, кнопки «+» и «−»); у каждой колонки свой уровень, который меняется кликом
по бейджу. Выбор уровня N показывает все колонки с уровнем N и ниже — так одна
коллекция дает несколько «срезов» без пересоздания колонок.

Изменения применяются по кнопке **«Сохранить»**.

## Вид «Список»

Компактные карточки: название, чип статуса (из первого свойства-статуса) и дата
(из первого свойства-даты). Правый клик по карточке — «Открыть», «Создать запись»,
«Удалить».

Вид запоминается для каждой коллекции отдельно.

## Нижняя строка

Единственное, что в ней есть, — навигация по строкам справа:

```
‹‹   ‹   10 – 50 из 125 437   ›   ››
```

**«10 – 50»** — номера строк, которые сейчас видны на экране, **«125 437»** — всего
записей. Сколько строк попадает в окно, столько и в диапазоне: развернете окно или
уменьшите высоту строк — диапазон станет шире.

| Кнопка | Что делает |
|---|---|
| **‹** | экран назад — окно сдвигается ровно на свою высоту |
| **›** | экран вперед |
| **‹‹** | в самое начало таблицы |
| **››** | в самый конец таблицы |

Кнопки к тому краю, у которого вы уже стоите, гаснут: на первой строке — «‹‹» и «‹»,
на последней — «›» и «››». Если вся таблица помещается на экране, погашены все четыре.

Прокрутка колесом и полосой работает как раньше — кнопки просто двигают ту же полосу,
и индикатор следует за любым способом прокрутки.

Общее число записей коллекции — это и есть число после «из»; отдельной надписи
«Всего» в панели нет. Фильтр и сортировка вызываются из меню заголовка колонки
([[filters-sorting]]), кнопок для них внизу тоже нет.

> **При фильтре и сортировке** строки нумеруются заново с единицы, а «всего» — это число
> записей в отфильтрованном срезе. Так «10 – 50 из 120» читается одинаково и с фильтром,
> и без него. Про фильтр — [[filters-sorting]].

В виде **«Список»** навигация не работает: кнопки погашены, она двигает именно таблицу.
