# Чеклист: календарь — режим «Диаграмма»

Проверка ганта на месяц: переключение и настройки, шапка и навигация, группы
коллекций, бары/кольца и подписи длительности, перенос и растяжение мышью, поиск,
фильтр коллекций, кэпы больших данных. Как устроено —
[features/calendar/diagram.md](../features/calendar/diagram.md), общие жесты —
[features/calendar/interactions.md](../features/calendar/interactions.md).

Подготовка: в одной БД заведите 2–3 коллекции с разными цветами и записями-датами
разных видов (через «+» календаря / окно записи):

- timed короткое — 1 час внутри одного дня;
- timed многодневное — например, 3 дня 2 часа (начало 10:00, конец через 3 дня в 12:00);
- «Весь день» на один день и «Весь день» диапазоном (например, 28–31);
- событие через границу месяца (начало в прошлом месяце, конец в текущем);
- для мульти-БД — вторая база со своей коллекцией и событиями в том же месяце.

## 1. Переключение и настройки

- [ ] В ComboBox навбара календаря есть «Диаграмма» (последним, после «Год»);
      выбор переключает вид, обратно на «Месяц» — без артефактов.
- [ ] Настройки → «Отображение раздела календаря» → «Диаграмма»: после перезапуска
      календарь открывается сразу в диаграмме.
- [ ] Остальные виды не пострадали: пощёлкать все семь режимов подряд туда-обратно.

## 2. Шапка, навигация, линия «сейчас»

- [ ] Заголовок — «июль 2026» (месяц и год, как у Месяца); ←/→ листают по месяцу,
      «Сегодня» возвращает к текущему.
- [ ] Шапка дней: две строки (Пн…Вс сверху, число снизу), Сб/Вс красные; колонки
      выходных в теле подсвечены серым.
- [ ] Подсветка выходных, вертикальные линии дней и красная линия «сейчас»
      заканчиваются на последней строке — ниже чистый фон.
- [ ] Красная вертикальная линия «сейчас» стоит на текущей дате-времени; в чужом
      месяце линии нет; если оставить окно открытым на несколько минут — линия
      сдвигается сама (минутный таймер).

## 3. Левая панель: группы и строки

- [ ] Строка группы: шеврон, цветная точка (серая у коллекции «без цвета»), имя
      жирным, справа — число записей; строки записей — только название с отступом
      (без дат/диапазонов).
- [ ] Клик по строке группы сворачивает/разворачивает её записи; строка группы и её
      суммарный бар остаются; шеврон меняет направление.
- [ ] Свёрнутость переживает правку записи (диалогом или drag), но НЕ листание
      в другой месяц и обратно — это нормально (пересборка данных).
- [ ] ВСЕ отмеченные коллекции всех допущенных баз присутствуют строками — включая
      коллекции без событий в этом месяце (счётчик 0, без суммарного бара); порядок —
      как в сайдбаре (по базам, внутри — по позиции); записи внутри группы — по дате
      начала.
- [ ] Длинное имя коллекции/записи обрезается многоточием, не ломая колонку
      диапазона.

## 4. Бары, кольца, подписи

- [ ] Блоки — в стиле баров Месяца: высота 20, полупрозрачный цвет коллекции на
      белой подложке, цветная полоска слева у начала события; блок занимает ячейки
      дней целиком (от начала ячейки первого дня до конца ячейки последнего),
      время суток на позицию не влияет.
- [ ] Многодневное timed — подпись «3 дня 2 часа» внутри блока; у короткого блока —
      справа от него; у правого края месяца — слева от блока.
- [ ] Однодневное событие (час, 30 минут) — кольцо цвета коллекции по центру ячейки
      своего дня (по ширине и высоте строки) + подпись «1 час» справа (у правого
      края месяца — слева).
- [ ] «Весь день» один день — кольцо с подписью «24 часа»; «весь день» 28–31 —
      блок «4 дня».
- [ ] Событие через границу месяца: блок прижат к краю, обрезанный край прямой и
      без цветной полоски, подпись показывает ПОЛНУЮ длительность (не обрезанную
      месяцем).
- [ ] Суммарный диапазон группы — как событие: многодневный охват — блок по ячейкам
      от первого до последнего дня записей, однодневный — кольцо по центру ячейки;
      подпись — общий охват дней и времени («30 минут», «1 день 3 часа 30 минут»,
      у полностью all-day группы — «N дней»/«24 часа»); после сворачивания группы
      остаётся.
- [ ] Склонения: «1 день / 2 дня / 5 дней», «1 час / 2 часа / 5 часов»,
      «1 минута / 2 минуты / 5 минут», «11–14 дней» — родительный.

## 5. Перенос и растяжение мышью

- [ ] Курсор над баром/кольцом — «рука»; над краями бара (±6 px) — «↔»;
      над пустым местом — обычный.
- [ ] Перенос за середину бара: ghost едет по дням, оригинал полупрозрачный;
      после отпускания событие на новых датах, правка видна сразу (без «Загрузка…»).
- [ ] Время суток и длительность при переносе сохраняются (проверить запись с
      временем вроде 14:48 — открыть диалог после переноса: часы-минуты те же,
      сдвинулись только дни; перенос НЕ проходит через диалог — секунды не
      теряются).
- [ ] Растяжение за правый край: конец двигается по дням, подпись длительности в
      ghost пересчитывается; конец не заезжает раньше начала. Левый край —
      симметрично.
- [ ] Кольца переносятся, но НЕ растягиваются; суммарный бар группы не таскается.
- [ ] Обрезанный краем месяца край бара не растягивается (зона ресайза только на
      реальном крае).
- [ ] Утащить бар к краю месяца: дальше границы (центр события за месяцем) не
      уезжает.
- [ ] Micro-drag (<5 px) — это клик: выделяет запись, даты не меняются; drag
      снимает выделение.
- [ ] После переноса другие виды (Месяц, Журнал) показывают новые даты; при
      активном поиске перенос тоже работает (идёт полной перезагрузкой — допустимо).

## 6. Клик и создание

- [ ] Наведение на блок/кольцо подсвечивает его (заливка ярче), уход курсора —
      возвращает; на выделенном ховер ничего не меняет.
- [ ] Одиночный клик по блоку/кольцу выделяет: блок заливается цветом (подпись
      внутри блока становится белой, полоска слева прячется — левый край остаётся
      скруглённым), кольцо закрашивается; медленный повторный клик НЕ открывает.
- [ ] Двойной клик открывает «Изменить запись» с данными именно этой записи
      (и по выделенному, и по невыделенному).
- [ ] Клик по пустому месту таймлайна или по другому событию снимает/переносит
      выделение; клик по строке записи слева открывает окно сразу.
- [ ] «+» в навбаре создаёт запись; после сохранения она появляется в своей группе
      на диаграмме.

## 7. Поиск, фильтр, пустое состояние

- [ ] Поиск в навбаре фильтрует строки; группы без совпадений исчезают целиком
      (в т.ч. пустые коллекции); очистка поиска возвращает всё.
- [ ] Снятие галки коллекции в сайдбаре убирает её группу; галка базы — все группы
      базы.
- [ ] Месяц без событий — коллекции остаются строками с «0»; «Нет записей» — только
      когда нет ни одной отмеченной коллекции или поиск ничего не нашёл; шапка дней
      на месте.

## 8. Прокрутка, зум, шрифт

- [ ] Много коллекций (контент выше окна): левая панель и таймлайн прокручиваются
      СИНХРОННО, шапка дней и «ВСЕ КОЛЛЕКЦИИ» стоят; вертикальный разделитель
      панели непрерывен сверху донизу.
- [ ] Переключение в диаграмму прокручивает к началу списка; «Сегодня» — тоже.
- [ ] Масштаб приложения 70 % и 130 % (Настройки): линии сетки чёткие (без
      размазывания), бары не съезжают относительно колонок дней.
- [ ] Смена размера шрифта — вид перестраивается живьём, подписи не наезжают.
- [ ] Ресайз окна: диаграмма растягивается, месяц всегда занимает всю ширину
      (горизонтального скролла нет).

## 9. Большие данные

- [ ] Коллекция с сотнями записей в месяце (стенд `Tests/DbGenerator`): после 200
      строк — серая строка «+N ещё», вид не виснет, прокрутка плавная.
- [ ] Счётчик группы показывает полное число записей (не 200), суммарный бар
      покрывает и обрезанные кэпом записи.
- [ ] Очень много коллекций: не более ~1000 строк всего, дальше «+N коллекций ещё».
