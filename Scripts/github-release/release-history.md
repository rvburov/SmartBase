# История релизов

Что изменилось в каждой выпущенной версии. Отсюда `release-notes.sh` собирает тело релиза
на GitHub, поэтому файл лежит внутри модуля выпуска, а не в корне репозитория.

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация — [SemVer](https://semver.org/lang/ru/) в трактовке настольного приложения:

- **MAJOR** — несовместимая миграция базы или смена формата данных (откатиться назад нельзя);
- **MINOR** — новый раздел, тип поля, расширение, заметная возможность;
- **PATCH** — исправления, производительность, рефакторинг.

Правки пишутся в секцию `## [Не выпущено]` по ходу работы. Перед выпуском секция переименовывается
в номер версии вручную, дату проставляет [release.sh](release.sh) — см.
[руководство по выпуску](../../docs/developer/guides/release.md).

Разделы внутри версии — только непустые: **Добавлено**, **Изменено**, **Исправлено**,
**Удалено**, **Безопасность**.

## [Не выпущено]

### Изменено
- Иконка приложения больше не обведена белой рамкой. Вместо одной картинки на все системы
  теперь три — под Windows, macOS и Linux, каждая по правилам своей системы: на macOS
  плашка вписана в сетку Apple, на Linux скругление заметнее.
- Установщик теперь лежит рядом с установленным приложением и служит единственной точкой
  входа для установки, обновления и удаления. На macOS вместо файла
  «Uninstall SmartBase.command», открывавшегося через Terminal, рядом с программой лежит
  «SmartBase-Setup».
- Окно установщика само находит установленные копии на компьютере — папку установки больше
  не нужно помнить. Если копий несколько, показывается список с путями и версиями.
- Флажок «вместе с данными пользователя» переехал в окно установщика, к кнопке «Удалить»,
  и предупреждает, что именно будет стёрто.

### Исправлено
- Удаление программы не снимало автозапуск: система продолжала пытаться запускать
  удалённое приложение.
- Путь установки, вписанный в поле вручную, не приводился к отдельной подпапке — программа
  могла лечь прямо в выбранную папку, например в «Документы». Теперь правило действует и на
  вписанный путь, а окно заранее показывает, куда именно установит.

## [1.0.4] — 2026-08-09

### Изменено
- Новая иконка приложения — одна для Windows, macOS и Linux. Retina-слот в Dock теперь
  собирается из мастера 1024×1024, а не растягиванием половинного размера.

### Исправлено
- Выпадающий список времени мог уронить программу, если в поле стояло произвольное
  время: прокрутка к выбранному пункту выполнялась и тогда, когда выбирать было нечего.
- Импорт и экспорт падали, если панель к этому моменту была отцеплена от окна.

### Безопасность
- Закрыты четыре уязвимости в транзитивных зависимостях:
  SQLitePCLRaw 2.1.10 → 2.1.12 (CVE-2025-6965, повреждение памяти в SQLite),
  System.Drawing.Common 4.7.0 → 4.7.2 (CVE-2021-24112, удалённое выполнение кода),
  Tmds.DBus.Protocol 0.20.0 → 0.21.3 и Tmds.DBus 0.9.1 → 0.92.0
  (GHSA-xrw6-gwf8-vvr9, подмена сигналов D-Bus).

## [1.0.3] — 2026-08-07

### Добавлено
- Универсальный конструктор данных: коллекции с произвольными полями, записи, представления.
- Календарь (месяц, неделя, день, год, расписание, журнал, диаграмма), задачи, расширения.
- Работа с несколькими базами одновременно, SQLite и PostgreSQL, пользователи и права.
- Импорт и экспорт, автообновление из сетевой папки, нативные уведомления, автозапуск.
