# История релизов

Что изменилось в каждой выпущенной версии. Отсюда `release-notes.sh` собирает тело релиза
на GitHub, поэтому файл лежит внутри модуля выпуска, а не в корне репозитория.

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
нумерация — [SemVer](https://semver.org/lang/ru/) в трактовке настольного приложения:

- **MAJOR** — несовместимая миграция базы или смена формата данных (откатиться назад нельзя);
- **MINOR** — новый раздел, тип поля, расширение, заметная возможность;
- **PATCH** — исправления, производительность, рефакторинг.

Правки пишутся в секцию `## [Не выпущено]` по ходу работы. Перед выпуском секция переименовывается
в номер версии вручную, дату проставляет [release.sh](release.sh) — см.
[руководство по выпуску](../../docs/developer/guides/release.md).

Разделы внутри версии — только непустые: **Добавлено**, **Изменено**, **Исправлено**,
**Удалено**, **Безопасность**.

## [Не выпущено]

## [2.0.0] — 2026-10-29

### Добавлено
- Свойство «Дата период времени»: продолжительность между датами с учетом выбранных дней
  недели и часов. Автоматический расчет или сохранение результата с явным пересчетом;
  значения доступны в фильтрах, сортировке и экспорте.
- Связи: подписи и поиск по нескольким свойствам, условия выбора записей и автоматический подбор
  по нескольким парам свойств с настройкой учета регистра и пробелов.
- Настраиваемый запрет удаления записей, на которые ссылаются связи, и проверка отдельного свойства
  из его окна настройки.
- Блок «Ссылаются на эту запись» на странице записи: обратные ссылки из подключенных баз
  с учетом доступа к коллекциям.
- Фильтр таблицы по нескольким цветам фона и текста, раскрытие длинного значения при правке
  ячейки, выделение диапазона через Ctrl+Shift и добавление недостающих строк и колонок
  при вставке с возможностью отменить операцию.

### Изменено
- **Совместимость и обновление.** Межбазовые связи переходят на постоянные номера баз;
  однозначно определенные цели преобразуются автоматически после подключения баз.
  Перед первым запуском новой версии создайте резервные копии всех связанных баз,
  завершите работу старой версии на всех компьютерах и обновите все рабочие места.
  Версии 1.x не понимают преобразованные межбазовые связи: для отката нужны копии баз,
  созданные до обновления. Если показано «(база не определена)», выберите «Целевую базу»
  в настройках свойства «Связь» и нажмите «Сохранить»; неоднозначные ссылки не удаляются.
- Значения и итоги связанных записей настраиваются внутри свойства «Связь».
  Ускорены фильтрация и сортировка по данным из связей.
- Тумблер «Автоподстановка файлов»: новые свойства остаются ручными; выключение
  сохраняет найденные пути и параметры, изменения применяются только по «Сохранить».
- Фоновый подбор через локальный пересобираемый каталог. Недоступность папки,
  отмена, конфликт или слишком широкий результат сохраняют прежние ссылки; список не обрезается.
- Показ первых восьми файлов и полный список с подгрузкой; варианты фильтра —
  отдельные пути, запись отбирается по любому подходящему файлу. Старые сохраненные фильтры
  по набору файлов сохраняют точное сопоставление.
- Резервное копирование показывает этапы, числовой прогресс и ошибки в фоновых работах;
  уведомления о результате включаются в настройках. Добавлены проверка свободного места,
  отмена операции и очистка временных файлов после прерывания.
- «Регистрация КД»: свои столбцы журнала и их порядок, отправка инструкции новым
  регистрирующим по кнопке, оформление ответов разметкой HTML.
- «Сравнение составов изделий»: в расшифровке строки сопоставляются по КД внутри родительского
  узла с учетом повторений; сначала выводится актуальный состав, затем исторические строки.
- «Сводная трудоемкость»: удаление пробелов по краям названий и текстовых значений
  при переносе в коллекцию.
- Разные значки баз SQLite и PostgreSQL; пустые корни баз скрываются при фильтрации
  в календаре, задачах и библиотеке.

### Исправлено
- Дополнительные окна открываются по центру главного окна без последовательного смещения
  вправо; учитываются изменение размеров, масштаб экрана и повторное открытие.
- Поля автора и времени создания и изменения читаются из метаданных записи в фильтрах,
  счетчиках, сортировке, экспорте, API и исходящих привязках выделенных записей.
- Поля типа «Пользователь» в новых записях таблицы, задач и календаря заполняются текущим
  пользователем. Явный выбор, включая пустое значение, сохраняется; перенос записей
  сохраняет исторические значения без повторного заполнения.
- Папка-приемник пережидает краткую блокировку входящего файла другой программой
  без повторного разбора и применения данных.
- Исправлены конкурентные операции с SQLite и PostgreSQL, межбазовые ссылки и соблюдение
  условий выбора связанных записей при дублировании и переносе.
- Автоподстановка файлов пересчитывается при создании, переименовании и переносе записей.
- Резервное копирование использует актуальный путь основной базы после переноса;
  состояние расписания и последней успешной копии корректно восстанавливается после прерывания.
- Исправлены регистрация КД по сообщению, обработка пустых ячеек и заголовка шаблона
  в расшифровке составов изделий.

### Безопасность
- Уязвимая зависимость System.Security.Cryptography.Pkcs 8.0.1 обновлена до 10.0.13.

## [1.3.2] — 2026-10-21

### Добавлено
- Связи по свойствам: выбор подписи и поискового столбца, автоматическое сопоставление
  значений двух свойств с предварительным просмотром, обновление после сохранения.
- Вычисляемые свойства `lookup` и `rollup`: значения связанных записей, количество, сумма,
  минимум, максимум и среднее.
- «Настройки → Управление базой данных → Проверить связи»: диагностика ссылок, конфигураций
  и зависимостей. Подтвержденные безопасные исправления применяются по выбору администратора
  после создания проверенной резервной копии. Недоступные базы не считаются удаленными.
- Свойство «Файл»: частичное совпадение имени при автопоиске, несколько найденных файлов
  через запятую с отдельными ссылками, пересчет по кнопке «Сохранить».
- Кнопка с иконкой глаза внизу панели записи скрывает пустые свойства.

### Изменено
- Быстрые и полные автоматические проверки объединены в workflow «Проверки».
  Выпуск ожидает полную проверку четырех платформ и PostgreSQL перед сборкой установщиков.

### Исправлено
- Копирование, перенос, экспорт, импорт и отмена операций со связями сохраняют базу и запись
  каждой цели. Повторная проверка прав и снимка защищает от записи устаревших изменений.
- Пакетные операции с базами в боковых панелях обновляют интерфейс один раз на всю группу.
- Быстрое сжатие базы всегда сообщает о начале этапа; первый сигнал прогресса больше
  не зависит от планирования фонового таймера.

## [1.2.0] — 2026-09-07

### Добавлено
- Раздел «Заметки»: папка с файлами Markdown на вашем компьютере — дерево файлов, три режима
  просмотра, живое оформление прямо в тексте как в Obsidian, меню разметки и автосохранение.
  Файлы остаются вашими и в базу не копируются.
- Разделы работают как одно целое: правка в конструкторе, календаре, панели записи или в окне
  расширения через мгновение видна во всех остальных разделах — без переключения галочек.
- «Настройки → Задачи»: фильтр при открытии раздела, показ выполненных, момент просрочки,
  стадия новой задачи, исполнитель и срок в строке быстрого добавления. Фильтр задач разделен
  чертой на две группы — стандартные пункты и все стадии из свойства «Статус» со своими
  значками; окно задачи предлагает стадии коллекции; в быстром добавлении есть «Не назначен».
- Раздел «Задачи» показывает все задачи без ограничения (страницы при прокрутке, «999+» в
  счетчиках), в том числе еще никому не розданные. Уведомления «Вам назначена задача» и
  «Задача сменила стадию» — стандартно выключены, тумблеры в «Настройки → Общее».
- «Настройки → Календарь»: пятидневка, рабочие часы, режим прокрутки недели, длительность
  нового события, длинные события в сетке.
- «Настройки → Резервное копирование»: расписание на каждую базу, папка копий, ротация;
  базы PostgreSQL копируются через pg_dump.
- PostgreSQL: помощник установки сервера и создание базы из программы. Окно настроек базы
  (имя, обслуживание, пароль); кнопка «Сжать файл» — файл базы больше не раздувается.
- Расширения «Регистрация КД» (обозначения по ГОСТ 2.201-80) и «Водяной знак на PDF»;
  «Сводная трудоемкость» выгружает свод в коллекцию и пишет большие книги потоком;
  настройки расширений — в «Настройки → Расширения».
- Инструкция пользователя внутри программы; «Оформление» — что открывать по умолчанию и что
  показывать; диагностика охватывает всю программу.
- Конструктор: цвет строк, ячеек и текста; фильтр колонки как в Excel; фильтр по дате деревом
  «год → месяц → день»; навигация по строкам в нижней панели; меню свойств в панели записи.

### Изменено
- Дата попадает в календарь только по тумблеру «Отображать в календаре».
- Единый показ Markdown во всем приложении; экспорт в Excel почти не занимает память.

### Исправлено
- Общая база в сетевой папке не зависает и не падает при перезагрузке сервера; ушла ошибка
  «database is locked» при создании задач.
- Календарь: перетягивание и растягивание через границу дня, пятидневка в «Годе» и «Диаграмме».
- Таблица: ручная ширина столбцов не сжимает соседей; «Сводная трудоемкость» больше не дает
  нечитаемый в Excel свод.

## [1.1.0] — 2026-08-16

### Добавлено
- Раздел «Задачи» показывает задачи всех коллекций, отмеченных галочками в боковой панели,
  разложенные по этим коллекциям: над каждой пачкой — название коллекции, полоска ее цвета
  и счет выполненных («2 из 7»). Клик по заголовку сворачивает группу, как в дереве слева.
  Раньше клик по коллекции открывал ее одну, и увидеть задачи двух коллекций разом было
  нельзя.
- Быстрый фильтр задач в панели навигации: «Все задачи», «Сегодня», «Мне назначено»,
  «Без срока», «Просрочено», «Выполнены» — у каждого пункта число задач, которые он покажет.
  Пустой пункт видно сразу: он бледный и без числа.
- Задачи выделяются и правятся пачкой: клик выделяет карточку, Shift+клик добавляет,
  Ctrl+Shift+клик берет все между. Правый клик открывает меню «Изменить / Дублировать /
  Удалить», Delete удаляет выделенное. Перед удалением и дублированием спрашивается
  подтверждение с количеством, а если на задачи ссылаются связи из других записей —
  предупреждение об этом.
- В строке быстрого добавления задачи появился выбор коллекции: задача больше не уезжает
  в первую попавшуюся. При нескольких базах к названию добавляется имя базы, а список
  исполнителей перечитывается под выбранную базу.
- При первом запуске на чистом компьютере заводится вводный чек-лист — по задаче на каждый
  раздел программы, с описанием, сроком и исполнителем. Если на компьютере уже есть базы,
  чек-лист не появляется; удаленные задачи не возвращаются следующим запуском.
- Журнал изменений и диагностику можно выгрузить в CSV — кнопка в правом краю панели
  навигации. В файл едет то, что на экране: те же фильтры, та же сортировка и те же подписи.
  Показывается прогресс с оценкой оставшегося времени, отмена удаляет недописанный файл.
- Панель пользователей в профиле: роли, доступ к базе данных и все права — в одной таблице
  «пользователь × действие», с выбором области действия (вся база или отдельная коллекция).
  Появились назначение и снятие роли администратора и удаление пользователя из базы, а также
  отдельное право на дублирование свойства.
- Горизонтальная прокрутка в боковых панелях и окнах «Отображение записей» и «Отображение
  свойств»: длинные названия больше не обрезаются насовсем.
- В режимах «День» и «Неделя» у блока «весь день» появилась своя полоса прокрутки.

### Изменено
- Галочки коллекций в боковой панели сохраняются между запусками — отдельно для календаря
  и для задач. Раньше после выхода из программы все коллекции снова оказывались отмеченными.
- Многострочные названия везде показываются одной строкой — карточки задач, календарь,
  панель записи, дерево слева, списки выбора. Само название не меняется: в окне правки виден
  и правится полный текст, а поиск, сортировка и экспорт работают по нему целиком.
- Разделы настроек и профиля занимают всю ширину окна: содержимое заканчивается там же, где
  заголовок раздела, а не обрывается посреди экрана.
- «Описание» стало обычным свойством коллекции — привязки к разделам теперь явные.
- Выпадающие списки: пустой список говорит «Список пуст» вместо полоски в несколько пикселей,
  выпадашка не шире самого поля, а ее высота — около восьми пунктов.
- Выделенная колонка таблицы заливается тем же голубым, что и выбранная запись, вместо
  синей рамки поверх ячеек.
- Отказ по правам объясняется, а не молчит: коллекция без права просмотра показывается
  замком, запрещенные пункты меню и кнопки поясняют причину окном.
- Иконка приложения больше не обведена белой рамкой. Вместо одной картинки на все системы
  теперь три — под Windows, macOS и Linux, каждая по правилам своей системы: на macOS
  плашка вписана в сетку Apple, на Linux скругление заметнее.
- Установщик теперь лежит рядом с установленным приложением и служит единственной точкой
  входа для установки, обновления и удаления. На macOS вместо файла
  «Uninstall SmartBase.command», открывавшегося через Terminal, рядом с программой лежит
  «SmartBase-Setup».
- Окно установщика само находит установленные копии на компьютере — папку установки больше
  не нужно помнить. Если копий несколько, показывается список с путями и версиями.
- Флажок «вместе с данными пользователя» переехал в окно установщика, к кнопке «Удалить»,
  и предупреждает, что именно будет стерто.

### Исправлено
- Счетчик выбранного фильтра задач сбрасывался в ноль: стоило зайти на пустой пункт
  («Сегодня») и вернуться обратно, как в свернутом списке появлялся ноль, хотя в раскрытом
  число было верным.
- Полоса прокрутки в скругленных блоках — многострочном «Описании», выпадающих списках,
  попапах-карточках — не доходила до краев и перекрывала рамку.
- В карточке свойства многострочное значение вылезало за края: показывались куски строк.
  Теперь видна первая строка, а полный текст правится в нижнем блоке.
- Автозапуск: программа, запущенная системой при включенном фоновом режиме, не показывала
  окно; тумблер в настройках не отражал состояние системы, а пропавшая запись автозапуска
  не восстанавливалась. Закрытие окна больше не срывает начатое обновление.
- Шкала «Диаграммы» заканчивалась под полосой прокрутки, а не там, где начинается полоса.
- В окнах «Отображение» и в фильтре колонки разъезжались отступы: просвет между номером,
  счетчиком и текстом отличался от строки к строке.
- После обновления программы на части компьютеров оставалась прежняя иконка — на ярлыке,
  на панели задач и в Проводнике, хотя внутри самой программы иконка была новая. Обновление
  меняло только сам файл программы, и система продолжала показывать значок, который
  запомнила раньше. Теперь обновление заодно обновляет ярлыки — включая закрепленные на
  панели задач и сделанные вручную — и просит систему перечитать значки.
- После обновления файл «SmartBase-Setup» рядом с программой оставался от прежней версии:
  со старой иконкой и старым номером версии. Из-за этого окно установщика могло показать
  не ту версию установленной копии.
- Удаление программы не снимало автозапуск: система продолжала пытаться запускать
  удаленное приложение.
- Путь установки, вписанный в поле вручную, не приводился к отдельной подпапке — программа
  могла лечь прямо в выбранную папку, например в «Документы». Теперь правило действует и на
  вписанный путь, а окно заранее показывает, куда именно установит.

## [1.0.4] — 2026-08-09

### Изменено
- Новая иконка приложения — одна для Windows, macOS и Linux. Retina-слот в Dock теперь
  собирается из мастера 1024×1024, а не растягиванием половинного размера.

### Исправлено
- Выпадающий список времени мог уронить программу, если в поле стояло произвольное
  время: прокрутка к выбранному пункту выполнялась и тогда, когда выбирать было нечего.
- Импорт и экспорт падали, если панель к этому моменту была отцеплена от окна.

### Безопасность
- Закрыты четыре уязвимости в транзитивных зависимостях:
  SQLitePCLRaw 2.1.10 → 2.1.12 (CVE-2025-6965, повреждение памяти в SQLite),
  System.Drawing.Common 4.7.0 → 4.7.2 (CVE-2021-24112, удаленное выполнение кода),
  Tmds.DBus.Protocol 0.20.0 → 0.21.3 и Tmds.DBus 0.9.1 → 0.92.0
  (GHSA-xrw6-gwf8-vvr9, подмена сигналов D-Bus).

## [1.0.3] — 2026-08-07

### Добавлено
- Универсальный конструктор данных: коллекции с произвольными полями, записи, представления.
- Календарь (месяц, неделя, день, год, расписание, журнал, диаграмма), задачи, расширения.
- Работа с несколькими базами одновременно, SQLite и PostgreSQL, пользователи и права.
- Импорт и экспорт, автообновление из сетевой папки, нативные уведомления, автозапуск.
