# Общая обвязка тестов расширений

Библиотека, а не набор тестов. Здесь лежит то, что нужно нескольким наборам из
[`Tests/Extensions/`](../Extensions/) и не имеет отношения ни к одному расширению в отдельности:

| Файл | Что делает | Кто пользуется |
|---|---|---|
| [TempDatabase.cs](TempDatabase.cs) | временная SQLite-БД, поднятая настоящим `DatabaseManager.Open` | `DocsCollection`, `TimeCollector`, `DocRegistry`, `PdfWatermark` |
| [TempDir.cs](TempDir.cs) | временная папка, которая сама убирается | `DocsCollection`, `TimeCollector`, `DocRegistry`, `PdfRename`, `PdfWatermark` |
| [SyncProgress.cs](SyncProgress.cs) | приемник прогресса без фоновых потоков | почти все наборы со сквозным прогоном |

Namespace и имя сборки — `SmartBase.Tests.Extensions.Shared`.

## Почему папка лежит рядом, а не внутри `Tests/Extensions/`

Скрипт прогона [`run-extensions.sh`](../run-extensions.sh) собирает наборы глобом
`Tests/Extensions/*/*.csproj` и написан с обещанием «править не нужно никогда». Проект внутри
попал бы в этот глоб, и прогон стал бы запускать библиотеку без тестов. Снаружи он в глоб не
попадает, и скрипт остается нетронутым.

## Как подключить

В `.csproj` набора:

```xml
<ProjectReference Include="..\..\ExtensionsShared\ExtensionsShared.csproj" />
```

В файле теста — `using SmartBase.Tests.Extensions.Shared;`.

## Правила

**Сюда попадает только то, что уже понадобилось ДВУМ наборам.** Обвязка «на будущее» — это
общая зависимость, которую никто не просил: наборы расширений задуманы самодостаточными, и
каждый лишний общий тип чуть-чуть отвязывает удаление расширения от «убрать папку».

**Специфичное для расширения остается в его папке.** Стенды `ExcelStand.cs`, `PdfStand.cs`,
`JournalStand.cs` знают про свое расширение и уезжают вместе с ним — им здесь не место.

**Никаких утверждений.** xunit тут не подключен намеренно: обвязка готовит условия, а проверяют
наборы. Стенд, которому понадобился `Assert`, — признак того, что он специфичен для расширения.

**Ушел последний потребитель — уходит и этот проект.** Это единственная цена, которую платит
отделимость расширений: удаление расширения перестало быть строго «убрать папку». Проверить, не
остался ли проект без потребителей:

```bash
grep -rl ExtensionsShared Tests/Extensions
```

Пусто — папку можно удалять целиком.

Подробности решения — [docs/developer/testing/extension-tests.md](../../docs/developer/testing/extension-tests.md),
раздел «Обвязка».
